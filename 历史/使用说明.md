# 核心考点背记训练器 · 使用说明（历史）

> 一个单文件网页：把 `images/` 里那 12 页**核心考点**拆成 **254 张考点卡**，用「翻卡背 → 填空闯 → 四选一」三个难度递进的模式反复刷，答错的自动进错题本，连续答对 3 次才算「熟练」。
>
> 另外收了 **两份卷子**，都在 ⑥ 套卷 里做：一份 **2026-2027 学年第一学期期中卷**（20 道选择题 + 3 道材料题，全卷 70 分，选项/答案/解析和参考答案、采分点都有），一份 **100 道选择题的期中冲刺专练**（带答案和逐项解析）。顶部可以换卷；可以整卷顺序、随机 20 题、只做错题、按单元做。

## 一、怎么打开

双击 **`核心考点训练.html`**，用 Chrome / Edge 打开。

- 不需要联网、不需要安装，考点、判分逻辑全在这一个文件里。
- 手机上也能用：把 `核心考点训练.html` 和 `images` 文件夹一起发到手机，用浏览器打开（**放在同一个文件夹里**，否则「对照原页」和套卷配图点不开）。
- 练习记录存在**这台设备的浏览器**里（关掉网页不丢），清缓存/换电脑会丢 —— 顶部有「导出记录 / 导入记录」用来备份和搬设备。
- **关网页 / 刷新 / 手机切到后台都没关系**：重新打开会回到上次练到的那一题，顶部会提示「上次练到：① 翻卡背 · 第 3/254 题」。点「从头开始」才会回到这一轮第 1 题；⑥ 套卷做了一半，本轮已答的题也会一起恢复。

目录结构：

```
核心考点训练.html    ← 工具本体（双击打开）
使用说明.md          ← 本文件
考点数据.json        ← 254 个考点的数据（改完可以重新生成网页）
试卷数据.json        ← 两份卷子的数据（papers[]：期中卷 23 题 + 100 题专练）
试卷单元.json        ← 100 题专练里每道题归到哪个单元（人工校正过的）
题库/                ← 期中卷的原卷照片（2026-2027学年度第一学期期中/01–08.jpg）
images/              ← 扫描的原页（点「对照原页 pN」会打开对应那张）
images/试卷/         ← 100 题专练里的 15 张配图（从 docx 里拆出来的）
预览截图/            ← 界面截图
```

## 三、六个模式怎么用

顶部六个标签，从左到右就是建议的使用顺序：

### ① 翻卡背 —— 认脸

先只显示问题，自己心里（或纸上）说一遍，再点「显示答案（空格）」。
答案里的**红字**是这份提纲里打星的关键词，就是要能默写出来的那部分。
对照完之后老实选一个：**会了（1）/ 有点模糊（2）/ 不会（3）**。
- 「会了」→ 熟练度 +1（连对 3 次标「熟练」）
- 「有点模糊」→ 不算对也不算错，连对计数清零，下次还会碰到
- 「不会」→ 记一次错，进错题本

> 自评要诚实。这里没人查，哄自己等于白练。

### ② 填空闯 —— 落笔

把答案里的关键词挖成空格，靠打字填。这是**最接近考试**的一关：历史最容易栽在"年份写错、人名写错一个字、条约名记串"，光认得没用。
- 填完按「提交判分」（或回车）。对的变绿，错的变红并在后面给出正解。
- 长答案（8 个字以上）判分做了容错：少写一个"的/和/了"不算错。
- 真觉得自己答对了但被判错（比如输入法问题），点「我其实答对了（算对）」，会把这题的错记录改回来。
- 实在想不起来点「看答案（算不会）」—— 直接算错，别骗自己。

### ③ 四选一 —— 提速

从别的考点里自动抽 3 个干扰项凑成 4 个选项，一条一条刷，速度最快。
历史特别适合这么练：一堆"第一部""最早""标志"很容易记混，四选一逼你在几个相近说法里做区分。
答错也能立刻知道正解，可以点「看整条答案」看完整答案。

### ④ 错题强化 —— 补漏

只出「错过、而且还没连续答对 2 次」的**考点卡**，按错得多的排前面。连续答对 2 次就自动出库。

页面下半部分另有一块**「试卷错题（N 道）」**：⑥ 套卷里错过的题不在上面的卡片队列里，会在这里单独列出来（题号 · 单元 · 累计错几次），点「回炉这题」直接跳回套卷那一道；点「打开套卷错题本 →」看全部，可以勾「我会了」清掉。

### ⑤ 清单 —— 查和背

- 按单元/课列出全部 254 张考点，点标题展开看答案。
- **顶部「按单元 / 筛选范围」两个下拉框在清单里也生效**：选「第六单元」就只列这个单元的卡，再叠「只看★必背」就只剩这一单元的必背卡；出现筛选时会多一行「筛选结果 N 张 · 清除筛选」，点一下回到全部 254 张。清单里打印的也是筛选后的结果。
- 勾上「遮住红字」，红字会变成灰块，点一下才显示 —— 适合对着清单自测。
- 上面有**各单元熟练度**和**最该补的 10 张**（都按当前筛选范围算）。
- 「打印这份清单」可以直接打印（或存成 PDF），纸上背。
- 搜索框可以查关键词，比如「文艺复兴」「瓦特」「1787」。

### ⑥ 套卷 —— 真题实战

这一栏现在有 **两份卷**：开头默认是 **2026-2027 学年第一学期期中卷**（20 选择 + 3 材料题，全卷 70 分），顶栏左边的下拉框可以换到 **100 题期中冲刺专练**。两份卷的记录分开记（按题 id 存），换回来还在。

- 一次显示一道题，**点选项或按 1–4** 作答；答完立刻判对错，并把这道题的 A/B/C/D **逐项解析**展开（正确项标绿）。
- **按回车**直接下一题。**回头再看同一题是空白重做**（不会带着上次的选项和答案）：题头会提示「这题本轮已作答」并给出上次选了什么，想核对就点「看上次的答案与解析」；做完那题也可以随时点「重做本题」清空重来。
- 每题都记**累计错几次 / 做过几次 / 对几次**，题头和错题本里都能看到（改对了也不清零）。
- **错题不再自动出库**：做过错的题会留在「错题本」里（顶栏「错题本（N）」），可以「重做这题」或勾「我会了，清掉」；清掉以后再做错，会自动回来。「只做错题」拉出的就是错题本里的题。
- 顶部下拉框：
  - 最左边选**哪一份卷**（期中卷 / 100 题专练）；
  - 中间选**单元**（只做某单元，比如「第六单元 资本主义制度的初步确立」29 题）；
  - 右边选**范围**：整卷顺序 / 随机 20 题 / 只做错题 / 只做没做过。
- 一轮做完出**结算页**：对几题、错几题、正确率多少，错题号点一下就跳回那道题看解析。
- 「打印整卷」会把**当前这份卷**连答案和解析排成一份可直接打印（或存 PDF）的解析版。
- 答错后点「看本单元考点」，会跳到 ⑤ 清单 里这一单元的考点卡，先补知识点再回来做。

**材料题（第 21–23 题）怎么练**：

- 屏幕上先给你**材料和每一小问的设问、分值**，没有选项也没有答案——**在纸上写**（或者先口头说一遍）。
- 写完了再点 **「我写完了，对照答案」**，才会展开**参考答案**和**采分点**清单。
- 对照着**逐条勾**「我写到了」，页面只算**自评覆盖率**（勾了几条 / 共几条），**不判分、不算错题**——主观题答案不唯一，机器判分只会误伤。
- 结算页会给「采分点自评 N/M 条」；勾不满就说明这题漏了得分点，回头再看一遍参考答案怎么组织的。

> 套卷考的是"读懂材料 → 对应史实 → 排除干扰项"，跟背记卡是两件事：**先用 ①–⑤ 把史实背住，再用 ⑥ 练材料题的判断**。正确率低于 60% 时别继续刷题，回 ⑤ 清单把对应单元过一遍。
>
> 期中卷的答案和解析是**按教材和考点自拟**的（原卷只印了题目，手写的作答是草稿，没有采用）。如果老师的答案不一样，**以老师的为准**，改 `试卷数据.json` 里那一题的 `ans` 和 `why` 再重新生成就行。

## 四、三周怎么安排（每天 15–20 分钟就够）

历史内容比道法多一倍，**按单元推进，不要从头平推**。

| 时间 | 做什么 | 目的 |
|---|---|---|
| 第 1–2 天 | 第一章（第一单元 36 张）走完 ① 翻卡背 | 摸清"一个单元到底有多少个考点" |
| 第 3 天起 | 每学完一课，当天就做 ② 填空闯（只选那一课所在单元） | 当天内容当天落笔，别攒 |
| 每周一次 | ④ 错题强化 清空错题 | 补漏，而不是平均用力 |
| 单元学完 | ③ 四选一 限时刷这个单元 + ⑤ 清单「遮住红字」过一遍 | 提速 + 查有没有记串 |
| 月考/期末前 | 「练习范围」选「只练★必背」→ ③ 四选一 快速刷 97 道 | 20 分钟过一遍全部必背 |
| 期中前一周 | ⑥ 套卷 → 「整卷顺序」两天做一遍（每天 50 题） | 熟悉卷面节奏、找出还在纠结的题 |
| 考前最后两天 | ⑥ 套卷 → 「只做错题」清空 + 「随机 20 题」限时 | 只补漏，不再铺新内容 |

**筛选用法**（顶部两个下拉框，①–⑤ 通用）：
- 左边选单元 → 只练／只看这一单元；
- 右边选范围 → 「只练★必背」/「只练未熟练」/「只练没练过」（在 ⑤ 清单 里显示为「只看…」）；
- ⑥ 套卷 的两个下拉框同理，但范围是「整卷顺序 / 随机 20 题 / 只做错题 / 只做没做过」。
- 两个筛选是**叠加**的，比如「第六单元 + 只看★必背」= 19 张。

## 五、"熟练"是怎么算的

每张卡记四个数：练过几次、对几次、错几次、**连续答对几次**。

| 标记 | 含义 |
|---|---|
| 未学 | 还没练过 |
| 记过 | 练过，但连着对还没到 3 次 |
| 熟练 | **连续答对 3 次** |
| 待强化 | 最近一次答错（在错题本里） |

只看「连续答对」，是因为隔了很久还答得出来才算真会；靠印象蒙对一次不算。
`不确定/模糊` 会把连续计数清零，但不算错、不进错题本 —— 这个设计是为了不打击"其实有点印象"的题。

**累计对/错次数在三个地方都能看到**（答对**不会**把错次清零，方便看"同一处反复错"）：

- **题头**：每张卡右上角/顶部一行的小标签「对 5 · 错 2 · 做过 7」，答完当场刷新，不用等下一题；
- **顶部统计条**：「累计 对 X / 错 Y」是全部考点卡的总和；
- **⑤ 清单**：每行考点后面「对 5 · 错 2」，扫一眼就知道哪张反复错。

（填空题答错后点「我其实答对了（算对）」，会把这张卡的错次 −1 并把连续计数记为 1 —— 那是"我确实答对了"的修正，不算偷偷洗数据。）

**报告怎么看**：
- 顶部「已熟练」上不去、但「待强化」也不多 → 练得太少，量不够；
- 「待强化」一直清不空 → 是**同一批**题反复错，那就是概念没通，回头看书（见第七节的边界）；
- 「今天」的正确率低于 60% → 该停下来把这一课重看一遍，别硬刷。

## 七、一个诚实的边界

这个工具管的是**"记没记住、写不写得出来"**，不管**"懂不懂"**。

历史和政治不一样：真正拉开分的是**材料题的"读懂材料→对应史实→说明影响"**这条链，而背记只能保证你脑子里有"史实库"。
所以这个工具的定位是**打地基**：知识点张口就来，材料题才有余力想别的。

如果一张卡连续错 5 次以上，多半不是你背得不够，而是这条知识点背后的因果关系没通（比如"为什么新航路开辟会导致价格革命""为什么工业革命首先在英国"）。
这时候正确动作是：**拿着「对照原页 pN」回到扫描页，把这一条念两遍，找老师或课本问清楚，再回来练。** 硬刷只会把错的记得更牢。

另外：
- 这些卡是从**你那份提纲**逐字转的，提纲本身写得简（比如有"……""等"），卡里也照原样保留了。**考试答题要按课本完整表述补全**，工具只保证"关键词不漏"。
- 年份、人名、条约名这类最容易错的，建议用 ⑤ 清单 的「遮住红字」对着背，比打字更接近考场。
- 书上如果你有新的补充（老师上课加的），可以告诉我，我再往卡里加。

## 八、以后要加页子怎么办

这份工具是「数据 + 模板」生成的，加内容不用手改网页：

1. 把新页子（拍照或扫描）放进 `images/`，命名接着编号，比如 `历史_13.jpg`，然后 `bun 工具/compress-pages.js 历史` 压成 WebP；
2. 我这边把它转成考点卡，追加到 `考点数据.json`；
3. 跑一句 `node 工具/build.mjs` 重新生成网页（模板在 `工具/core-template.html`）。

也可以直接把新页子发给我，我来做。**注意：重新生成后，网页里的练习记录还在**（记录是按考点 id 存的，id 不变就不丢）。

### 再加一套带答案的试卷

`试卷数据.json` 现在是**多卷**结构：`{ "papers": [ 卷1, 卷2, ... ] }`，网页顶部按这个顺序出现在「选卷」下拉里（排第一的就是默认打开的那份）。

**A. 有解析版 docx**（选择题卷）——不用手抄：

```powershell
python 工具/parse-paper.py "历史\images\新试卷.docx" _新卷.json `
  --id ls-paper02 --name "九上历史·第二套" `
  --imgdir "历史\images\试卷2" --imgbase "images/试卷2/" `
  --override "历史\试卷单元.json"
# 再把 _新卷.json 作为一个元素 append 进 试卷数据.json 的 papers 数组
node 工具/build.mjs 历史
node 工具/test.mjs 历史
```

- `parse-paper.py` 按「1．」切题、按 `A．B．C．D．` 拆选项、按 `【答案】/【详解】` 取答案和解析，题干里的配图和题表按原顺序保留；
- 它自带自检：选项不是 4 个、答案字母不对、解析里"正确"那一项和答案对不上、题号不连续，都会报错并拒绝写出；
- 每题的单元标签先按关键词自动判，判错的写进 `试卷单元.json` 覆盖（键是题号）；
- 它写出来的是**单卷**格式，放进 `papers` 数组时不用改字段。

**B. 只有照片**（像这次的期中卷）——按下面的格式手写一题一条，放进 `papers` 数组：

```json
{
  "id": "ls-mid01",                 // 卷 id，全局唯一；题 id 用 <卷id>-q01
  "name": "2026-2027学年第一学期期中·历史（九上）",
  "exam": "初三级历史期中",           // 可空
  "source": "题库/…/01.jpg–08.jpg",
  "questions": [
    { "no": 1, "id": "ls-mid01-q01", "unit": "第五单元 走向近代",
      "blocks": [{ "t": "p", "v": "题干……（　）" }],
      "opts": ["A 项", "B 项", "C 项", "D 项"],
      "ans": 1,                      // 0=A 1=B 2=C 3=D
      "why": { "A": "……错误。", "B": "……正确。" }, "sol": "" },

    { "no": 21, "id": "ls-mid01-q21", "kind": "sub", "unit": "综合", "score": 8,
      "blocks": [{ "t": "p", "v": "材料一……" }, { "t": "tbl", "rows": [[{"t":"表头"}]] }],
      "parts": [
        { "ask": "根据材料一并结合所学，概括……", "score": 2,
          "ans": "参考答案整段……",
          "pts": ["采分点1", "采分点2"] }
      ] }
  ]
}
```

- **主观题**（`kind: "sub"`）没有 `opts`/`ans`，只有 `parts[]`（每一小问一条：`ask` 设问、`score` 分值、`ans` 参考答案、`pts` 采分点）；`pts` 有几条，自评就能勾几条。
- **图解题**：能用题表（`tbl`）转录的就用题表（人口折线图、柱状图数据、展览馆图片说明都属于这类）；确实要原图的，把裁好的图放进 `images/试卷/`，用 `{"t":"img","src":"images/试卷/xxx.webp"}`。
- 加完跑 `node 工具/build.mjs 历史` 会**先校验再写文件**：题号、4 个选项、答案范围、主观题的设问/答案/分值、图片是否存在，任何一条不过都不会生成网页。
- 旧记录不会丢：记录按题 id 存，id 不变就不丢。

> 页面上的「⑥ 套卷」标签只在有 `试卷数据.json` 时出现；公式记背没有这个文件，就不显示。
