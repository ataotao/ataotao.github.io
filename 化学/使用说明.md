# 化学 · 使用说明

化学目录有**三个入口**：

- `化学每日五写.html` —— **每天 10–12 分钟的手写输出**：5 个化学式 + 2 个化学方程式 + 3 条现象句 + 2 条原因句，按日期自动换题，可打印。见下面「三、每日五写」。
- `化学闪练卡.html` —— 人教版初三（九上 + 九下）**全考点随机练习**，独立于具体卷子，适合每天反复练。见下面「一、闪练卡」。
- `化学思维脚手架.html` —— 九上化学的**一张卷子长出来的训练页**。
  第一版由 2026—2027 学年第一学期期中卷（8 页 / 60 分）的批改结果生成，之后每次考卷都可以往里加。见下面「二、脚手架」。

## 一、化学闪练卡（独立入口）

单文件、零外部数据依赖，直接用浏览器打开 `化学闪练卡.html`。题目由参数化生成器**随机生成**：11 个单元 / 93 类题型（按人教版 2024 新版教材分单元，覆盖中考基础点），同一题型每次数字、物质、选项都可能不同，可反复练。

| 视图 | 用法 |
| --- | --- |
| 今日 | 「全部考点随机 10 题 / 混合 20 题」；下面 11 个单元卡片可进入按单元练 |
| 单元页 | 「本单元随机 10 题」「先看一道例题」，或点任一题型只出该类题 |
| 练习 | 选择题**点选即存高亮**，数值 / 符号题输入后提交（或回车）；点「看提示」展开难点；答错进错题库 |
| 答案解析 | 逐字段显示正确答案 / 你的答案 + **考点难点** + 分步解析 + 考点标签 |
| 错题回炉 | 按 1 / 3 / 7 / 14 天到期；答对自动移出；可「复习到期题」或「全部错题练一遍」 |
| 训练报告 | 累计题数 / 正确率、各单元与薄弱考点正确率、导出记录 JSON |

- 第三单元含「微粒结构示意图」一类：出题时题干里画**真示意图**（圆圈内写核电荷数、外侧逐层弧线标电子数），问法五种——几种元素 / 原子还是离子 / 第几周期 / 易得还是易失电子 / 写离子符号。示意图由内核 `rich()` 把 `⟦sd:z|e,e,e⟧` 标记渲染成内联 SVG，`prompt` 仍存纯文本（错题键引用它）。
- 记录键 `chemflash_v1`（做题 + 错题）与 `chemflash_v1_sess`（续练会话），与脚手架的 `chemScaffold.v1` 分开。
- 深链：`#view=today|wrong|report`、`#view=mod&m=<单元id>&k=<题型id>`。单元 id：`intro/air/struct/water/eq/carbon/fuel/metal/sol/ab/salt/life`。
- 改了出题 / 判分后跑 `node 题库工具/check-flash.mjs 200`：11 单元 / 93 类题型、每类 200 题全通过才收工。

## 二、化学思维脚手架（按卷训练）

### 脚手架的六个页签

| 页签 | 内容 | 什么时候用 |
| --- | --- | --- |
| ① 期中诊断 | 分数构成、选择题对表、逐空判分、失分归因、17 题逐题讲评 | 考完当天，把「为什么错」看明白 |
| ② 知识框架 | 六个板块的判据清单（变化/空气/微粒/水/质量守恒/碳） | 做题卡住时回查，不从头背 |
| ③ 题型模板 | 五类题型的固定步骤 + **十条答题要素**（每个空必须写到哪几条）+ **错空复盘**（给每个错空标一个错因，自动统计） | 考前一周，练「认题型」；每周复盘时标错因 |
| ④ 错题回炉 | 25 题点选即判，错误自动进错题库 | 每天 10 分钟 |
| ⑤ 使用说明 | 口径、来源、维护方式 | 想知道数据怎么来的 |
| ⑥ 原卷重做 | 逐题练习：选择点选即判、填空输入核对；**长填空先逐条勾「必须写到的要素」，再点看答案**，未勾的要素在答案展开后标红 | 按原卷再完整做一遍 |

> 深链 `#view=paper` 进「原卷重做」，`#view=paper&no=17` 直接落到第 17 题，`#view=method` 进答题要素页；其余深链见第五节。

### 本次卷的批改口径（重要）

- **成绩以批改系统为准**：总分 **21.5/60（等级 C2）**，其中客观分 **12/24**、解答题 **9.5/36**。
  数据存在 `题库/2026-2027期中卷.json` 的 `meta.score`，页面「期中诊断」页顶部展示总分/客观分/解答题，并有逐题小问的得分明细。
- **选择题**按答题卡的填涂计分，每题 2 分。合计 12/24。
  （试卷空白处另有铅笔圈注，与填涂不一致；按「以答题卡为准」的口径，**不作为作答、不计分**，页面只作口径说明。）
- **逐空 ✓/✗** 是教辅标注，供卷面核对；「每空均分」估算 ≈8/36 只用来定位失分点，**不再作为成绩**。
- **手写辨认不清的空**仍标「△ 待核」（7 空），只影响卷面核对，不影响上面的官方成绩。
- 有两处参考答案本身有合理歧义（第 13⑤ 质量比、第 14(5) 选 A 还是 D），题内已标「以老师讲评为准」，没有硬扣分。

> 结论先行：这次不是「不会」，是两类可修的错——
> ① 化学用语不规范（离子符号、化学式只写酸根、化合价不列式）；
> ② 概念只记结论、不记判据（「微观上什么变了」答成「物理变化」）。

### 主观题怎么练（36 分的那一半）

这次 5 道大题 34 个空，错了 27 个，**平均每空 1.06 分**——不是某个知识点不会，是绝大多数空都写不出能得分的答案。所以主观题不靠「多讲题」，靠三层：

| 层 | 在哪做 | 怎么做 |
| --- | --- | --- |
| ① 答题要素 | ③ 题型模板 | 十条要素表：认问法 → 对「必须写到」→ 看自己缺哪条 |
| ② 逐空自检 | ⑥ 原卷重做 | 长填空写完，先勾「必须写到的要素」（勾选存本机）；勾不全就点看答案，缺的要素标红 |
| ③ 错因复盘 | ③ 题型模板底部 | 27 个错空各标一个错因；标满 5 个自动出结论。**最大类不是「不知道」就不要再加刷题量** |

工具替代不了的两件事：

- **每天 10 分钟手写**：5 个化学式 + 2 个方程式 + 3 条现象 + 2 个原因句，家长照答案圈错，错的抄 3 遍。他的错（`PO₄` 漏金属、`H₂O₂ H₂O₂` 不配平）只在手写时暴露，键盘输入练不出来。
- **每周 60 分钟整卷限时**：`#view=paper` 计时重做，做完再逐空对。练的是一题多空时的节奏，不是知识。

错因六类：不知道 / 术语不准 / 答非所问 / 漏要素 / 写法错 / 读题漏条件。标记存在本机 `chemScaffold.err.v1`，不进训练统计。

### 加一份新卷子怎么做

1. 把卷子与答题卡照片放到 `学习资料/题库/化学/<考试名>/`（不入库，照片体积大，仓库只放 JSON）。
2. 照 `2026-2027期中卷.json` 的结构抄一份：`meta` + `questions[]`。
   - 选择题：`type:"choice"`，`options` 四个、`ans`、`mine`、`ok`、`why`。
   - 填空题：`type:"fill"`，`blanks[]` 里每个空写 `k`（①/(2)①）、`ask`（问什么）、`ans`、`mine`、`ok`、`why`。
3. 想让它出现在页面上，需在 `源/shell.html` 里把 `EXAM` 指向新文件（或把多份卷子合成一个 `exams[]`，届时同步改 `build.mjs`）。
4. `node 工具/build.mjs` → `node 工具/parity.mjs 化学`。

### 补录原卷照片（重做用）

原卷 JPG 留在 OneDrive 本机留档，不入库；仓库只放页面读的压缩 webp：

```bash

node 工具/build.mjs && node ../工具/parity.mjs 化学
```

脚本做四件事：按 1400px 宽 / q72 压成 webp → 写入 `images/试卷/<id>/` → 登记 `题库/试卷库.json`（同 id 覆盖，自动清理旧图与临时文件）。
「对应题库id」填了，页面上才能进**逐题练习**与打印空白卷；不填则只能看原图。
参数中 `ffmpeg` 需在 PATH（或设 `FFMPEG` 环境变量）。单卷实测 6 张约 550 KB，远低于仓库 2 MB 硬限。

### 逐题练习怎么用

- 打开「⑥ 原卷重做」，默认逐题练习：题号导航条显示进度（绿=对、红=错、黄=自评中）；「看整卷原图」可切回画廊。
- **选择题**：点选项立即判分并显示理由；「重做本题」清空选择。
- **填空题**：短空输入后点「核对这一空」自动判（忽略全半角/空格/「约」/括号说明）；长空与简答写完点「看答案自评」，自己判定对/待复习。
- **每题原图**：题面上的折叠区显示该题在原卷上的裁切局部，点图看整页放大（左右键翻页、Esc 关闭）。
- 作答进度存本机 `chemPractice.v1`（与诊断页记录 `chemScaffold.v1` 分开），刷新可续；换卷时在 `试卷库.json` 的 `crops` 里标每题裁切框 `{page, box:[x1,y1,x2,y2]}`，坐标按 1400×1050 的页面图。

## 三、化学每日五写（每天 10–12 分钟，纸笔）

`化学每日五写.html` 是**唯一要求「写在纸上」的入口**。键盘输入练不出来的错——`PO₄` 漏金属、`CaOH₂` 漏括号、方程式不配平不写条件——只有手写才会暴露。

### 每天固定 12 项（学到九上全部时的满配）

| 组 | 项数 | 练什么 | 判分口径 |
| --- | --- | --- | --- |
| 化学式 | 5 | 五类问法各 1 个：给名称写 / 给原子团·化合价写 / 给信息写 / 标化合价 / 改错 | 代数和为 0、原子团加括号、脚标最简 |
| 化学方程式 | 2 | 实验室制气、燃烧、金属与酸、还原、复分解 | **四件套**：化学式、配平、条件、↑↓；缺一项整问 0 分（广州阅卷口径） |
| 现象句 | 3 | 固体 / 气体 / 溶液 各 1 条 | 只写看到的，不写结论（「生成四氧化三铁」不是现象） |
| 原因句 | 2 | 原因 / 作用 / 目的 | 两段式：因为…（条件或原理）→ 所以…（结果）；作用类要写全 2–3 件事 |

### 范围：只出学过的单元

页面工具条第一行是 **「学到第 ▾」**，选到学校已经讲到的那个单元（人教版 2024 新版 11 单元，九上 ①–⑦，九下 ⑧–⑪）。**只有该单元及以前的题会出**，后面的知识点不会混进来：

| 学到 | 当天项数 | 说明 |
| --- | --- | --- |
| ② 空气和氧气 | 4 项 | 化学式、方程式都还没学，只出现象句 + 原因句 |
| ④ 自然界的水 | 9 项 | 化学式开始出（5 类问法都能抽到），方程式仍空 |
| ⑤ 化学反应的定量关系 | 11 项 | 加进 2 个方程式；溶液类现象要到 ⑩ 才有 |
| ⑥ 碳和碳的氧化物 | 12 项 | 满配 |
| ⑦ 能源…（默认） | 12 项 | 九上全 |
| ⑨ / ⑪ | 12 项 | 含九上全部 + 对应九下单元 |

- 空掉的那一组会显示「这一组的知识点还没学到，先不练」并注明**最早在哪个单元出现**，不是页面坏了。
- 每道题**题号后面的 ①…⑪** 是这道题的知识点单元（上册青色、下册紫色），鼠标悬停看全名。所以既能整体按进度筛，也能单看某题属于哪一单元。
- 选择结果按天记在本机（`lv` 字段），换设备或清缓存要重选一次。
- 切换范围**不会打乱已标的对错**：每天的记录按范围分开存，切回原范围标记还在。

### 怎么用

1. 打开页面 → **先把「学到第」调到学校已经讲到的单元**（第一次用必做，默认停在九上全部）→ 点「开始计时」（12:00 倒计时）→ 写在作业本上，**写不出来就空着，别翻书**。
2. 写完才点每项的「对答案 · 勾要素」：先自己核「这题必须写到」的 2–4 条，**没写到的就是这一空扣的分**。
3. 每条标「✓ 写对 / ✗ 写错」，底部实时统计（写对 x/N、各类小计、连续天数）；标错的项第二天重写一遍。
4. 「换一组」当天的题重抽；「打印题目 / 打印答案」分两次打印，**答案别和题目印在同一张纸上**（打印件也带单元徽章，能看出这题属于哪一单元）。

### 题目从哪来（出题口径）

- **问法照真题**：题干一律用中考的设问句式（「写出…的化学式」「写出…的化学方程式」「…的原因是」「…的作用是什么」），不用「请回答以下问题」这类泛化表述。
- **标「期中卷」的条目**：直接取他这次写错的原题（磷酸钠化学式、FeTiO₃ 中 Ti 的化合价、过氧化氢制氧方程式、红磷燃烧压强变化、集气瓶水的作用、液态空气分离依据…）。
- **轮转**：同一天刷新题目不变，跨天自动换；化学式 5 类共 63 条 ≈ 12 天不重复，方程式 31 条、现象 36 条、原因 31 条，周期约两周。全部题目按日期确定性抽取，不用联网。
- **单元归属**：题库里每条都有 `u`（1–11，对应 `units` 表），表示这个知识点最早出现在哪一单元。化学式一律不早于 ④、方程式不早于 ⑤（能力前置），物质本身属于后面单元的按后面单元算（如 `FeTiO₃` 标 ⑧）。构建时会算一张「进度 × 可用条数」表，默认档凑不满 12 项就直接报错。
- **不做的**：不给主观题自动打分（关键词判分误判率高），只给「勾了几条要素」；五写的对错**不进错题回炉**，避免和闪练卡的统计混在一起。
