# 公式记背 · 使用说明（九上数学）

> 一个单文件网页：把九上「一元二次方程」「二次函数」的 **24 条公式**拆成「背 → 填 → 认」三轮反复刷，答错的自动进错题本，**连续写对 3 次才算「熟练」**。

---

## 一、怎么打开

双击 **`公式记背.html`**，用 Chrome / Edge 打开。

- 不需要联网、不需要安装。公式排版、判分逻辑全在这一个文件里（没有引用任何外部字体或脚本）。
- 手机上也能用：把这一个文件发到手机，用浏览器打开就行，不用带别的文件夹。
- 练习记录存在**这台设备的浏览器**里（关掉网页不丢），清缓存/换电脑会丢 —— 顶部有「导出记录 / 导入记录」用来备份和搬设备。

目录结构：

```
公式记背.html      ← 工具本体（双击打开）
使用说明.md        ← 本文件
公式数据.json      ← 24 条公式的数据（改完可以重新生成网页）
预览截图/          ← 界面截图
```

## 三、五个模式怎么用

顶部五个标签，从左到右就是建议的顺序。

### ① 背公式 —— 先能默写

只显示公式**名字**和一句提示，先在纸上写一遍，再点「看公式（空格）」对答案。

对完老实选一个：**写对了（1）/ 差不多（2）/ 没写出来（3）**。
- 写对了 → 熟练度 +1（连对 3 次标「熟练」）
- 差不多 → 不算对也不算错，连对计数清零
- 没写出来 → 记一次错，进错题本

> 数学公式必须**落笔**。眼睛看着觉得会，一写就漏负号、分母写成 a —— 这是最常见的情况，所以这一关请拿纸笔。

### ② 填一填 —— 抠细节

公式里的关键块被挖空（比如求根公式挖「分子」和「分母」两处），每空给 4 个候选块，**其中 3 个是故意写错的**：

- `b±√(b²-4ac)` —— 漏了负号
- `-b±√(b²+4ac)` —— 根号里写成加号
- `-b±√(b²-4ac)/a` —— 分母少了 2

这一关练的就是「**别记串**」。全填完点「提交判分」，错的标红，下面给出正确写法。

### ③ 认一认 —— 反向认脸

反过来：给你一个公式，问「这是哪个公式？」。四个选项里三个是同一章节的其它公式，专门用来区分「两根之和 / 两根之积 / 对称轴 / 顶点纵坐标」这种长得像的。速度最快，适合碎片时间刷。

### ④ 错题 —— 补漏

只出「错过、而且还没连续对 2 次」的，按错得多的排前面。清空了说明这一段真补上了。

### ⑤ 公式表 —— 查和背

**最上面那块是「今日必背」**，就是老师要求明天默写的那 13 条，一条一条列好公式：

- **打印这张清单** —— 打出来就一张 A4，明天早读拿着背；打印时会自动只留这一块，章节列表和按钮都不进纸。
- **只练这一批** —— 直接跳到 ① 背公式，只出这 13 条。
- 每条右边有「取消」，点一下就从这一批里拿掉；下面章节列表里任意一条展开后也有「标为今日必背」，点一下能加回来。
- **全部取消** —— 默写完了点它，名单清空，换下一批用（练习记录不受影响）。

名单**存在本机浏览器里**，关掉网页不会丢；列表上标「今」的就是当前这批。

其余部分：

- 按章节列出全部 24 条，点标题展开看公式、口诀、易错。
- 勾上「**遮住公式**」：公式会糊掉，**口诀和易错也一起遮**（不遮等于把答案写在旁边）；展开任意一条，点一下那张卡就揭开。想重新全部遮住，把勾取消再勾上。「今日必背」那块也会一起遮。
- 「打印公式表」打印的是全部公式（正在遮着也会按清晰版打印）。
- 搜索框可以查关键词，比如「判别式」「顶点」「韦达」。

## 四、今晚怎么用（明天要默写）

**今晚 40 分钟，按这个顺序走**。顶部「练习范围」先选「**只练今日必背**」，五个模式就只出那 13 条。

| 时间 | 做什么 | 为什么 |
|---|---|---|
| 5′ | ⑤ 公式表 → 点「打印这张清单」，打出来放桌上 | 明天早读要用的纸，现在顺手打好 |
| 15′ | ① 背公式：**拿笔在纸上默写**，写完再点「看公式」对 | 明写的是卷面，不是「看懂了」 |
| 12′ | ② 填一填：13 条全过一遍 | 这一关专门抓「分母写成 a」「4ac−b² 和 b²−4ac 反了」这类错 |
| 5′ | ③ 认一认：快速刷一遍 | 防止「两种形式记串」「两根之和记成积」 |
| 3′ | 扫一眼 ⑤ 公式表里的「易错」 | 明天错的八成就在这几句里 |

**明早**：拿着打印的清单，遮住公式自己说一遍；说不出来的那几条，用 ① 背公式「只练这条」单独过两遍。

> 别贪多。13 条一次全上，容易前面记住后面忘。实在背不完，优先顺序是：**求根公式 → 判别式 → 韦达（和/积）→ 顶点坐标 → 对称轴 → 三种形式 → 根的情况 → 例题**。

**默写考完之后**：⑤ 公式表点「全部取消」清掉名单，把「练习范围」选回「全部范围」，慢慢把剩下 11 条（变形、最值、平移、系数符号、配方来历等）补上。

## 六、"熟练"是怎么算的

每条记四个数：练过几次、对几次、错几次、**连续答对几次**。

| 标记 | 含义 |
|---|---|
| 未学 | 还没练过 |
| 记过 | 练过，但连着对还没到 3 次 |
| 熟练 | **连续答对 3 次** |
| 待强化 | 最近一次答错（在错题本里） |

只看「连续答对」，是因为隔了几天还写得出来才算真会；刚看完答案马上默写一遍不算。
「差不多」会把连续计数清零，但不算错、不进错题本 —— 这是为了不打击那些「其实有点印象」的公式。

**报告怎么看**：
- 「已熟练」上不去、但「待强化」也不多 → 练得太少；
- 「待强化」一直是**同一批**清不空 → 不是记的问题，是没懂（见第八节）；
- 「今天」正确率低于 60% → 停下来把这一章课本例题重看一遍，别硬刷。

## 七、记录怎么备份 / 换设备

- **导出记录**：下载一个 `数学-公式记录-日期.json`。里面既有每条的练习记录，也有「今日必背」名单。

> 注意：在网页里点「清空」只清练习记录；「今日必背」名单要用 ⑤ 公式表里的「全部取消」单独清。

## 八、一个诚实的边界

这个工具管的是**"能不能默写出来"**，不管**"会不会用"**。

九上真正拉开分的是这几件事，工具一样也帮不上：

| 会默写 | 还要会 |
|---|---|
| Δ=b²−4ac | 含参题里用韦达求出参数后，**回头检验 Δ≥0** |
| 顶点坐标 (−b/2a, (4ac−b²)/4a) | 给定取值范围时，最值可能在**端点**而不是顶点 |
| 顶点式 y=a(x−h)²+k | 从「利润」「面积」的文字里**列出函数**，再求最值 |
| 三种形式 | 看题目给的条件**挑**用哪一种 |

所以定位是**打地基**：公式不再写错、符号不再记反，考场上那 10 分的基础分先拿稳，才有余力去想别的。

如果一条公式连续错 5 次以上，多半不是背得不够，而是没弄清它在算什么。这时候正确动作是：关掉工具，翻开课本对应例题，把推导走一遍，再回来练。硬刷只会把错的记更牢。

另外：例题卡（`cf-11`）那一条是**过程**，不是公式 —— 它在 ① 背公式 里可以一步一步看，在 ③ 认一认 里不会出现。

## 九、以后要加公式怎么办

这份工具是「数据 + 模板」生成的，加内容不用手改网页：

1. 改 `公式数据.json`，照现有条目加一条；
2. `node 工具/build.mjs 公式记背` 重新生成网页；
3. `node 工具/test-formula.mjs` 自检（993 项断言：每条公式都能画出来、槽位数对得上、选项不重复）；
4. `node 工具/test-ui-formula.mjs` 再自检（用本机 Chrome 真点一遍五个模式）。

一条公式长这样：

```json
{
  "id": "qe-14",
  "unit": "一元二次方程",
  "name": "显示名（③ 认一认 的选项就是它，别和别的重名）",
  "q": "卡片正面那句提示 / 问题",
  "tex": "x=\\frac{-b\\pm\\sqrt{b^2-4ac}}{2a}",
  "cloze": {
    "tex": "x=\\frac{\\slot{0}}{\\slot{1}}",
    "blanks": [
      { "ok": "-b\\pm\\sqrt{b^2-4ac}", "wrong": ["b\\pm\\sqrt{b^2-4ac}", "-b\\pm\\sqrt{b^2+4ac}", "-b+\\sqrt{b^2-4ac}"] },
      { "ok": "2a", "wrong": ["a", "2", "4a"] }
    ]
  },
  "tip": "口诀",
  "trap": "易错",
  "why": "为什么（可省）",
  "star": 3
}
```

- `tex` 用**简化 LaTeX**：支持 `\frac{}{}`、`\sqrt{}`、`^`、`_`、`\text{中文}`、`\slot{n}`，以及 `\pm \times \div \le \ge \ne \Rightarrow \Leftrightarrow \Delta` 等符号。不认识的命令会原样漏出来，所以改完一定跑一遍自检。
- `cloze.tex` 就是 `tex` 把要挖的地方换成 `\slot{0}`、`\slot{1}`……
- `blanks` 每项 `ok` 是正确答案，`wrong` 至少 3 个，**故意写成常见错法**才有训练价值。
- `star`：3 = ★★核心，2 = ★，1 = 普通。
- `today: true`：表示「下次打开时默认进今日必背名单」。**只在第一次打开（本机还没有名单）时生效**，之后以你在网页里点出来的为准，所以老师加了新要求，直接在 ⑤ 公式表里点「标为今日必背」最快，不用重新生成。
- 只改文字、不改 `id` 的话，练习记录不会丢（记录是按 id 存的）。

**注意**：重新生成网页后，浏览器里的练习记录还在（记录存在浏览器，不在网页文件里）。
