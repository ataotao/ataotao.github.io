# 题图显示规范（出题前图 vs 答后验证图）

适用：所有训练页里带 `fig` 的题目（`函数思维脚手架.html`、`数学闪练卡.html` 及其他训练页）。
新增题、改题、迁移题型时都要按这份规范判定，不要默认“图放在答后就行”。

## 一、两类图，判定只有一条标准

**题干里的文字是否已经把解题所需的位置关系写全？**

| 类型 | 判定 | 图的作用 | 显示时机 |
| --- | --- | --- | --- |
| **题设图** | 文字没写全，必须看图才能确定点、角、长度、位置 | 图承载题设信息，不看图不能下笔 | **出题时**（题干后、输入项前）就必须看到 |
| **验证图** | 文字已写全（坐标/长度/条件都给了） | 只是“答案画出来长这样”，帮着对答案 | 答后在反馈区显示 |

快速 Checklist（命中任一条 → 题设图）：

- 题干出现「如图 / 图中 / 读图 / 网格中 / 图象如图」；
- 点、角、长度要靠图读出来（网格格点、圆周角、弦心距、扇形圆心角、旋转前后位置、灯罩轴截面、拱桥未给坐标）；
- 第一步的动作就是“作辅助线 / 看哪两条线平行 / 判断哪条弧”——这些关系写在图里比文字清楚。

反例（→ 验证图）：「抛物线顶点 A(−2,0)，过 B(0,−2)，求解析式」「反比例函数过 (4,−2)，求 k」——坐标已给全，图只是验证。

## 二、实现约定（数学闪练卡）

- 题设图：`fig.need = 1`（与 `w/h/svg` 或生成器 fig 并列）。
  - `renderPractice()`：在 `qbody` 之后、`q.fields` 之前插入「题图（答题时看这张）」+ `MT.svgFor(q)`。
  - `renderExample()`：题图放在**答案之前**；例题页末尾不再重复。
  - 答后反馈：`q.fig && !q.fig.need` 才显示「图象验证」，题设图不重复出现。
- 验证图：不加 `need`，保持原答后分支。
- `svgFor()`：`fig.svg` 是内联 SVG 片段时直通返回（与题包 `fig.svg` 同格式），**不走坐标变换**，
  否则圆、扇形会被压扁。

## 四、验收

新增或改动带图题后，至少跑：

```bash
node 工具/trainer/build.mjs 数学
node 数学/题库工具/smoke-ui.mjs
node 数学/题库工具/check-training.mjs
```

`smoke-ui.mjs` 对题设图已有断言：答题前出现「题图（答题时看这张）」、答后不出现「图象验证」、
`svgFor` 输出以 `<svg` 开头且无 `NaN/undefined`。新增题设图时把该断言的覆盖范围一起扩掉。

设计背景见 `docs/plans/第12周限时练习录入-2026-11-20.md` 第七节。
