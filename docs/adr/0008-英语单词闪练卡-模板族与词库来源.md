# ADR-0008：英语单词闪练卡走 scaffold 族，词库从 apps/english 构建时提取

- 状态：已采纳（2026-11-19）
- 相关：`docs/plans/英语单词闪练卡-2026-11-19.md`、`GLOSSARY.md`「闪练卡」条、`工具/trainer/kernel.js`、`工具/trainer/scaffold.js`

## 背景

要给英语单词做一张反复练词的闪练卡：三方向四选一（英→中、中→英、音→中），按年级→单元选题，音标配喇叭 TTS。仓库已有两个训练器内核（ADR 前的「训练器模板」术语）：

- **flash 族**（`kernel.js`，化学闪练卡）：UI 由内核字符串模板生成，科目只写 core + 配置，零 UI 维护。但题干/选项都走 `esc()` 转义（`kernel.js:416,425`），所有点击动作是内核写死的 `data-act` 列表（`kernel.js:557-569`），**没有 TTS 发音能力，也不允许科目插自定义按钮**；单元页是扁平 module 列表（`kernel.js:396-404`），没有年级分组这一层。要满足喇叭 + 两级筛选必须改共用内核。
- **scaffold 族**（`scaffold.js`，物理/数学闪练卡）：UI 是科目私有真源 `源/train.ui.js`，h() 函数式渲染 + 自定义事件，加喇叭按钮和年级级联是常规操作，且不动化学那套已稳定的内核。代价是多一份约 20 KB 的 UI 要长期维护。

词库方面，`apps/english/src/data/` 是 4 来源 / 18 册 / 约 3908 词的单一真相源，18 个 `.ts` 文件同构 `Category`（Source → Category/年级册 → Unit → Word），字段 `english/phonetic/pos/chinese`。用户确认只用「沪教版」+「沪教牛津小学」两来源（约 2245 词，音标覆盖良好）。`apps/english` 的 `dist/` 用绝对路径 `/assets/`，`file://` 打不开，不能直接当闪练卡用。

## 决定

1. **英语单词闪练卡归入 scaffold 族**：新增 `工具/trainer/subjects/英语单词.mjs` + `英语/源/train.{css,core,ui}.js` 三源 + `英语/源/train.data.js`（词库），`node 工具/trainer/build.mjs 英语单词` 生成 `英语/英语单词闪练卡.html`。
2. **词库在构建时从 apps/english 提取并内联进单文件**，不运行时 fetch（`file://` 下 CORS 拦截）、不复制第二份数据（双份漂移）。apps/english 保持词库的单一真相源；`英语/题库工具/extract-vocab.mjs` 读两个来源的 `.ts` 字面量，产出 `英语/源/train.data.js`（`var EW_VOCAB = …`）。
   **实现中发现原假设「build.mjs 不改」不成立**：build 只内联 css/core/ui，没有数据段插槽。选择给 `build.mjs` / `selfcheck.mjs` 增加一个**所有科目向后兼容的可选 `dataFile` 段**（科目配置有该字段才插入 `<script id="data">`，无则原样），而不是把 121 KB 词库塞进手写 core——后者会让「改词库」和「改出题逻辑」撞进同一文件。这是本 ADR 相对最初规划的唯一共用脚本改动。
3. **与「粤学词」并存分工**：新卡负责「三方向四选一 + 间隔回炉 + 今日/错题/报告」的记忆训练；粤学词（`英语/yuexueci-web/`）保留其音标跟读、录音评分、发音示范能力。开始页三个英语单词入口并存（`words` 站点首页 / `yuexueci` 粤学词 / `wordsflash` 新卡）。
4. **音→中的「音」= 音标文本 + 喇叭 TTS**，音标为空的词自动降级为纯听音（隐藏音标文本，只留喇叭）。不引入 yuexueci 的第二套词库补音标。
5. **（2026-11-19 补充）例句来自粤学词的词典语料，且在提交后展示**：用户要「课文原文相关的句子」，但全仓库核查后**没有任何按单元组织的课文原文/对话文本**（apps/english 的 `sentences` 字段从未填写、例句靠网络 API，离线不可用）；最接近的是九上试卷题干（仅九上、多挖空）。于是取 yuexueci `full-data.js`/`primary-data.js` 的 `example/exampleZh`（真实语料库句子，非模板造句，词表同属沪教牛津教材体系），构建时按词形匹配注入词库。**只保留例句确实含目标词（或可高亮词形/首个实词）的配对**（2004/2651 = 75.6%），避免给孩子看标不出词的例句。例句**只在提交答案后的解析区显示**，因为中→英/音→中若提前显示含英文的句子等于泄题。不冒充「课文原句」——UI 标签写「用法例句」。

## 后果

- 英语单词卡多一份约 20 KB 的 `train.ui.js` 要维护——换来不碰化学/物理共用内核，且喇叭与年级级联能做干净。以后若 flash 族内核长出 TTS 能力，再评估是否迁移。
- 词库改动必须重跑提取 + `build.mjs 英语单词`；apps/english 的词库 `.ts` 与闪练卡产物之间有一道构建依赖，改词后忘了重建会被 `parity` 类校验抓到。
- 开始页英语组从两个单词入口变三个；「单词闪练」与「粤学词」名字要在开始页 desc/note 里写清分工，避免用户困惑。
