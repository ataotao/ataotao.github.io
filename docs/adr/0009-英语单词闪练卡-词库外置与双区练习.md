# ADR-0009：英语单词闪练卡词库外置，单元/随机双区练习

- 状态：已采纳（2026-11-19）
- 相关：`docs/plans/英语单词闪练卡-词库外置与双区练习-2026-11-19.md`、`docs/adr/0008-…-模板族与词库来源.md`
- 取代：ADR-0008 决定 2 中「词库内联进单文件、不运行时 fetch、无外链」的约束（其余决定不变）

## 背景

ADR-0008 为避开 `file://` 下 `fetch()` 的 CORS 限制，把约 271 KB 词库内联进 HTML 成单文件。运行半年（本仓为一天）后暴露两个问题：

1. 产物 336 KB 里八成是数据，改一处 UI 逻辑要在几万字符里翻找；未来词量增长只会更差。
2. 单轮按单元只出 10 题，单元动辄 14–48 词，一轮练不完；也没有「从全库随机抽 N 词」的练法。

## 决定

1. **词库外置为同目录 `英语/词库.js`**，内容仍是 `var EW_VOCAB = …`（经典脚本，非 ES module）。`<script src="词库.js">` 在 `file://` 下由浏览器本地加载，不走 fetch、不受 CORS 限制；站点发布时两文件放同一目录即可。
   - 不用 JSON + `fetch()`：本地双击时必被 CORS 拦，且引入异步时序；JS 文件能同步赋值，core 无需改动加载方式。
   - 真源仍是 `英语/源/train.data.js`（`extract-vocab.mjs` 生成）；构建器只是把它**复制**成产物 `词库.js`，不是第二份手写数据，避免双份漂移。parity 把产物纳入快照。
2. **构建器向后兼容**：科目配置新增可选 `dataOutFile` / `dataRef`。有字段 → 外置并发 `<script src>`；无字段 → 维持原内联 `<script id="data">`。化学/物理/数学/其它英语产物零影响。
3. **按单元练习加「整单元」模式**：core 新增 `genUnitAll`，每个单元词恰好一题、不遗漏、乱序；「再来一轮」重建新乱序，可完整循环。p2c 方向遇到无音标词降级为 e2c，保证覆盖全部词。
4. **随机练习独立成区**：今日页两个区域各有自己的配置与会话槽（`unit` / `rand`）。随机区从全库去重抽 20/30/50 词；两区配置、会话互不读写。
5. **自检覆盖**：`check-training.mjs` 从外置文件加载数据，新增全单元/随机出题与双区隔离用例；`selfcheck.mjs` 校验外置契约且不影响老科目。

## 后果

- 产物从 1 文件变 2 文件：复制/搬家必须带上 `词库.js`，否则页面提示「词库没加载」。页脚与今日页提示同步更新。
- 站点组装脚本必须发布这俩文件到同一相对目录；漏发则线上白板，已加进 `assemble-site.sh`。
- 数据仍不在运行时联网；离线可用性不变（只是需要两个本地文件）。
- 其它 ADR（scaffold 族选择、粤学词例句、深链契约）继续有效。
