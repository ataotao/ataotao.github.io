# 主观题训练方案（现状评估 + 分阶段做法）

- 状态：方案，未实施（2026-11-04）
- 结论：**主观题是当前六科训练器最大的结构性缺口**，但它不是"再写一个页面"能解决的，主要成本在内容（采分点），不在代码。

## 一、现状

| 科目 | 现有题型的本质 | 主观题覆盖 |
|---|---|---|
| 历史 | 考点卡（问答）+ 100 题选择题套卷 | 材料题**没有**：无史料、无设问、无采分点、无书写训练 |
| 道德与法治 | 考点卡 + 四选一 | 情境判断/辨析题**没有** |
| 数学 | 五步引导 + 分步给分 + 整卷 | 有"分步给分"的雏形；但大题书写过程没有对照物 |
| 物理 | 五步引导 + 试卷（选择为主）+ 概念卡 | 计算题的"过程分"没有单独练 |
| 英语 | 原卷选择 + 填空自测 | **写作、听力**完全没有 |
| 公式记背 | 公式卡 | 不涉及 |

现有判定逻辑的共同点：**答案可枚举**（选择/填空/数值），所以能自动判分。主观题的核心矛盾是：答案不唯一，但**得分点可枚举**。

## 二、三种做法与成本

### A. 采分点自评（推荐先做，1–2 天/科）

**做法**：给考点卡加一个可选字段 `pts: ["设未知数", "列出方程", "解出并检验"]`；做题时孩子先写，点「对照采分点」，逐条勾选「我写了」；错误/遗漏的采分点高亮。
**优点**：不判分、不会误判；直接训练"先写能拿分的动作"；复用现有卡片/渲染。
**代价**：需要为每道题手写 3–5 条采分点（历史材料题一题约 10 分钟）；勾选结果只能算"自评覆盖率"，不能当分数。

### B. 关键词/采分点自动判分（不推荐）

用关键词命中判对错。主观题表述多样，误判率高；判错会直接摧毁孩子对工具的信任（比不判更糟）。**明确不做**，除非将来接人工复核流程。

### C. 整卷材料题（内容工程，1–2 周/套）

**做法**：录一套原卷材料题（题干 + 史料图 + 设问 + 标准答案 + 采分点），页面按"一次一题、先写后对照、按采分点自评"运行。
**优点**：最接近真实考试；一套卷能覆盖一整个单元的材料题类型。
**代价**：一套卷 3–5 大题、每题 3–5 问，录入 + 校对约 1–2 周（历史/道法各一套 = 2–4 周）。素材依赖原卷（照片可读性、答案来源）。

## 三、建议顺序

1. **历史 + 道法先做 A**：这两科主观题分差最大，且现有 `core-template` 已有卡片渲染与筛选，加字段成本最低。
2. **数学补"过程对照"**：把期中卷 19–25 的官方 `solution` 拆成采分点（题包里已有 `steps`，可扩展 `steps[].pt` 显示"这一步值几分"），让孩子写完一步对照一步。
3. **英语作文**：先做"范文 + 扣分点清单"（5 条以内），暂不做自动评分；听力需要音频素材，优先级最低（本地音频与版权都要单独处理）。
4. **C 的整卷材料题**放到寒/暑假做，一次录一套，作为期末复习用。

## 四、验收口径

- A 落地后：每科主观题卡片数 ≥ 20；孩子能不看答案说出「这题要写哪几步」。
- 数学过程对照：一道大题能指出自己漏了哪个得分点（对照 `steps`）。
- 不做"自动给主观题打分"这种假精度；自评覆盖率只用作提醒，不进统计面板的总分。

## 五、与现有工具的关系

- 不做新站点：复用各科单文件页面 + `开始.html` 入口（`#mode=...` 深链已在契约里）。
- 记录：自评勾选可以写进各科 localStorage（新增字段，向后兼容），由「开始.html」的备份一起带走；训练台面板不需要为新字段改动（不认识就不统计）。
