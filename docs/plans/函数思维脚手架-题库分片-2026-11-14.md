# 函数思维脚手架 · 试卷题库拆分为分片

- 状态：**已实施（2026-11-14）**
- 日期：2026-11-14
- 真源：`数学/题库/pack-*.json`（只改这里）；产物 `数学/题库/packs/*.js` + `数学/函数思维脚手架.html` 的
  `<!-- PACKS:BEGIN -->` … `<!-- PACKS:END -->` 区块由 `qb.py build` 生成，不手改（ADR-0003）
- 验收：见「五」

## 一、目标

把「试卷练习」的题目数据从主包 HTML 里搬出去，主包只留引擎。判据：

1. `数学/函数思维脚手架.html` < 400 KB（原来 1.92 MB）；
2. 每套卷一个分片文件，单文件 < 800 KB（`工具/check-size.mjs` 的软阈值，不触发 pre-commit 警告）；
3. `file://` 双击打开时 5 套卷 / 106 题照常出现，做题、判分、录得分、得分档案都不变；
4. 以后加卷只新增一个分片 + 主包一行 `<script src>`，主包大小不再随题量增长。

## 二、范围

- **只改**：`数学/函数思维脚手架.html`（数据块 → 占位 + 分片清单）、`数学/题库工具/qb.py`
  （build / verify / 新增 bundle）、`数学/题库工具/check-pack.mjs`（改读分片）、
  `工具/qa/mk-t-math.mjs`、`工具/qa/mk-probe-others.mjs`（探针相对路径）、`.gitignore`、

  `C:\陶宸欣\ataotao.github.io\tools\publish.ps1`（training 清单加一行）
- **不要动**：`题库/pack-*.json`（一个字节都没改）、BANK / DRILLS / 引擎逻辑、其它学科
- **相关契约**：无 hash 契约变化；`localStorage` 键仍是 `fn_scaffold_v1`，旧记录不受影响

## 三、现状（改造前）

- 主包 1,927,439 B / 11,645 行，其中内联 PACKS 占 **1,619,068 B（84%）**、4,756 行。
- 其余：`head+style+body` 28 KB、`BANK` 67 KB、`DRILLS` 52 KB、引擎 154 KB。
- 数据本来就已在 `题库/pack-*.json` 分卷存放，`qb.py build` 只是把它们**合并后内联**进 HTML——
  也就是说「按卷拆分」这件事早就有真源了，缺的只是运行时别塞进一个文件。
- 已知压力点：主包已 1.92 MB，逼近 `工具/check-size.mjs` 的 **2 MB 硬阈值**（新增文件超 2 MB 直接拒绝提交）。
  按 5 套卷 106 题 1.6 MB 的速度，再加 2～3 套卷就会卡住 pre-commit。

## 四、方案（已实施）

1. **分片格式**：`题库/packs/<题包id>.js`，内容是
   `(window.__PACKS__ = window.__PACKS__ || []).push({…});`
   ——**必须是 classic script**。`file://` 下 ES module（`type="module"`）会被 CORS 拦掉，
   而 classic `<script src>` 不受限，这是整个方案能离线双击的前提。
2. **主包**：`var PACKS = window.__PACKS__ || [];`；分片清单放在主脚本之前的
   `<!-- PACKS:BEGIN -->` … `<!-- PACKS:END -->`，由 build 写成 N 行 `<script src>`（顺序 = 卷顺序）。
3. **build**：写分片 + 重写清单 + 删掉不再对应任何卷的旧分片；单个分片 > 700 KB 时提示拆卷。
4. **bundle**：把分片内联回主文件，产出 `数学/_单文件/函数思维脚手架.单文件.html`（gitignore），
   保住原来「一个文件发手机」的用法。内联时把 `</script` 转义成 `<\/script`，防止 HTML 解析器提前截断。
5. **空分片兜底**：`viewPaper` 的空态文案区分「分片没拷过来」和「真没导入题包」。

## 六、风险 / 没做的事

- **主包不再自包含**：只拷 HTML 会看到空题库（已加提示文案）。要单文件走 `qb.py bundle`。
- **发布清单已同步**：`ataotao.github.io/tools/publish.ps1` 的 training `Items` 加了
  `@{ Path = '数学/题库/packs'; Filter = '*.js' }`；`-DryRun` 已确认 5 个分片会发布。
  **这一行漏了线上就是空题库**——以后改分片目录名要同步改它。
- **`题库/packs/*.js` 是产物**：不要手改，`qb.py build` 会覆盖。想改题就改 `pack-*.json`。
- **没做懒加载**：分片仍是页面加载时全部同步加载（首屏要解析 1.6 MB JS，本地约几十毫秒）。
  真要按需加载见「优化建议」第 1 条——它要改 render 的同步假设，风险明显更大，本次不做。
- **`pack-全部.json` 仍是 1.55 MB 且入库**：它现在和分片内容重复。见优化建议第 2 条。
