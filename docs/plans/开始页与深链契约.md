# 开始页与深链契约（维护必读）

`开始.html` 是全项目唯一入口。它有两个运行环境，一份代码：

| 场景 | 地址 | 能力 |
|---|---|---|
| 本机 | `file:///.../learning-training/开始.html` | 读七科 localStorage →「今天做什么」+「备份全部记录」 |
| 网页 | `https://ataotao.github.io/1/`（= 发布后的 `1/index.html`） | 只做入口（网页读不到孩子设备上的记录），显示科目说明 |

本地与网页的链接都是**相对路径**（`历史/核心考点训练.html`），因为发布后目录结构与仓库根一致。

## 一、今天做什么：任务怎么算

按 `开始.html` 里 `collect()` 的口径读这些键（`file://` 才读）：

| 存储键 | 科目 | 用到哪些字段 |
|---|---|---|
| `kss_v1_历史` / `kss_v1_道德与法治` | 历史 / 道法 | `cards[].seen/ok/wrong/last/firstOk`、`days`、`paper` |
| `gs_v1_数学` | 公式记背 | 同上（无 paper） |
| `physScaffold.v2` | 物理 | `exam[].tries/okN/wrongN`、`guided`、`concept[].n/ok/due`、`days` |
| `physTrain_v1` | 物理训练 | `recs[].ts/ok/mod/kind/mode`、`wrong`（错题本，按 1/3/7/14 天到期） |
| `chemScaffold.v1` | 化学 | `stat[].att/ok/wrong/at`、`days`（`{n, ok}` 按天累计） |
| `ywScaffold.v1` | 语文 | `stat[].att/ok/wrong/at`、`days`（`{n, ok}` 按天累计）、`essay.self` |
| `fn_scaffold_v1` | 数学 | `log[].ok/ts`、`drill[].right/total`、`paper[].ok/ts` |
| `mathcoord_v1` | 坐标图象 | `stat[].att/ok/wrong/at`、`days`（`{n, ok}` 按天累计） |
| `mathtrain_v1` | 数学训练 | `recs[].ts/ok/mod/kind/mode`、`wrong`（错题本，按 1/3/7/14 天到期） |
| `mathwrong_v1` | 数学错题 | `recs[].ts/result`、`wrong`（按 1/3/7/14/30 天到期） |
| `jjb-jiuzhong-shang-v1` | 数学急救包 | `log[id].n/r/w`、`firstOk` |
| `eng9a-practice-v1` | 英语过关 | `stat[].att/ok/wrong`、`at`/`atList` |
| `eng9a-flash-v1` | 英语语法闪练 | `stat[].att/ok/wrong/peek`、`rounds[].endAt`、`current` |
| `enwordflash_v1` | 英语单词闪练卡 | `recs[].ts/ok/mod/kind/mode`、`wrong`（错题本，按 1/3/7/14 天到期） |

任务排序（取前 3，科目不重复）：
1. 物理概念卡到期（`concept[].due <= 今天`）——分数最高
2. 今天没练的科目（按 `last` 越久分越高）
3. 累计错次最多的科目 → 错题模式
4. 不足 3 条时用固定任务补齐（数学基础快练 / 英语逐题 / 公式今日必背 / 历史★必背）

没有记录时给三条「第一次用」任务。改任务逻辑只改 `buildTasks()`，不要在各科里复制一套。

## 二、深链契约（各科必须对得上）

| 科目 | 支持的 hash | 说明 |
|---|---|---|
| 历史 / 道德与法治 | `#mode=recite\|cloze\|choice\|wrong\|list\|paper`、`#fs=all\|star\|weak\|unseen` | 可组合；`paper` 仅历史有套卷 |
| 公式记背 | `#mode=recite\|fill\|name\|wrong\|table`、`#fs=all\|star\|weak\|unseen\|today` | `table` 兼容 `list` |
| 物理 | `#/home`、`#/guided`、`#/concept`、`#/exam`、`#/wrong`、`#/report`、`#/admin` | 物理本来就有完整路由 |
| 物理训练 | `#view=today\|model\|amount\|calc\|draw\|read\|wrong\|report` | 五个动作模块（认模型／认量／算到底／作图判断／读数）+ 错题 + 报告。`calc`/`amount` 是核心；非法值回今日 |
| 化学 | `#view=diag\|map\|method\|drill\|paper\|doc`、`#list=wrong` | 单页六页签。`#view=drill` 进入错题回炉，`#list=wrong` 只练做错过的题，`#view=paper` 进「原卷重做」；非法值静默回 `diag` |
| 化学闪练卡 | `#view=today\|wrong\|report`、`#view=mod&m=<单元id>&k=<题型id>` | 独立单文件。12 单元 id：`intro/air/struct/water/eq/carbon/fuel/metal/sol/ab/salt/life`；`mod` 带 `m` 打开单元页，带 `k` 直接按题型练；`wrong` 进错题库，`report` 进报告。非法值静默回 `today`；带 hash 进入不恢复上次练习位置 |
| 语文 | `#view=diag\|method\|drill\|essay\|doc`、`#list=wrong`、`#tag=<考点>` | 单页五页签（诊断／框架／闪练／作文逐段批改／怎么用）。`#list=wrong` 只练错过的题，`#tag=字音` 之类按考点筛；非法值静默回 `diag` |
| 数学 | `#view=task\|drill\|paper\|report\|library` | `task` = 直接开始本次任务第一项 |
| 坐标图象 | `#lv=L1\|L2\|L3\|L4\|L5`、`#lv=line\|para` | 五层闯关：找点／读点／一次函数／二次函数／综合。`line`、`para` 是两个滑块探索区（不判分）。非法值回首页 |
| 数学训练 | `#view=today\|write\|entry\|drill\|report` | 三个训练模块（基础快练／写解析式／大题前两步，顺序与页签一致）+ 报告。`write`/`entry`/`drill` 打开模块页（题型列表 + 例题 + 开始一轮），`report` 打开报告；非法值回今日 |
| 数学错题 | `#view=today\|list\|practice\|report\|doc`、`#list=wrong`、`#id=p01` | 单页五页签（今日复习／错题列表／重做／报告／说明）。`#view=practice` 直接开始今日复习，`#list=wrong` 只练做错过的题，`#id=` 直接打开某题；非法值回今日 |
| 英语过关 | `#view=practice\|review`、`#mode=drill\|exam`、`#unit=U1..U4` | 一题一屏。`drill`（默认，选中后提交即判分）/ `exam`（交卷后才给答案与解析）。旧值别名：`#view=mistakes`、`#view=wrong` → 复盘·错题；`#view=report` → 复盘·原卷批改；`#view=fills` → 做题；`#layout=one` 静默忽略。也认 `#unit=1`/`#unit=unit1` 与 `#v=`/`#u=` 缩写；`tab=wrong\|paper` 可直接选复盘的 tab（`#view=review&tab=paper` 等价 `#view=report`） |
| 英语语法闪练 | `#block=1..5`、`#view=drill\|result`、`#list=wrong`、`#view=doc&doc=card\|pair\|plan\|guide` | 点选即判（无提交按钮）。**有进行中的本轮时，`#block` / `#view=drill` 都会被"接着上次"接管**（刷新不清进度）；`#list=wrong` 是明确指令，会覆盖本轮；`doc` 打开页内文档（口诀卡 / 最小对立对卡 / 今晚复习方案 / 使用说明） |
| 英语单词闪练卡 | `#view=today\|random\|wrong\|report` | 四视图（今日选题 / 随机练习 / 错题本 / 报告），今日页内做来源→年级册→单元级联与三方向开练（英→中/中→英/音→中）。非法值回今日 |

约定：
- 只在**启动时**读一次 hash；运行中切模式不回写 hash（地址栏稳定、刷新按 hash 重进）。
- 非法值按 key 独立静默忽略、回默认（`#mode=xxx` → 默认模式，不报错）。
- 从深链进入**不恢复上次练习位置**（否则停不到第一题），但离开时照常写续练会话。
  **例外**：英语语法闪练有意为之——刷新/带 hash 重进都会接着上次那一题（`current` 快照），
  因为"刷新丢进度"是它上线后被投诉过的第一个问题；要换组先按「退出」。

改契约要同步改三处：各科读取逻辑、`开始.html` 的 `SUBJECTS[].quick/wrong`、本文档。

**新增卡片**（`开始.html` 的 `SUBJECTS`）时，还要在 `GROUP_OF` 里给它指定分组（语文/数学/英语/物理/化学/历史/道德与法治/公式记背），
否则会落到「其他」组；组标题的先后由 `GROUP_ORDER` 决定。分组只影响入口页的排版，不影响深链与记录。

## 三、备份格式

「备份全部记录」把上表的原始 store 原样打进一个文件：

```json
{
  "schema": "lt.practice-records/1",
  "kind": "backup",
  "exportedAt": "2026-11-04T07:00:00.000Z",
  "apps": { "kss_v1_历史": { "cards": {}, "days": {}, "paper": {} }, "...": {} }
}
```

- 文件名 `全部记录-YYYY-MM-DD.json`，放进仓库根 `学习记录/`。
- 训练台（`工具/dsh-plugin/records.js` 的 `expandBackup()`）会把它拆成各科记录，走和各科导出完全相同的解析与「同工具只取最新」去重。
- 加一科记录要改 `RECORD_KEYS`（开始.html）和 `BACKUP_APPS`（records.js），并在 `selfcheck.mjs` 的备份用例里加一行。
  现状：`chemScaffold.v1`、`ywScaffold.v1` 已进 `RECORD_KEYS`（备份文件里有），但 `BACKUP_APPS` 尚未接解析，
  所以训练台面板里看不到化学与语文的统计——补的时候在这两处一起加，别只加一边。
  `mathwrong_v1`（数学错题本，2026-11-13 新增）同样只在 `RECORD_KEYS`，`BACKUP_APPS` 尚未接；训练台面板暂不显示它。

## 四、发布

`开始.html` 由站点仓库（`ataotao.github.io`）的 `tools\publish.ps1` 以**改名**方式发布成 `1/index.html`：

```powershell
cd <站点仓库>
.\tools\publish.ps1 -DryRun -Prune      # 先看会改什么
.\tools\publish.ps1 -Prune -Commit -Push
```

**家里和公司两台电脑的路径不同**，脚本里不写死绝对路径。解析顺序：

1. 命令行 `-TrainingRoot` / `-VocabRoot`（临时）
2. 本机配置 `tools\publish.local.json`（已 gitignore，可用 `machines` 按 `COMPUTERNAME` 分机器）
3. 环境变量 `LEARNING_TRAINING_ROOT` / `LEARN_ENGLISH_DIST`
4. 自动探测（仓库父目录、用户目录、`C:\learn`、`C:\work`、`D:\...` 往下两层找）

换机器后第一次跑：`.\tools\publish.ps1 -TrainingRoot <训练仓库> -VocabRoot <vocab-app\dist> -WriteConfig`，之后免参数。详见站点仓库 `tools\README.md` 的「多台电脑」一节。找不到源目录时脚本会列出尝试过的位置并以退出码 1 结束。

- 同步的范围：`开始.html`（→ `1/index.html`）+ 各科训练器 + 英语过关练习 + **英语语法闪练**（单文件，题库与说明文档都已内联）+ 数学急救包 + 物理/历史配图。清单在站点仓库 `tools/publish.ps1` 的 `$Jobs[training].Items`：**新增一个训练器必须同时把它加进那份清单**，否则站点上点开就是 404（本次语法闪练就是新增的一条）。
- 发布脚本不做构建：改完训练器/入口页要先在各自仓库构建、跑自检，再发布。
- 日常只发训练侧时可加 `-Only training`，避免把 vocab 的无关构建产物一起带进提交。
- 网页版入口页不读本地记录，看不到「今天做什么」与备份按钮，这是设计（`body.web` 时隐藏 `.file-only`）。
