## 一、目标

四件事一起做，让「今日任务」从「每次点开始随机出一批题」变成**有规则、当天固定、可复现**的题单，并补上写全式与因式分解两块短板。

可观察判据：

1. 同一天打开页面两次，「今日任务」四段的题**完全相同**（题干逐字相同）；换一天则不同。
2. 今日任务卡上能直接看到**今天的配比**（如「顶点式 2 · 线段 4 · 分段 2」）和**规则说明**。
3. 「写解析式 → 顶点式」的答案里有**完整解析式** `y = a(x − h)² + k` 三个空，不再是只填 `a =`。
4. 基础快练里有**因式分解（十字相乘）**题型。
5. `gen(mod, null, seed)` 真正**随机混抽**题型（原来永远命中第一类）。
6. `node 数学/题库工具/check-training.mjs` 退出码 0。

## 三、现状（锚点）

- 核心层：`数学训练脚手架.html:168` 起（`<script id="core">`），`gen` 在 `:848`，`judge` 在 `:867`，`ansText` 在 `:883`，`selfTest` 在 `:1029`
- 出题器 bug：`gen` 里 `if (!kindId || m.kinds[i].id === kindId) break` → `kindId` 为 null 时永远取**第一类**；记录里 8 题写解析式全是 `vertex`、2 题基础快练全是 `eq`
- UI 层：`renderToday` 在 `:1143`，`startSession` 在 `:1264`，`nextQuestion` 在 `:1293`，字段渲染在 `:1370`，`readDraft`/`submit` 在 `:1562`/`:1583`
- 今日任务卡现在：`META` 里写死「6 题 / 8 题 / 3 题」，开始按钮调 `startSession(mod,null,n)` → 每题现场随机

## 四、方案

1. **修混抽**：`gen` 里先判断 `kindId`，命中才 break；否则按种子随机取一类。
2. **加题型**：`genFactor`（十字相乘，`set` 两空，顺序不限）进 `drill.kinds` 首位。
3. **写全式**：新增字段类型 `expr`（模板 `y = {}(x − {})² + {}`，三个空），顶点式改成「写全式 + 求另一点 y」；线段解析式同样改成 `y = {}x + {}` + 求值。`judge`/`ansText`/`selfTest`/UI 渲染/订正同步支持。
4. **今日任务规则**（核心层纯函数，可单测）：
   - `daySeed(key)`：`YYYY-M-D` 的 FNV-1a 哈希
   - `planForDay(key, weakKind)`：返回当天配比 —— 基础快练 6 = 因式分解 2 + 解方程 2 + 轮换 2；写解析式 8 = 顶点式 2 + 主力 4 + 次主力 2；大题前两步 3；错题回炉按到期
   - 主力按 5 类轮换（顶点式→反比例→线段→分段→利润），`seed % 5` 取；最近 8 条写解析式记录里有错题 → 主力换成错题那一类（弱项覆盖）
   - `dailyQueue(mod, plan)`：按 plan 生成当天固定题单（同种子同题，题内去重）
5. **UI**：`renderToday` 用 `planForDay` 出卡，显示配比 + 规则卡；开始按钮走 `startDaily`（用 `dailyQueue` 预生成队列）；模块页每类按钮改「专项 10 题」。

## 七、第二轮（2026-11-13）：交点式 + 题单快照

1. **交点式题型**（`write.intercept`，`数学训练脚手架.html:275` 起）：
   - 题干给两个 x 轴交点 + 一个点，先做一道**选择题**「先设哪种形式？」（顶点式 / 交点式 / 一般式），
     再写 `y = [a](x − [x₁])(x − [x₂])` 三个空 —— 这样「选形式」本身也被判分。
   - 登记进写解析式（6 类），并进主力轮换：`WRITE_ROT` 变 6 类，**六天一轮**全覆盖；
     页面规则卡、`每日20分钟-执行卡.md`、`check-training.mjs` 的轮换断言同步改成 6。
   - `exprText` 增加 `intercept` 形式（反馈里拼回 `y = 2(x − 1)(x + 3)`）。
2. **当日题单快照**：
   - `DB.days = { 'YYYY-M-D': { qs: [{mod, kind, kn, p, a, ok, sec, t}] } }`，每次 `submit` 追加一条

   - 「报告」页新增**「题单快照（最近 14 天）」**卡：按天倒序列出当天做过的每道题、对错、用时。

## 附：已知边界

- `expr` 是「模板 + 数字空」，不是自由表达式解析；负数直接带负号填（`+ −3` 显示为 `+ -3`，判分正确）。
- 今日题单只保证「同一天固定」与「同一套内不重复」；跨天不保证不重复（种子不同，实际很少撞）。
- 跳过几天不累计欠账；错题回炉仍按 1/3/7/14 天到期。
