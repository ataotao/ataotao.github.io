# 数学闪练卡：板块随机题练习 + 专项 3 题（2026-11-20）

## 目标

1. 「基础快练」按页面分组（方程与代数 / 二次函数 / 反比例函数 / 圆 / 直线与圆 / 图形与变换 / 推理与证明）各加一个「当前板块随机题练习」：题数由该板块题型数决定，每种题型出 1~2 题，题型全覆盖。
2. 「写解析式」目前没有分组：按整页作为一个板块加同样按钮；实现上沿用同一分组抽象，未来加 group 后自动变成按组按钮，无需改逻辑。
3. 「专项 10 题」→「专项 3 题」，按钮文案、调用题量、注释、用户文档同步。

## 改源（产物不手改）

- `数学/源/train.ui.js`：模块页按钮、`startGroupRandom()`、总结页「再来一轮」复用本轮队列、`__mt` 钩子。
- `数学/源/train.css`：`gsec` 内按钮对齐。
- `数学/题库工具/smoke-ui.mjs`：冒烟断言（专项 3 题 / 板块随机覆盖与题量 / 重来）。
- `数学/每日20分钟-执行卡.md`：用户可见文案。

## 行为约定

- 随机队列：每种题型先保证 1 题，再以 50% 概率加 1 题；洗牌后生成；同一板块总题数 N~2N（N=该板块题型数）。
- 同一板块内同一题型的两次出现尽量不出现相同题干（换 seed 重试）。
- 随机练习不写 `daily:true`，不计入今日任务打勾（和专项练习一致）。
- 总结页「再来一轮」必须重放同一板块的随机规则，而不是退化为按 `s.total` 现场混抽。
