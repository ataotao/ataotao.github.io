## 四、方案

| 卡片 | 补的内容 |
| --- | --- |
| 读数 | `voltmeter` 电压表读数（0~3 V / 0~15 V，30 小格，分度值 0.1 / 0.5 V）+ `svgMeterDial` 通用表盘（`svgAmmeter`/`svgVoltmeter` 共用） |
| 作图判断 | `draw.wire.3` 电压表接法（4 张电路图，串联底图：并在 L₁ ✓ / 串进电路 / 并在电源 / 并在 L₂） |
| 认模型 | `meter` 电压表测哪段 / 使用规则 / 量程选择 |
| 认量 | `seriesI` 串联电流处处相等、`parallelU` 并联各支路电压相等 |
| 算到底 | `seriesU` 串联分压（U总=U₁+U₂）、`parallelI` 并联分流（I总=I₁+I₂） |

电路图新增 `connect-voltmeterSL1 / Sloop / Sbattery / SL2` 四个变体（串联底图，避免并联时各电压相等导致答案不唯一），共用 `voltmeter(x,y)` 符号。
