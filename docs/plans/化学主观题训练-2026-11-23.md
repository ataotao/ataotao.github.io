# 化学主观题训练：从「看答案」到「对要素」

- 状态：已实施（2026-11-23）
- 对象：`化学/化学思维脚手架.html` ③ 题型模板 / ⑥ 原卷重做
- 前置：`化学基础保分评估-2026-11-23.md`（结论是「闪练卡能保客观题、保不住主观题」）
- 结论一句话：**主观题不是知识点缺口，是「答案产出」缺口；训练要落在「每个空必须写到哪几个要素」和「错因归类」上，不在加大题量。**

---

## 一、为什么改的方向是「要素」而不是「多刷题」

本次期中 5 道大题 **34 个空，错 27 空**，空均分 1.06 分。逐空看，绝大多数不是「完全不会」，而是：

| 错型 | 原答 | 该答 |
| --- | --- | --- |
| 问名称答用途 | 「通过分液漏斗控制」 | 「量筒」 |
| 问方法答变化类型 | 「物理变化」 | 「蒸馏」 |
| 问微观答现象 | 「分子在不停降温」 | 「分子间隔变大」 |
| 问原因答孤证 | 「分子在运动」 | 「燃烧放热→温度升高→气体膨胀，压强增大」 |
| 只写一段趋势 | 「增大走势」 | 「先升、后降、再回升」 |
| 化学式漏金属 | 「PO₄」 | 「Na₃PO₄」 |
| 方程式缺三件 | 「H₂O₂ H₂O₂」 | 「2H₂O₂ —MnO₂→ 2H₂O + O₂↑」 |

这些错有共同点：**答案的「骨架」不对，不是「内容」不知道**。所以训练要给出骨架。

## 二、三层训练法

| 层 | 载体 | 做法 |
| --- | --- | --- |
| ① 答题要素 | ③ 页「十条答题要素」 | 认问法 → 对「必须写到」→ 对「你的原答 / 该有的样子」 |
| ② 逐空自检 | ⑥ 页长填空 | 写完先勾采分点，勾不全再看答案；缺的要素标红 |
| ③ 错因复盘 | ③ 页底部 | 27 个错空各标一个错因，标满 5 个自动出结论 |

工具之外的两件事（不可替代）：
- 每天 10 分钟**手写**「五写」（5 化学式 + 2 方程式 + 3 现象 + 2 原因句）——`PO₄` 漏金属这类错只在手写时暴露。
- 每周 60 分钟**整卷限时重做**——练节奏，不练知识。

## 三、十条答题要素

| 问法 | 必须写到 | 他的原答 | 该有的样子 |
| --- | --- | --- | --- |
| 原因类 | 两段式「因为…所以…」，缺一段扣 | 分子在运动 | 燃烧放热→温度升高→气体膨胀，压强增大 |
| 作用类 | 写全 2–3 件事：吸收什么、防止什么、帮助什么 | 分子在不停降温 | 吸收 P₂O₅ 白烟、防止污染、降温助冷 |
| 微观解释 | 点到分子/原子，并指明「间隔/运动/种类/构成」哪个变了 | 物理变化 | 分子间隔变大，分子本身没变 |
| 名称类 | 只写名称，不写用途、不写变化类型 | 通过分液漏斗控制 | 量筒 |
| 趋势描述 | 按时间分段，用「先…后…再…」 | 增大走势 | 先升、后降、再回升 |
| 化学式 | 正价在前 + 酸根在后 + 交叉配平 + 查脚标 | PO₄ | Na₃PO₄ |
| 化学方程式 | 四件套：配平、条件、↑↓、化学式 | H₂O₂ H₂O₂ | 2H₂O₂ —MnO₂→ 2H₂O + O₂↑ |
| 控制变量与条件 | 说「只变了什么」，答「变的那一项」；条件要写全（谁＋多少） | 催化剂 | 过氧化氢溶液的浓度 |
| 判断 + 理由 | 两问问两答：先标号，再判据 | 选 C，理由写「二氧化锰」 | D，反应物里没有碳元素 |
| 画图（微观） | 先数原子总数，再画分子，只画要求的那一侧 | 已画，看不出对不对 | 反应前画 3 个 O₂，每个 2 个氧原子 |

## 四、实现改动

### 数据（`化学/题库/2026-2027期中卷.json`）

16 个长填空各加两个字段，其余 18 个短空不动：

```json
"pts": ["起点是「燃烧放热」", "中间是「温度升高」", "落到「气体膨胀 → 压强增大」"],
"qt": "原因类"
```

`pts` = 采分点（2–4 条，可勾选的自检项，不给结论本身）；`qt` = 问法类型，供复盘分组。
用一次性脚本按 `"k"` 锚点插入，未重排 JSON，diff 恰好 16 行。

### 渲染（`化学/源/shell.html`）

- `emptyAns()` 增加 `pts: {}`，`qState()` 对旧记录做 `st.pts = st.pts || {}` 兜底（向后兼容）
- ⑥ 页长填空：textarea 下插入采分点勾选组，勾选数实时显示；点开答案后**未勾的要素标红**
- 按钮文案带进度：`看答案自评（要素 1/3）`
- ③ 页新增两块：十条要素表（窄屏自动转卡片式）+ 错空复盘（27 空 × 六类错因）
- 复盘统计实时更新，标满 5 个给出结论：最大类不是「不知道」就提示「别再加刷题量」
- 新增深链 `#view=paper&no=17` 直接落到某题

### 本机存储

- 采分点勾选：随原卷作答一起存在 `PS`（`chemScaffold.paper.v1` 那一份），刷新可续
- 错因标记：单独 key `chemScaffold.err.v1`，**不进训练统计面板**（避免把自评当分数）

## 六、未做（有意留白）

- **不给主观题自动打分**：表述多样，关键词判分误判率高，判错比不判更伤信任。只用「勾了几条要素」提示，不当分数。
- **错因不进统计面板**：自评覆盖率不是成绩，只看趋势。
- **没有做全科通用**：这套（采分点 + 错因）目前只落在化学这份卷子；若验证有效，再按 `docs/plans/主观题训练方案.md` 的 A 方案推到历史/道法。
