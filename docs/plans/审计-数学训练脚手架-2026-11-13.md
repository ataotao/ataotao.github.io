## 1. 结论摘要

- **能确认**：出题/判分核心层、今日题单纯函数、题单快照三条链路 `check-training` 与 `smoke-ui` 全绿；11-12 卡与 11-13 卡（含第二轮）的可观察判据**大部分已实现**，`expr` 写全式、交点式、`DB.days` 快照、14 天裁剪、报告快照卡都在。
- **能确认（有 bug）**：交互层有 **2 个 P0、6 个 P1**——最重的是 **`expr` 判分按空位排序比较，a/h/k 填错位置仍判对**（核心判分错误），以及 **「看完例题 → 错题回炉」会把例题当题目显示、点「看懂了」直接抛 `未知模块 wrong`**（回炉入口不可用）。另有**空提交判错进错题本**、**点选项/草稿纸清空已填数字**、**例题页按回车写进一条 `sec≈56 年` 的假记录**。
- **能确认（规格缺口）**：①「同一天题单逐字相同」被「弱项覆盖」破坏——当天答错一题后再开今日任务，题单就变；②规则卡/执行卡的 6 类轮换**顺序与实现不一致**；③`second === vertex` 的日子（如 2026-11-14）配比文案写「顶点式 2」实际队列是 4 题顶点式。
- **不能确认**：真浏览器下的渲染/触摸/下载行为（Chrome 在沙箱起不来）、手机窄屏表现、`file://` 下 Blob 下载与 `input.click()` 选文件；这些只做了代码级推断。
- 证据命令与关键输出见 §6；自检覆盖缺口见 §5（最关键是 `smoke-ui.mjs` 的 DOM 桩 `addEventListener` 是空函数，**所有点击路径都没被冒烟覆盖**）。

### 3.4 今日题单生成链（11-13 卡核心）

```
today() 1266 → daySeed(key) 1164-1168 (FNV-1a)
            → planForDay(key, weakKind()) 1182-1201
                 main = weakKind || rot[dayIndex(key) % 6]   // 1187
                 second = rot[(main+1) % 6]                   // 1188
                 drill.kinds = [factor,factor,eq,eq,extra,extra]        // 1193
                 write.kinds = [vertex,vertex,main×4,second×2]          // 1194
            → dailyQueue(mod, plan) 1207-1230

                 其它：i 从 0..n-1，seed=plan.seed+i*7919+guard*104729 逐题 gen，qKey 去重（最多重试 12 次）
            → startDaily 1461-1469 预生成队列 → nextQuestion 逐题
```

- 同一 `key + plan` 必然同一套 ✓（纯函数，无 `Math.random`）；**但 plan 里的 `main` 依赖 `weakKind()`，而 `weakKind()` 读当天记录** → 当天可变（B06）。
- `dayIndex` 1178-1181 用 `Date.UTC(y,m-1,d)/86400000`，跨时区稳定 ✓；7 天 seed 实测互不相同 ✓。

## 5. 现有自检没覆盖到的路径

**先说根因**：`smoke-ui.mjs` 的 DOM 桩里 `addEventListener() {}`（`smoke-ui.mjs:34`）是空函数——**所有 `click`/`keydown` 事件都不会触发**。它只验证「渲染出什么文本」和直接调用 `__mt.submit/startDaily`，所以本报告里 90% 的交互 bug 它都看不见。`check-training.mjs` 只抽 `<script id="core">`，完全不碰 UI 层。

`smoke-ui.mjs` 未覆盖（按用户路径分类）：

1. **所有点击路径**：页签切换、今日卡「开始/再来」、模块卡「开始/看例题」、专项 10 题、提交/提示/订正/下一题/草稿纸、报告「回炉/导出/导入/自检/清空」、总结「再来一轮」。
2. **键盘**：回车提交、回车订正、回车下一题、例题页回车（B03）。
3. **hash 路由**：桩里 `location.hash=''` 固定，没测 `#view=write|report|drill|entry|today`、非法值、刷新重进、前进后退（前进后退按契约不实现，但应断言「不写 hash」）。
4. **空/异常输入**：空提交（B05）、只填部分空、全角数字、`1.428e6`、`3/0`、`-`、纯空格。
5. **判分边界**：`expr` 空位乱序（B01）——`selfTest` 的错解是「每个答案 +1」，排序后仍不同，抓不到换位错。
6. **今日题单稳定性**：只比较同参数两次（`check-training.mjs:76-84`），没测「当天答错后 weakKind 变化」导致换题（B06）；也没测「当天已做过一部分，再开今日是否仍是同一套」。
7. **弱项覆盖的负例**：没测「weakKind 恰好是 vertex 时配比文案与实际队列是否一致」（B08）。
8. **状态泄漏**：看完例题 → 回炉（B02）、`S.scratch` 跨题（B23）、`S.mode` 残留（B03）。
9. **错题本全生命周期**：`addWrong` 的 due 1/3/7/14 推进、`n` 累加、同一题重复进本、回炉答对移出、回炉题 `fig`（B13/B14）、未到期时的 alert。
10. **`DB.days`**：14 天裁剪（含单/双位数日排序，B10）、跨零点（B26）、导入后的天数裁剪。
11. **导入/导出**：坏 JSON、`v` 不匹配（B19）、重复导入（B17）、导出文件名/Blob（桩里没有 `Blob`/`URL`）、`FileReader`。
12. **清空**：清空后报告/今日/模块页是否复位、错题本是否清空、`S` 是否残留。
13. **存储异常**：`setItem` 抛错（B18）、`getItem` 返回坏 JSON（B19）、隐私模式。
14. **计时器**：`sec` 的合理区间（B03 的 56 年就是没有断言）、`summary` 用时、跨题计时。
15. **窄屏/样式**：`.expr-slot` 无宽度导致三空换行（B24）；`.input`/`.bar` 死样式。
16. **报告空态**：空记录时各卡片（空态代码 1942/1966/1984 存在，但没有断言）。
17. **`selfTest` 自身**：没断言「答案有限小数」（11-12 验收 11）、没断言 `expr` 模板空数与 `ans` 一致以外的语义、没断言选项无重复。
