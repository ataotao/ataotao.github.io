## 2. 环境陷阱（全部实测踩过，别再踩）

| 现象 | 原因 | 处理 |
|---|---|---|
| 1 | 写文件报 `Permission denied`，但 `icacls` 显示 `Authenticated Users:(M)` | DSH 沙箱命令跑在 **Low 完整性**，目录没有 Low 标签就不能写（比 ACL 更常见的隐藏原因） | 以**管理员** PowerShell 跑：`icacls "<目录>" /setintegritylevel "(OI)(CI)L" /T /C /Q`。期望"0 个失败" |
| 1b | 标签已打好、仍写不进 | 不是权限问题，是**执行方沙箱只允许写会话工作区**（目标仓在工作区之外） | 把目标仓设为会话工作区，或对该条命令提升沙箱权限（本条只在目标仓位于工作区外时需要） |
| 2 | `git ls-remote` 报 `cannot spawn ssh: No such file or directory` | `ssh.exe` 在 `C:\Windows\System32\OpenSSH\`，不在 PATH | `export PATH="/c/Windows/System32/OpenSSH:$PATH"` |
| 3 | node 脚本里 `spawnSync git EPERM` | 沙箱默认**禁止孙进程**（node→git 是第二层） | 跑构建/校验类命令时提升沙箱权限（`danger-full-access`），或在没有该限制的环境里跑 |
| 4 | 工作树出现整文件 diff（如某个 HTML 改 6000 行） | 工具把文件写成 CRLF，git 存的是 LF | 仓库已有 `.gitattributes`（`* text=auto eol=lf`）；`git add` 后假 diff 自动消失。**不要**手工改行尾 |
| 5 | 站点仓 28 个文件显示已修改 | 上一轮 `publish.ps1` 复制产物时写入 CRLF；内容零差异 | Phase 1 用 `git checkout -- .` 丢弃，**不要**提交 |

### 附录 A · `工具/assemble-site.sh`

> 这是把旧 `publish.ps1` 的白名单**逐条翻译**的结果。清单是白名单：

```bash
#!/usr/bin/env bash
# 组装站点到 _site/。白名单来自退役的 tools/publish.ps1（$Jobs 表）。
set -euo pipefail
cd "$(dirname "$0")/.."
OUT="${1:-_site}"

pub() {  # pub <源> <目标相对1/的路径>

  mkdir -p "$OUT/1/$(dirname "$2")"

# ---------- 目录型资源（按扩展名筛选） ----------
copydir() {  # copydir <源目录> <目标相对1/的路径> <扩展名>
  local src="$1" dst="$OUT/1/$2" ext="$3" n=0
  [ -d "$src" ] || { echo "缺失源目录：$src" >&2; exit 1; }
  while IFS= read -r -d '' f; do
    mkdir -p "$dst/$(dirname "${f#"$src"/}")"
    cp "$f" "$dst/${f#"$src"/}"
    n=$((n+1))
  done < <(find "$src" -type f -name "*$ext" -print0)
  echo "  $2: $n 个 $ext"
  [ "$n" -gt 0 ] || { echo "目录里没有 $ext：$src" >&2; exit 1; }
}
```

### 附录 B · `.github/workflows/deploy.yml`

```yaml
name: 构建并发布站点
on:
  push:
    branches: [master]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: false
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
          cache-dependency-path: apps/english/package-lock.json
      - uses: actions/setup-python@v5
        with:
          python-version: '3.x'
      - name: 英语工程
        working-directory: apps/english
        run: npm ci && npm run build
      - name: 校验（任一红即不发布，禁止加 continue-on-error）
        run: |
          node 物理/题库工具/check-training.mjs
          node 数学/题库工具/check-training.mjs
          node 化学/题库工具/check-flash.mjs
          node 工具/dsh-plugin/selfcheck.mjs
          python 数学/题库工具/qb.py verify
          node 工具/parity.mjs
          node 工具/check-size.mjs
      - name: 组装站点
        run: bash 工具/assemble-site.sh _site
      - uses: actions/upload-pages-artifact@v3
        with:
          path: _site
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```
