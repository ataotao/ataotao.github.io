# 任务卡：语法闪练 · 答后译文 + 悬停词义（2026-11-10）

## 目标（用户口径）

1. **答完题**（选过选项 / 看过答案）后，在英文题干**下方**显示整句中文译文。
2. **没答题之前**，鼠标滑过题干里的**单词或短语**，显示该词/短语的中文释义；不影响做题（不能靠悬停泄露答案）。

## 已确认事实

- 源：`英语/语法闪练/index.html`（引擎）+ `data/g*.json`（题库）；产物：`data/bundle.js`、`英语/语法闪练.html`、`考点识别速查表.html`。
  **产物不手改**，改源后 `node 英语/语法闪练/build.mjs`（ADR-0003）。
- 题库共 170 题（g1-clause 38 / g2-verb 38 / g3-word 50 / g4-gz 20 / g5-verbform 24）。
- `cn` 字段原本只有 g5 有（旧译文），且是**打开就显示**；本卡改成「答完才显示」。
- 词表无法在运行时生成（离线单文件），必须入库为数据。

## 数据契约（SCHEMA.md 同步更新）

- `item.cn: string`：整句中文译文，按正确选项补全后翻译（不留空位）。答完显示；未答只悬停看词。
- `item.gloss?: { "题干里实际有的词/短语": "语境中文" }`：只写语境义覆盖（全局词表兜底），键按题干实际词形、大小写不敏感。
- 新增 `data/glossary.json`：`{ "words": {词形: 中文}, "phrases": {短语: 中文} }`，覆盖题干全部词形；短语键 = 题干里实际出现的连续词形。
- build 校验：cn 必填（缺 → 警告，`--strict` → 错误）；gloss 键必须能在题干里逐词匹配；**悬停覆盖率**按词统计并打印，未覆盖词会点名。

## 已知取舍 / 不做的事

- 悬停**不显示空格的答案**（否则等于泄题）；译文只在答完/看答案后出现。
- 不填充题干空格、不改判分/记录格式、不改深链契约。
- 译文中英混排用中文标点；专有名词用通行译名。
- 移动端没有鼠标：点一下单词也能出词义浮层（顺手支持），不影响点选项。
