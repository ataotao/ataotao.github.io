## 一、目标

今天化学闪练卡错题库暴露两处关键缺口：①方程式配平（`eq.balance` 连错 2 题：Fe₃O₄+CO、KClO₃）；②化学用语——看到元素名称/离子名称写不出符号，无法对应周期表里的元素，导致「已知反应物求生成物」这类题第一步就卡死。

可观察判据：专项页有 3 个模块 15 类题型；`selfTest(200)` 0 失败；新增记录键不污染 `chemflash_v1`；开始页与线上白名单都能进；共享错题回炉段逐字节一致。

## 三、现状与调研结论

- 错题库 `化学闪练卡记录.json`：`eq.balance` 两题全错（Fe₃O₄+___CO→3Fe+4CO₂ 应填 4；2KClO₃→2KCl+___O₂ 应填 3），`eq.eqcalc` 两题全错；截图是「已知反应物求生成物」的 7.9g KMnO₄ 计算题。
- 现有闪练卡有 `symbol`/`ion`/`valence` 零散题型，但**没有**「名称↔符号↔周期表信息」的对应训练，也没有方法化的配平训练（tip 只列方法名，解析不说步骤）。
- 调研可靠做法（多来源一致）：配平先固定动作顺序——最小公倍数法（左/右各出现一次、原子数不同，初中最多）、观察法（复杂物质内部比例反推）、奇数配偶法（一奇一偶先配 2）、定一法（含 C/H/O 燃烧，分数最后化整），收尾必查「原子数 / 最简比 / 条件与↑↓」。化学用语用分散记忆 + 闪卡 + 口诀 + 对比书写（化合价正上方、离子右上角，1 的写法相反），并在题目里应用巩固。

## 四、方案

1. 新建 flash 族科目「化学专项」：core 全局 `CF`、记录键 `chemfocus_v1`、深链 `#view=mod&m=<模块>&k=<题型>`，走 `kernel.js` 同一套壳/记录/回炉。
2. 3 模块 15 题型：
   - ① 化学用语地基：`symbol`（符号→名称四选一）、`name`（名称→符号，大小写敏感判分）、`period`（周期表小格：原子序数 / 相对原子质量 / 元素身份）、`ion`（名称→离子符号）、`ionrule`（离子/化合价写法辨析）。
     顺序按认知坡度排：先认元素符号 → 再写元素符号 → 周期表判读（认元素身份 + 相对原子质量，为模块③计算铺路）→ 离子符号书写 → 离子/化合价写法辨析。2026-11-23 由 `ion → ionrule → period` 调整；`kind id` 与 `prompt` 未变，错题键与历史记录不受影响。
   - ② 配平四法：`lcm` / `odd` / `observe` / `setone`（按方法出系数填空，解析写完整步骤）、`method`（按方程式选方法）、`check`（最简比 / 原子数 / 系数 1 的自检）。
   - ③ 写方程式与计算：`write`（由反应物推生成物，含截图的高锰酸钾）、`writeout`（默写生成物化学式，文本输入，「不会写」必须真写）、`calc`（按相对质量比算质量，含今天两道错题）、`massrel`（相对质量对应关系，防「实际质量错位」）。
3. 接入：开始.html 加卡/分组/记录键/统计/默认任务 → assemble-site.sh 加 pub → parity 加目标 → 全部验收命令跑通。
