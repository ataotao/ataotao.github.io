## 一、目标

做一个**独立于化学脚手架**的入口页，把人教版初三化学（九上 + 九下）全部考点做成可反复练的闪练卡：题库随机生成、选择点选即判 / 填空输入判分、**答案解析说明考点与难点**、错题库按 1/3/7/14 天回炉。

可观察判据：`node 化学/题库工具/check-flash.mjs` 退出码 0（12 单元 / 53 类题型，每类 200 题共 10600 题无坏题）；Chrome 无头交互冒烟 28 项全 PASS、0 console error。

## 三、现状（锚点）

- 数学 / 物理的同类做法：`物理/物理训练脚手架.html` 的 `<script id="core">`（mulberry32 + `gen*()` 生成器 + `judge()`）与 `<script id="ui">`，自检 `物理/题库工具/check-training.mjs`；本页沿用同一分工，便于复用自检思路。
- 化学脚手架已有 25 题固定闪练（本次期中卷失分点），覆盖面有限；新页做**全考点 + 随机生成**补足。
- 深链：物理训练等用 `#view=...`；本页只用 `#view=today|wrong|report` 与 `#view=mod&m=<id>&k=<题型>`，启动时读一次 hash，运行中切视图回写但不重进。

## 四、方案

1. **数据层**（core）：12 单元 × 53 类题型，每类一个 `gen(r)`；字段三类——`choice`（选项 + 下标）、`num`（数值 + 容差）、`text`（化学式 / 离子符号，全角 / 下标 / 大小写归一）。每题带 `tip`（难点）、`explain[]`（分步解析）、`kp[]`（考点标签）。
2. **出题**：`mulberry32` 可复现随机；`kindQueue()` 轮换题型、避开上次做过的类；`sigOf()` 去重避免一轮内重复题。
3. **判分与反馈**：逐字段判分、全对方为对；反馈逐条显示正确答案 / 你的答案 + 考点难点 + 分步解析 + 考点标签。
4. **错题库**：`chemflash_v1` 存 `recs[]` 与 `wrong{}`，按 1/3/7/14 天到期；答对移出；「复习到期题」与「全部错题练一遍」两个入口。
5. **存档**：做题会话存 `chemflash_v1_sess`（含题面 / 选项 / 已答状态），刷新或「继续上次练习」可续；带 hash 进入按契约不恢复位置。
