# 化学闪练卡：按 2024 新版教材补中考基础点（2026-11-23）

## 一、为什么做

上一轮只补了「微粒结构示意图」一类，且全库 12 单元对应的是 **2012 版旧教材**。
本轮调研（广州中考 2023—2026 真题、人教版 2024 新版目录、中考图形题型）发现三个问题：

1. 新版教材是 **11 单元**（上册 7 + 下册 4），原⑩酸和碱 + ⑪盐 化肥合并为「⑩ 常见的酸、碱、盐」，⑫化学与生活 → ⑪化学与社会。
2. 广州卷固定考法没实现：物质分类填汉字（连续四年）、单位只填数字、鉴别必须写现象。
3. 全库除结构示意图外**没有一张题面图形**，而广州卷每年有装置图／操作图／微观图／溶解度曲线。

## 二、四个已定决策（用户 2026-11-23 确认）

| 决策 | 结论 |
|---|---|
| 单元结构 | 改 11 单元；`salt` 走别名映射到 `ab`，旧错题键不错位 |
| 图形范围 | 先做 4 类高频：操作图、装置图、微观粒子图、溶解度曲线 |
| 方程式口径 | 统一「化学方程式」（配平、条件、↑↓），不写符号表达式 |
| 题型边界 | 「鉴别／除杂／方案评价」算基础题，要补 |

## 六、本轮修掉的四个真 bug

1. **微观图反应箭头消失**：`esc()` 先把 `>` 转成 `&gt;`，占位符内容被污染 → 在回调里还原实体。
2. **曲线轴标题压住刻度**：`S_TXT` 与追加的 `text-anchor` 重复，浏览器取第一个 `middle`。
3. **曲线刻度不是整数**：改为 5 等分 + niceStep（1/2/2.5/5/10 × 10ⁿ）。
4. **`NaNO₂` 被判成 NaN**：自检正则改 `\bNaN\b`。
