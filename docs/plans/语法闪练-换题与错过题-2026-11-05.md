# 语法闪练 · 换题与「错过题」口径（2026-11-05）

## 目标（用户反馈两条）

1. **需要支持切换其他题**：做题屏不再只能按顺序一题题走，要能切到本轮里的其他题。
2. **点「看答案」也要纳入「只刷我错过的题」**：开始屏的错过题队列从 `wrong > 0` 扩到 `wrong > 0 || peek > 0`。

## 方案

### 1. 换题（`英语/语法闪练/index.html`）

- 题卡下方加一条切题条：`‹ 上一题` ｜ `答题卡 1/20` ｜ `下一题 ›`。
- 「答题卡」弹窗按题号网格列出**本轮**所有题（134 题一轮也能滚）：未做 / 做对 / 做错 / 看答案 / 当前题五种状态，点题号跳题；题号上带 `data-id`。
- 键盘 `←` / `→` 换题（`1–4/A–D` 判题、`Enter` 下一题、`Esc` 退出不变）。
- **切换不判分、不计数、不改变正确率**；本轮进度 = 已作答（判过或看答案）的题数。
- 已作答的题切回去是**只读回看**：看到当时的选项/讲解，不能再判一次、不重复计分。
- 本轮结束条件不变：所有题都有结果（判过或看答案）后才会进重练/结算；有跳过的题时，点「下一题 →」会跳到第一道还没做的题。
- 快照 `store.current` 增加 `results`（每题 `{picked, peek, correct}`），刷新后切题状态、答题卡状态都还在；旧快照没有 `results` 时按旧逻辑恢复。

### 2. 错过题口径（同文件）

- `wrongItems()`：`s.wrong > 0 || s.peek > 0`。
- 开始屏提示改成「错过的题：N 道（做错或看过答案都算）」；空态提示同步。
- `#list=wrong` 深链同样生效。
- `stat` / 正确率口径不变：看答案只加 `peek`，不动 `att/ok/wrong`。

## 不做

- 不改结算页「重练错题」：它仍只重练本轮判错的题（本轮重练队列里已经强制包含看答案的题）。
- 不重排题库、不改 `data/`、不改 build 校验。
