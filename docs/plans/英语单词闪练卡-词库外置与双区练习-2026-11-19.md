- 状态：**已实施**（2026-11-19）
- 补充（2026-11-19 二轮）：短语题干扰项类型匹配——题干是短语时只混短语、单词只混单词，避免「长短语 vs 两字单词」结构泄题（core 的 `donorsFor`/`buildQ` + `isPhrase`）。截图案例 `pass down from generation to generation` 原干扰项含「膝；膝盖」「钱包」，修复后为 `have no choice`/`stare at`/`a set of`。
- 日期：2026-11-19

- 产物（不手改）：`英语/英语单词闪练卡.html` + `英语/词库.js`

## 一、目标

1. 词库从 HTML 抽离：产物改为「HTML（结构 + 逻辑）+ 同目录 `词库.js`（数据）」两文件，`file://` 双击仍可用。
2. 单元练习支持「整单元全词一轮」：当前单元每个词恰好出一题，不遗漏、可完整循环再来一轮。
3. 新增独立「随机练习」区域：20 / 30 / 50 词三档，从全库随机抽取；与单元练习区状态隔离、互不干扰。

## 二、范围

- 改：科目配置（新增 `dataOutFile` / `dataRef`）、`build.mjs`（有该字段时外置词库并发 `<script src>`，无字段的科目零影响）、`selfcheck.mjs`（外置契约校验）、`check-training.mjs`（从外置文件读数据 + 新用例）、`parity.mjs`（watch 加 `英语/词库.js`）、`assemble-site.sh`（两文件同目录发布）、`英语/源/train.core.js`、`英语/源/train.ui.js`、`英语/源/train.css`。
- 不改：`英语/源/train.data.js`（仍由 `extract-vocab.mjs` 生成，是词库唯一真源）、其它学科、产物手改、深链契约。
- 决策依据：`docs/adr/0009-英语单词闪练卡-词库外置与双区练习.md`（取代 ADR-0008 第 2 条的单文件约束）。

## 三、关键契约

- 外置文件必须是 **JS**（`var EW_VOCAB = …`），不能用 JSON + fetch：`file://` 下 `fetch()` 被 CORS 拦，经典 `<script src>` 可加载同目录文件。
- HTML 里 `<script src="词库.js">` 必须在 `<script id="core">` 之前；core 继续用 `typeof EW_VOCAB !== 'undefined'` 容错。
- 全单元：`genUnitAll(modId, kinds, seed)` 返回与单元词数等长的题目数组（每词一题，p2c 无音标降级 e2c），乱序不重复；`genRandom(n, seed, kinds)` 从全库去重抽 n 词。
- 双区状态：`S.sessions.unit` / `S.sessions.rand` 各自保存会话；随机区配置 `S.randCount/S.randKind` 与单元区 `S.selSource/selGrade/selUnit/selKind` 分离。session 带 `area` 与 `builder`，「再来一轮」按 builder 重建，不串区。

## 五、二轮修复（2026-11-19，评审后）

| # | 问题（实测） | 修法 |
| --- | --- | --- |
| 1 | 解析页题号/进度条提前进位：答完第 1 题显示 `2 / 10`，最后一题 `11 / 10` | `s.done++` 从 `submit()` 移到 `next()`；进度条按 `done + (answered ? 1 : 0)` 计 |
| 2 | 快练每问重新 `gen(...,10)` 只取第 1 题 → 10 题平均只 7.8 个不同词，最差 15 词单元只有 4 个 | core 新增 `genSession()`：一次建队列，同一轮词不重复，单元词不足才换乱序循环 |
| 3 | 随机「去重」按「单元×词位」：词库 281 个跨册同形词，50 词约 10% 会话出现同词两次 | `genRandom` 改走 `uniqueWordRefs()`（按 en 去重、区分大小写），超库容收敛到唯一词数 2313 |
| 4 | 全局 Enter 劫持按钮：聚焦选项按 Enter 弹「先选一个答案」；聚焦退出按 Enter 反而下一题 | keydown 只在焦点不在 button/a/input/textarea 时触发提交/下一题 |
| 5 | 文案与文档：今日页「点选即判」与实际「先选后提交」不符；缺词库提示是开发指令；深链文档缺 `random` | 文案改为「先选再提交（回车也行）」；缺词库提示改成「词库.js 与页面放同一目录」；契约表补四视图与 `random`；GLOSSARY 注明本卡是选后提交 |
