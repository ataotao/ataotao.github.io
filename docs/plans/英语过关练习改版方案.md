# 英语过关练习改版方案（一题一屏 · 两种判分时机 · 按原卷分区）

- 状态：**已实施（2026-11-04）**；实现见 commit「feat(英语): 一题一屏 + 答题卡 + 复盘（阶段②）」，验收 `qa.mjs` 69 条断言 + `build.mjs` 校验 + `check-grading.mjs` + 训练台 selfcheck 130 项
- 日期：2026-11-04
- 真源：`英语/练习工具/index.html` + `data/u*.json` / `u*.key.json` / `u*.explain.json`；产物 `英语/九上英语过关练习.html` 由 `node 英语/练习工具/build.mjs` 生成（ADR-0003：产物不手改）

## 一、为什么要改（实测证据）

1. **一张卷被劈成两个视图**：练习页只有选择题（`index.html:966-968`），填空题在「填空自测」（`1563-1605`），页脚还留一句"本页还有 N 道填空，去填空自测"（`977`）。原卷是 1–27 连号混排，"按原卷做一遍"不成立。
2. **滚动成本**：手机 390px 下 U1 整卷 5408px（≈6.4 屏）；答一题内联展开的解析块 **568px ≈ 2/3 屏**，其下所有题整体下移（`1151-1160`、`1196`）。
3. **点一下就判分且锁死**：`if (store.picks[id]) return;`（`1026`）、全部选项 `disabled`（`1189`）；唯一反悔路径「重做本题」是删记录（`1047`）。
4. **零键盘**：全文件唯一 `keydown` 是填空输入框回车（`1611`）。
5. **未答也能点「看解析」**（`1149`/`1051-1054`），答案随时可见——所以"先做完再批"在现状架构下不可能。
6. **复盘视图手机不可用**：批改报告 12529px（86 行表格，`.tablewrap{overflow:hidden}` 裁切，`325`）、错题本 10688px。
7. **原卷 4 张图 ≠ 4 张卷**：同一份材料连续 4 页，U1 跨页 1–2、U2 跨页 2–3。由此暴露 **4 处数据错误**（见 §三）。
8. **卷面无分值、无完形/阅读篇章/作文**；只有一段 U2 语法填空短文（跨页）。

## 二、目标形态

- **两种模式**（`#mode=`）：
  - `drill`（过关，默认）：一题一屏，先选后交，提交立即给四段式解析
  - `exam`（模拟考）：一题一屏，交卷前不给答案/解析，可标记不确定，一次交卷后结算 + 逐题讲评
- **一题一屏 + 答题卡 + 底部固定条**，不再有滚动长卷
- **先选后交**：点字母只是"选中"（`data-state="picked"`，CSS 早已存在，`235-236`），`提交`/`Enter` 才判分
- **记录只追加**：再答一次 = `stat.att+1` + `atList` 追加；上次答案与解析保留可对比
- **原卷对照**：作答前隐藏，提交后显示"原卷你答的是 B"；卷头与每题都可打开整页扫描图
- **复盘**：错题 + 原卷批改 合并为一个视图的两个 tab

## 三、阶段①：数据修正 + id 定稿

现状题量：U1 25 / U2 26（含 2 道外来题）/ U3 23（含 6 道错归属）/ U4 16（题号拍平）。
修正后：**U1 27 / U2 29 / U3 17 / U4 16 = 89 个答题单位（40 选择 / 49 填空）**。

| 卷 | 修正动作 | id 变化 |
|---|---|---|
| U1 | ① 第 25 题补选项（页2 首行 `A. if; whether / B. that; that / C. whether; if / D. that; whether`），答案定为 **D（that; whether）**，去掉 `doubt`；② 从 `u2.json` 搬入 `p26/p27` 作为第 26、27 题（答案与 why 已在，需补 explain）；③ 表头按卷面改：学号 `099`、姓名（卷面涂黑不可读）置 `null`、班级（字形不清）置 `null` | `U1-1`…`U1-25` **不变**；新增 `U1-26`、`U1-27` |
| U2 | ① 移出 `p26/p27`（归 U1）；② 把错记在 `u3.json` 的 6 空（旧 18–23）搬回，作为「语法填空」`gf1`–`gf6`，删掉占位 `gf11`；③ 补短文正文（唯一需要转写的内容） | `U2-m1..m13`、`U2-g1..g10` **不变**；新增 `U2-gf1..gf6`；删除 `U2-p26/p27/gf11` |
| U3 | 移除旧 18–23（→U2）；补 `section`：阅读 / 语法 | 旧 `U3-1..13` → `U3-r1..r13`；旧 `U3-14..17` → `U3-g1..g4` |
| U4 | 题量不变（16 = 13 个编号题 + 第 6 题 (1)(2)(3)）；补 `section` | 旧 `U4-1,2` → `U4-m1,m2`；`3–8` → `U4-c1..c6`；`9–13` → `U4-s1..s5`；`14–16` → `U4-t1..t3` |

- **`section` 字段**：U1 卷面没有大题标题 → `section: null`（不得编造）；U2 = `主体 / 语法 / 语法填空`；U3 = `阅读 / 语法`；U4 = `单词拼写 / 单项选择 / 完成句子 / 句型翻译`
- **`no` = 卷面题号**（各大题内重数）；`id` = `U{unit}-{sec}{no}`，无 section 时 `U{unit}-{no}`（= U1 现状，故 U1 迁移量为零）
- **id 迁移表**：硬编码在 `index.html` 的 `MIGRATE_IDS`（旧→新），`loadStore()` 与导入时逐字段重映射 `picks/fills/stat/at/atList/cleared`；新旧 id 都认（旧 id 作别名读取）
- **按空拆填空**：`fields` 字段（字符串数组，长度 = 卷面横线数），答案 `answer` 已按 `"a / b"` 对齐；判分按空给红绿，**题级判定仍为"全对才算对"**（兼容 `stat`）
- **待核对**：U2 语法填空第 4、5 空被修正带遮挡 → `note` 写明、`doubt: true`，不猜
- `build.mjs`：删掉 `DROP = { U2: ["p26","p27","gf11"] }`；汇总输出改为按 section 分组计数
- `check-grading.mjs`：跟进 `fields` 与 section，输出逐空清单

**阶段①验收**：`node build.mjs` 汇总 = 89/40/49；`check-grading.mjs` 无缺答案；旧界面照常能跑（此时界面还没改）；`qa.mjs` 旧断言不回归。

## 四、阶段②：界面改版

### 视图与参数

| 视图 | 内容 |
|---|---|
| `practice` | 做题（一题一屏）。`#mode=drill`（默认，提交即解析）/ `#mode=exam`（交卷才解析） |
| `review` | 复盘。`#tab=wrong`（默认，错题卡片流）/ `#tab=paper`（原卷批改，含「待核对 / 存疑」） |

### 题卡（一题一屏）

- 顶部（sticky，紧凑）：`U1–U4` 单元切换 · 模式（过关/模拟考）· 进度 `3 / 27` · 答题卡 · 原卷
- 题卡：`大题名 · 卷面第 N 题` → 题干（`______` 渲染为空格占位）→ 选项（A–D，两列→手机一列）或按空输入框
- 提交后：正确项绿、错选红、✓/✗、四段式解析（考点/规则/解析/易错点/正确答案）、**原卷你答的是 X**、`重做本题`
- 模拟考模式：提交按钮改为「下一题」，**不出现解析与正确答案**（DOM 层断言）；可「标记不确定」
- 底部固定条（`env(safe-area-inset-bottom)`）：`← 上一题` ｜ `提交` / `下一题 →` ｜ 进度 ｜ 答题卡

### 键盘

| 键 | 行为 |
|---|---|
| `1–4` / `A–D` | 选中选项 |
| `Enter` | 未提交→提交；已提交→下一题 |
| `←` / `→` | 上一题 / 下一题 |
| `Esc` | 关答题卡 / 结算页 |

### 答题卡

- 手机：底部条按钮打开抽屉；≥1100px：右侧常驻
- 按 section 分组、题号网格；状态：未做 / 已答 / 标记 / 对 / 错；点格子跳题
- 交卷前显示"未答 N 题"提醒

### 结算页与讲评（模拟考）

交卷 → 结算页（`对 X / Y`、用时、错题号 chips 可点）→ 逐题讲评（同一题卡，显示解析与原卷手写）。
卷面无分值 → **只算正确率，不算得分**。

### 原卷

- 入口：卷头「原卷」+ 每题「看原卷」，都打开 `英语/题库/九上_U{unit}.jpg`（原图，浏览器原生缩放）
- 网页版隐藏入口（`publish.ps1` 清单不含 `题库/*.jpg`，发布就会 404）——沿用 `开始.html` 的 `body.web .file-only` 机制
- 不做逐题坐标裁剪，不做页内缩放浮层

### 记录（只加不删）

- 既有字段全部保留：`picks/fills/stat/cleared/at/atList/unit`
- 新增 1 个可选字段：`rounds: [{mode, startAt, endAt, costMs, ok, total}]`（最近 20 轮，只给结算页/复盘用；开始页与训练台不认识就不统计）
- 交卷时写 `rounds` 与 `at`；逐题提交照旧写 `stat/at/atList`

## 五、深链契约

| 链接 | 行为 |
|---|---|
| `#view=practice` | 做题，默认过关模式 |
| `#view=practice&mode=exam` | 模拟考 |
| `#view=practice&unit=U2` | 定位该单元第一题 |
| `#view=review` / `#view=review&tab=paper` | 复盘 / 原卷批改 |
| 别名 | `#view=mistakes`→`review&tab=wrong`；`#view=report`→`review&tab=paper`；`#view=fills`→`practice&filter=fills`；`#layout=one` 静默忽略 |
| `#unit=U1..U4` | 保留（也认 `1`/`unit1`） |

只在启动读一次、不回写 hash、非法值按 key 静默忽略（契约文档:43-48 不变）。
**同步改三处**：`index.html` 的 `applyDeepLink()`、`开始.html` 的 `SUBJECTS[].quick`（改 `#view=practice&mode=drill`）与 `wrong`、`docs/plans/开始页与深链契约.md:41`。

## 七、验收口径（写进 `qa.mjs`）

1. 手机 390px：任一题含解析时，底部「下一题」可见且可点，`scrollY` 不参与
2. 模拟考交卷前，DOM 中不含正确答案与解析文本
3. 键盘：`1–4/A–D` 选中、`Enter` 提交与下一题、`←→` 翻题
4. 交卷 → 结算 → 讲评 ≤ 2 次点击
5. 记录：一次作答 `stat.att+1`、`atList` 追加、重做不覆盖；旧存档 id 迁移后逐字段正确
6. 原卷手写文本只在提交后出现
7. 数据完整性：89 / 40 / 49、无缺答案、id 唯一、每题可归到大题；`file://` 直开无报错
8. 深链 4 个用例各落正确视图/模式/单元

## 十、风险

| 风险 | 应对 |
|---|---|
| U2 语法填空短文拼接有不确定（4、5 空被修正带遮挡） | 标 `doubt` + note，讲评里显示"待核对"；不猜 |
| 表头/姓名不可辨 | 按 SCHEMA `null`，界面不显示，不编造 |
| id 迁移写错会串记录 | 迁移表逐条列 + `qa.mjs` 断言"迁移后每字段条数不变" |
| iOS 底部安全区 | 底部条 `env(safe-area-inset-bottom)` |
| 旧深链被外部引用（书签/开始页缓存） | 旧 `#view` 全部留别名 |
