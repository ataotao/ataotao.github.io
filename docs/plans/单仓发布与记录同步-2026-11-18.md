## 一、目标

1. **单仓 + 推送即发布**：`ataotao.github.io` 成为唯一开发发布仓；`git push` 一次站点自动更新。
   判据：删除 `publish.ps1` 后，从零 clone 的机器不需任何路径配置即可发布；改一科产物 → push → `https://ataotao.github.io/1/` 出现新版本。
2. **训练器模板**：三份先抽成模板 + 科目配置，**先迁化学一科**验证。
   判据：`化学闪练卡.html` 由 `工具/trainer/build.mjs 化学` 生成；记录键仍是 `chemflash_v1`；`node 化学/题库工具/check-flash.mjs` 通过。
3. **记录跨设备同步**：训练器加「云同步」，走私有仓 + 事件并集。
   判据：两个浏览器 profile 各答 3 题 → 同步 → 另一个看到 6 条；**再同步一次仍是 6 条**。
4. **历史导出不丢**：已有的两份导出（物理/数学）经原始种子重算后被并进载体，且**重复导入不翻倍**。
