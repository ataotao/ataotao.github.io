## 四、顺手修的两处自检问题（与清理无关，清理后暴露）

1. `工具/dsh-plugin/selfcheck.mjs` 断言仓库根目录以 `learning-training` 结尾，但目录已改名「做题思维训练」
   → 改成认 `开始.html` + `AGENTS.md` 两个标记文件。
2. 同文件的学习记录夹具直接写盘，mtime = 当前时间；解析器对没有导出时间的记录会退回 mtime，
   于是「物理」永远排到 `recent` 第一行 → 夹具写盘后用 `utimesSync` 固定成 `2026-11-04T06:27:11Z`。
3. `工具/dsh-plugin/records.js`：`recent` 排序把 `at` 为 null 的记录当成最大值（比较结果为 false 时返回 -1）
   → 显式把空值排最后。
