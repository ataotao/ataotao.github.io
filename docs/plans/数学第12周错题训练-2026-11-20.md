## 一、目标

本次错题来自 `数学/函数思维脚手架.html` 的第 12 周数学限时练习（11.18，`题库/packs/pk-week12-1118.js`）：

| 题号 | 内容 | 结论 |
| --- | --- | --- |
| 10 | 扇形周长（150°、半径 3 → 5π/2 + 6） | 错 |
| 11 | 平行弦之间的距离（2 或 14，漏一种情况） | 错 |
| 12 | 「关联圆」新定义 + 旋转 + 取值范围 | 错 |
| 13 (2) | 解一元二次方程：x² − 4x − 8 = 0（配方 / 公式） | 对 |
| 13 (1) | 解一元二次方程：x² − 2021x = 0（**缺常数项，提公因式**） | **错**：换了出题形式就不会（照 (2) 的思路两边除以 x，把 x = 0 丢了） |
| 16 | 圆弧拱桥求半径 + 抛物线拱 + 水位上升水面宽 | 错 |
| 附加（第 17 题） | 含参 b、等腰三角形存在性、开区间取值范围 | 错 / 不会 |

要做两件事：
1. **核对闪练卡是否已覆盖**这些题涉及的知识点，已覆盖的不重复加，**没覆盖的补成参数化题型**；
2. 在闪练卡里**单独加一个临时训练项目**「本周错题」，专练本卷错题与不会题，不动原有结构。

## 四、方案

1. 在「第 12 周补的四个缺口」（扇形周长 / 平行弦 / 外心 / 等边弧长）之后新增五个生成器：
   `genRelateCircle`（关联圆）、`genArchCircle`（圆弧拱桥含水位变化）、
   `genIsoPoint`（对称轴上的点构等腰三角形）、`genRangeOpen`（开区间取值范围）、
   `genMissingConst`（缺常数项提公因式，第 13 题 (1)：x² − 2021x = 0 / ax² − bx = 0 / 整体提公因式 (x − m)² = k(x − m) 三种形式；
   判分用 `set` 两个根，坑写在解析里——两边同除以 x 会丢根 x = 0）。
2. 五个题型插进 `MODULES.drill.kinds`：扇形周长 / 平行弦 / 关联圆 / 圆弧拱桥进「圆」，等腰三角形存在性 / 开区间取值范围进「二次函数」，缺常数项进「方程与代数」（drill 44 → 49 类）。
3. 新增模块 `MODULES.week12`：`daily:false`（**不进今日任务**），7 个 kind 与错题一一对应（第 17 题的 (2)(3) 各一个），
   全部**复用已有生成器**，不新增题面逻辑；专项统计按 `mod='week12'` 单独记。
4. 壳级改动三处：页签加「本周错题」；`renderToday` 用 `daily !== false` 过滤任务行；深链 `#view=` 改走 `MT.moduleById()`，以后加模块不用再改这里。
5. 临时项的下线方式写进注释：删 `week12` 模块 + 页签那一行 + `VIEWS` 那一行，其余不动。

## 七、每个练习点标「卷面第几题」+ 原题裁切图（2026-11-20 追加）

**需求**：孩子要能一眼看出这个练习点对应卷子上的哪一题；光有题型名不够，要**题号 + 原题裁切图**。

**卷面事实**：本卷第 17 题就是「（附加题 20 分）」——卷面印的是 17，不是「附加」。所以：
`secperim→第10题`、`paralleldist→第11题`、`relatecircle→第12题`、`missingconst→第13题(1)`、`archcircle→第16题`、
`isopoint→第17题(2)`、`rangeopen→第17题(3)`（第 17 题 (2)(3) 共用同一张裁切图）。

**实现**（`week12` 的 kind 上声明，`gen()` 里挂到题目上，其它模块不受影响）：

- kind 上加 `ref`（`'10'`…`'17'`）、`refLabel`（`'第 10 题'` / `'第 17 题 (2)'`）、`crop: { key: 'q10', cap: '卷面原题：…' }`；
- `gen()`：`k.ref → q.no / q.noLabel`，`k.crop → q.fig`（`need:1`，答题时就看得到，图注用 `q.fig.cap`）；
  **drill 里的同名题型不带 ref/crop**，避免基础快练每道变式都贴原卷；
- UI 三处 `figcap` 改成 `q.fig.cap || 原文案`；题号 pill 认 `q.noLabel`（`qnoLabel()` 只认纯数字）；
- **裁切图不进错题本**：错题快照只存 `cropKey` / `cropCap` / `noLabel`（几十 KB 的 base64 塞进 localStorage 会撑爆、每次答题都整库落盘）；
  回炉时 `figOf(q)` 用 `MT.cropFig({key})` 现重建 —— smoke 里有断言：答错后条目 `fig` 必须为空、`cropKey='q10'`、`noLabel='第 10 题'`；
- 兼容老 WebView：`<image>` 同时写 `href` 与 `xlink:href`，`svgFor()` 的 `<svg>` 补 `xmlns:xlink`；
  core 里 `WEEK_IMG` 用 `typeof` 守卫，只抽 core 的 `check-training` 照样跑（只是不画图）。

