## 一、目标

做一张英语单词闪练卡：按「年级（册）→ 单元」选范围，三方向四选一反复练（英→中、中→英、音→中），答错进错题库按 1/3/7/14 天回炉，带今日/随机/错题/报告四视图，HTML + 同目录 `词库.js` 两文件 `file://` 双击可用（单文件约束已被 ADR-0009 取代）。词库读 apps/english 的沪教版 + 沪教牛津小学两来源（约 2651 词）。

可观察判据：① `node 工具/trainer/build.mjs 英语单词` 成功产出 HTML + `词库.js` 两文件；② `node 工具/trainer/selfcheck.mjs 英语单词` 通过；③ `check-training.mjs` 出题自检通过（三方向各成百上千题、无 undefined、判分正确）；④ 开始页 `wordsflash` 卡可点开、深链生效；⑤ 产物除同目录 `词库.js` 外无外链、无运行时 fetch。

## 三、现状（锚点）

- 物理 scaffold 三源：`物理/源/train.{css,core,ui}.js`（ui 54 KB，core 120 KB）；构建 `工具/trainer/build.mjs:91-97` 把三源逐字节内联；`selfcheck.mjs:63-95` scaffold 分支只校验「产物=源」+ core 全局 + 记录键 + merge/sync + 单文件。
- 物理 UI 的 h() 引擎在 `物理/源/train.ui.js:31`；核心可复用骨架（DB/回炉/导入导出/云同步/测试钩子）见调研结论，本次派 agent 摸行号。
- 词库真源：`apps/english/src/data/沪教版/*.ts`（7 册）+ `沪教牛津小学/*.ts`（8 册），同构 `Category`，字面量形如 `{ english, phonetic, pos, chinese }`。中考/阅读两来源本次不用。
- 音标覆盖：沪教版与小学大多有 `phonetic`，个别空串 → 音→中模式对空串降级纯听音。
- 开始页：`开始.html:197-204` 现有 `words` + `yuexueci` 两入口；`GROUP_OF:211-217` 映射；记录读取 `~366-535`；待办 `~596,650`。

## 四、方案

1. 词库提取：`extract-vocab.mjs` 解析两个目录下 15 个 `.ts` 的 `export const X: Category = {…}` 字面量（剥 import/类型标注 → vm/JSON 求值），合并成 `英语/源/vocab.json`，校验每条 en/zh 非空、统计册/单元/词数。
2. core（`EW`）：`MODULES` = 年级册两级索引；`gen(gradeId,unitId,kind,seed)` 三方向出题（英→中题干=en选zh、中→英题干=zh选en、音→中题干=ipa+喇叭选zh），四选一干扰项同单元内随机；`judge` 按下标比对；`selfTest` 批量自检；`DAY=86400000`。
3. ui（约 20 KB，从物理裁剪）：保留 h() + DB + 1/3/7/14 回炉 + 今日（年级册→单元级联，默认九上）/随机/错题/报告 + 导入导出（走 `__ltMerge.mergeRecords`）+ 云同步（`__ltSyncUI`）+ `window.__ew` 测试钩子；喇叭用 `speechSynthesis`，音标空时隐藏文本只留按钮。
4. 开始页加 `wordsflash` 卡，desc/note 写明与粤学词分工；记录读取登记 `enwordflash_v1`。
5. （2026-11-19 补充）双向混合模式：`startSession` 的 kind 参数支持数组，`['e2c','c2e']` 即「英↔中」两方向轮换（不练音），今日页加按钮；`sess.kind` 原样存数组，「再来一轮」保持同种混合。core 不变，仅 UI 调度。
6. （2026-11-19 补充）例句高亮：仓库无课文原文数据，改用粤学词 full/primary-data.js 的词典语料例句（与词表同属沪教牛津体系）。`extract-vocab.mjs` 合并例句提取，词条从 4 元素扩到 6 元素 `[en,ipa,pos,zh,ex,exZh]`；只保留例句确实含目标词（或可高亮词形/首个实词）的配对，2004/2651 = 75.6%。core 加 `highlightExample`（词形变化 + 词边界 + HTML 转义），gen 把 ex/exZh/word 带到题上；UI 提交后在解析区显示「用法例句」虚线框，目标词黄色高亮 + 中文翻译，不泄题。错题快照带例句，回炉重做同样能看到。产物为 HTML 70 KB + `词库.js` 272 KB 两文件（ADR-0009 外置词库）。
