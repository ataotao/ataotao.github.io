# 核心考点背记训练器 · 使用说明（道德与法治）

> 一个单文件网页：把 `images/` 里那 10 页**知识提纲**拆成 **128 张考点卡**，用「翻卡背 → 填空闯 → 四选一」三个难度递进的模式反复刷，答错的自动进错题本，连续答对 3 次才算「熟练」。

---

## 一、怎么打开

双击 **`核心考点训练.html`**，用 Chrome / Edge 打开。

- 不需要联网、不需要安装，考点、判分逻辑全在这一个文件里。
- 手机上也能用：把 `核心考点训练.html` 和 `images` 文件夹一起发到手机，用浏览器打开（**放在同一个文件夹里**，否则「对照原页」点不开）。
- 练习记录存在**这台设备的浏览器**里（关掉网页不丢），清缓存/换电脑会丢 —— 顶部有「导出记录 / 导入记录」用来备份和搬设备。

目录结构：

```
核心考点训练.html    ← 工具本体（双击打开）
使用说明.md          ← 本文件
考点数据.json        ← 128 个考点的数据（改完可以重新生成网页）
images/              ← 扫描的原页（点「对照原页 pN」会打开对应那张）
预览截图/            ← 界面截图
```

## 二、里面有什么

| 内容 | 数量 |
|---|---|
| 考点卡 | **128 张**（第一单元 48 张 · 第二单元 80 张） |
| 单元 / 课 | 2 个单元 / 6 课 |
| ★必背（书上打星的） | **94 张** |
| 可挖空练习的 | 127 张（另有 1 张是纯陈述句，只能翻卡背） |
| 表格型考点 | 1 张（四个历史时期「阶段—成就—结论」对照，就是那个最容易配错的知识点） |

来源：`道德与法治/images/政治_1.webp` ~ `政治_10.webp`（2026 九年级上册《道德与法治》知识提纲，共 10 页）。每张卡右上角的「对照原页 pN」可以直接跳到扫描页，**文字和原页对不上时以原页为准**。

> 原页是压缩过的 WebP（1600 像素宽，一张 100–530KB，手机上打开很快）。压缩前的原始高清照片还在 git 历史里，需要时可以取回。

## 三、五个模式怎么用

顶部五个标签，从左到右就是建议的使用顺序：

### ① 翻卡背 —— 认脸

先只显示问题，自己心里（或纸上）说一遍，再点「显示答案（空格）」。
答案里的**红字**是这份提纲里打星的关键词，就是要能默写出来的那部分。
对照完之后老实选一个：**会了（1）/ 有点模糊（2）/ 不会（3）**。
- 「会了」→ 熟练度 +1（连对 3 次标「熟练」）
- 「有点模糊」→ 不算对也不算错，连对计数清零，下次还会碰到
- 「不会」→ 记一次错，进错题本

> 自评要诚实。这里没人查，哄自己等于白练。

### ② 填空闯 —— 落笔

把答案里的关键词挖成空格，靠打字填。这是**最接近考试**的一关：考场上写不出来，就是因为只会"认"不会"写"。
- 填完按「提交判分」（或回车）。对的变绿，错的变红并在后面给出正解。
- 长答案（8 个字以上）判分做了容错：少写一个"的/和/了"不算错。
- 真觉得自己答对了但被判错（比如输入法问题），点「我其实答对了（算对）」，会把这题的错记录改回来。
- 实在想不起来点「看答案（算不会）」—— 直接算错，别骗自己。

### ③ 四选一 —— 提速

从别的考点里自动抽 3 个干扰项凑成 4 个选项，一条一条刷，速度最快。
答错也能立刻知道正解，可以点「看整条答案」看完整答案。
**这一关适合考前 10 分钟快速过一遍**，不适合替代 ②。

### ④ 错题强化 —— 补漏

只出「错过、而且还没连续答对 2 次」的考点，按错得多的排前面。
连续答对 2 次就自动出库；清空了说明这一段真的补上了。

### ⑤ 清单 —— 查和背

- 按单元/课列出全部 128 张考点，点标题展开看答案。
- 勾上「遮住红字」，红字会变成灰块，点一下才显示 —— 适合对着清单自测。
- 上面有**各单元熟练度**和**最该补的 10 张**。
- 「打印这份清单」可以直接打印（或存成 PDF），纸上背。
- 搜索框可以查关键词，比如「主心骨」「新质生产力」。

## 四、两周怎么安排（每天 15–20 分钟就够）

| 时间 | 做什么 | 目的 |
|---|---|---|
| 第 1–3 天 | 只做 ① 翻卡背，一次一个单元，每题允许自己看答案 | 先「认脸」，知道这一课到底有几个考点 |
| 第 4–8 天 | ② 填空闯 + 当天新学的课；做完看「今天」的正确率 | 从"认得"变成"写得出" |
| 第 9–11 天 | ④ 错题强化，把错题清空 | 补漏，而不是平均用力 |
| 第 12–13 天 | ③ 四选一 全范围快速过一遍（★必背优先） | 提速 + 查有没有记串的 |
| 第 14 天 | ⑤ 清单 →「打印这份清单」，纸上默写一遍 | 模拟考场，脱离电脑 |

**考前一天的最佳用法**：顶部「练习范围」选「只练★必背」，然后 ③ 四选一 快速刷 94 道，20 分钟能过一遍。

**筛选用法**（顶部两个下拉框）：
- 左边选单元 → 只练这一单元；
- 右边选范围 → 「只练★必背」/「只练未熟练」/「只练没练过」。

## 五、"熟练"是怎么算的

每张卡记四个数：练过几次、对几次、错几次、**连续答对几次**。

| 标记 | 含义 |
|---|---|
| 未学 | 还没练过 |
| 记过 | 练过，但连着对还没到 3 次 |
| 熟练 | **连续答对 3 次** |
| 待强化 | 最近一次答错（在错题本里） |

只看「连续答对」，是因为隔了很久还答得出来才算真会；靠印象蒙对一次不算。
`不确定/模糊` 会把连续计数清零，但不算错、不进错题本 —— 这个设计是为了不打击"其实有点印象"的题。

**报告怎么看**：
- 顶部「已熟练」上不去、但「待强化」也不多 → 练得太少，量不够；
- 「待强化」一直清不空 → 是**同一批**题反复错，那就是概念没通，回头看书（见第七节的边界）；
- 「今天」的正确率低于 60% → 该停下来把这一课重看一遍，别硬刷。

## 六、记录怎么备份 / 换设备

- **导出记录**：下载一个 `道德与法治-练习记录-日期.json`，里面有每张卡的记录。
- **导入记录**：选那个文件，覆盖本机记录（导错了可以用「清空」重来）。
- 换手机/换电脑：把 `核心考点训练.html`、`images/`、导出的 json 一起拷过去，打开后导入记录。

> 记录只存在浏览器里，**不会上传到任何地方**。

## 七、一个诚实的边界

这个工具管的是**"记没记住、写不写得出来"**，不管**"懂不懂"**。

如果一张卡连续错 5 次以上，多半不是你背得不够，而是这条知识点背后的概念没通（比如"全过程人民民主"到底指什么、"新质生产力"和"高质量发展"什么关系）。
这时候正确动作是：**拿着「对照原页 pN」回到扫描页，把这一条念两遍，找老师或课本问清楚，再回来练。** 硬刷只会把错的记得更牢。

另外：
- 这些卡是从**你那份提纲**逐字转的，提纲本身写得简（比如有"……""等"），卡里也照原样保留了。**考试答题要按课本完整表述补全**，工具只保证"关键词不漏"。
- 表格、数字、年份这类最容易错的，建议用 ⑤ 清单 的「遮住红字」对着背，比打字更接近考场。
- 书上如果你有新的补充（老师上课加的），可以告诉我，我再往卡里加。

## 八、以后要加页子怎么办

这份工具是「数据 + 模板」生成的，加内容不用手改网页：

1. 把新页子（拍照或扫描）放进 `images/`，命名接着编号，比如 `政治_11.jpg`，然后 `bun 工具/compress-pages.js 道德与法治` 压成 WebP；
2. 我这边把它转成考点卡，追加到 `考点数据.json`；
3. 跑一句 `node 工具/build.mjs` 重新生成网页（模板在 `工具/core-template.html`）。

也可以直接把新页子发给我，我来做。**注意：重新生成后，网页里的练习记录还在**（记录是按考点 id 存的，id 不变就不丢）。
