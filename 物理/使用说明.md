# 物理思维脚手架 · 使用说明

> 一个单页工具（本地文件，双击即用）：把物理题拆成 **认情境 → 圈条件 → 选规律 → 代数据 → 验结果** 五步来练，
> 另有 **概念闪练**（2 分钟一轮）、**试卷练习**（原卷原题 + 自动判分 + 原卷答案）、**错题回炉**、**训练报告**。
>
> 题目和答案全部来自 `题库/` 里你自己的周练卷（第 1、2、4、5(国庆1/2)、6、8、9 周，共 **8 套 118 题**），另有 **120 张概念卡**、**15 组五步母题**。

---

## 一、怎么打开

1. **双击 `物理思维脚手架.html`**，用 Chrome / Edge 打开即可（不需要联网、不需要安装）。
2. **`图片/` 文件夹必须和网页放在一起**（原卷的图都裁在这里；挪走网页会看不到图）。
3. 手机上也能用：把 `物理思维脚手架.html` 和 `图片/` 文件夹一起发到手机（用"文件管理"打开网页）。
4. 练习记录保存在**这台设备的浏览器**里，关掉网页不会丢；清缓存或换设备会丢——报告页有「导出记录 / 导入记录」。

```
物理/
  物理思维脚手架.html   ← 双击打开（唯一需要双击的文件）
  使用说明.md           ← 本文件
  图片/                 ← 原卷裁图（每题的原题 + 参考答案），必须和网页放一起
  题库/                 ← 题包 JSON（加新卷时改这里）+ 原始 docx
  预览截图/             ← 界面截图（想先看看长什么样）
  源/                   ← 源码（改样式/模块才用）
  工具/                 ← 构建、裁图、体检、截图脚本（见 工具/README.md）
  _recon/               ← 中间产物（raw 素材、裁图备份），可以整个删掉
```

## 二、它到底在解决什么

「听课懂、做题不会」不是知识没听懂，而是**做题时那条检索链没建起来**：
听课是跟着老师走一遍，做题得自己完成

**认情境 → 圈条件 → 选规律 → 代数据 → 验结果**

这条链断在哪一环，多刷题补不上，只会把同一个错误刷得更熟。所以工具做了三个刻意的设计：

| 设计 | 为什么 |
|---|---|
| **五步每题一问，走完才允许落笔** | 强制把「想」和「算」分开。孩子原来的习惯是一看题就动笔，写着写着不知道自己在算什么 |
| **提示分三级，先自己想 20 秒** | 一级指方向、二级给方法、三级才说这一步怎么做；看提示会记下来 |
| **只统计「第一次就答对」** | 提示后答对不算会。这样报告里的百分比才有诊断价值，不是自我安慰 |

## 三、五个模块怎么用

### 1）五步引导（练"流程"）
- 每题只问五步，一步一步点。答错会直接说**断在第几步**，并给这一步的"为什么"。
- 卡住：先想 20 秒 → 点「看提示 1/3」→ 还不够 → 2/3 → 3/3。
- 题目卡片右上角有「看思路」：一次讲透入口、五步各自该做什么。**看过思路的题不算会**，报告里会标出来。
- 走完五步才进入"落笔"：把最终答案填进去（自动判分），再对照原卷答案与解析。
- 顶部有换题条：上一题 / 题号直达 / 下一题 / 题目清单。题号颜色 = 这道题的状态。

### 2）概念闪练（练"概念"，每天 2 分钟）
- 「快练一轮 · 20 张」：优先推没练过、生疏、到期该复习的卡片。
- 「按考点练」：哪个考点虚就点哪个（杠杆五要素、滑轮组、比热容……25 个考点）。
- 「错卡重练」：最近答错的卡单独过一遍。
- 答完立刻给**一句话解释**；最近一次答对且正确率 ≥80% 就记为「掌握」（答对一次即可，不必等第二轮复习）。
- 熟练度分四档：没练过 / 生疏 / 熟悉 / 掌握。报告页能看到分布。

### 3）试卷练习（练"验收"）
- **先在纸上把整张卷子做完**，再回到这里一题一题录答案。**不要边做边看答案**。
- 每题显示**原卷原题图**（连图带表，和卷面一模一样）；选择题点选项，填空/解答填数值。
- 提交后：判对错 → 给正确答案 → **答案图默认折叠**（先自己想）→ 分步解析 → 一句话关键。
- 做过的题再进来是**空白作答区**，必须重新做一遍（上次的选项/填空不会带过来）；想核对上一次的答案，点「看上次的答案与解析」再展开。
- 每题都记**累计做错次数 / 做对次数**，题头、题号清单、整卷结果、错题本里都能看到。
- 最后有整卷结果：对 x/y、这一轮还错着的题、「只练错的」「回炉错题本」。
- 标「自评」的题（画图、说理、答案不唯一）不自动判分，只给原卷答案和评分要点。

### 4）错题回炉（练"补漏"）
- 三类错误汇总：五步断点、试卷错题、概念错卡。
- 点进去就是原题，重做一遍。**只有五步断点做对了会自动清**。
- **试卷错题、概念错卡都不自动清**：一旦错过就留在上面（旁边记着「累计错 N 次」），直到你自己在清单里勾「我会了」再点清掉。理由：这类题很容易"当次末尾改对一次"就以为会了，自动清会把真正的断点抹掉；留着才能过几天再回炉一遍。

### 5）训练报告（看"断点"）
- 五步各环命中率 → 最红的一环就是本周要补的地方，下面直接给"下一步做什么"。
- 概念熟练度分布 + 正确率最低的考点（可直接点进去练）。
- 每套卷的正确率、错题总数、连续练习天数。
- 记录导出/导入（换设备、备份用）。

### 6）题库管理（加新卷）
- 看所有题包、导入新题包 JSON、导出全部题包。
- 加新卷的完整流程见 `物理/源/内容作者必读.md`；简版：docx 放进 `题库/` → 跑 `物理/工具/extract.ps1` 裁图 → 照 `题库/pack-模板.json` 写 JSON → 这里导入（或重建页面）。

## 四、建议的一周安排（每天 15–20 分钟）

| 时间 | 做什么 | 目的 |
|---|---|---|
| 第 1 天 | 五步引导 1 题，慢一点，允许看提示 | 把五步走顺，知道每一步在问什么 |
| 第 2–5 天 | 每天 1 题五步引导 + 1 轮概念闪练（2 分钟） | 让流程变成习惯，不追求快 |
| 学校发了卷子 | 试卷练习：**先整张做完，再一题一题录** | 验收，错题自动进错题本 |
| 第 6 天 | 看训练报告：最弱的一环 + 错题回炉 | 只补断点，不均匀用力 |
| 第 7 天 | 错题回炉清一遍；概念闪练把"生疏"刷到"熟悉" | 把这一周的错误清掉 |

## 五、家长怎么配合（比工具本身更重要）

1. **不报答案，只问三句**：
   - 这题是什么模型？（第 1 步）
   - 题目给了哪些条件？单位统一了吗？（第 2 步）
   - 你要用哪条公式？为什么能用？（第 3 步）
2. **孩子点提示不要批评**，但要追问："在看提示之前，你想到了什么？"——想不起来，说明这一步真的空。
3. **只看趋势不看分数**。报告里哪一步最红就补哪一步；不要因为算错就罚做计算题（那是把"思维问题"误判成"努力问题"）。
4. **每周一次"讲题"**：让孩子对着五步，给你讲一道做过的题。讲不清的那一步，就是断点。
5. 试卷练习**先做后录**：一次录一整张，别做一题对一题，否则就成了"边看答案边做题"。

## 六、报告怎么读

- **命中率低于 60% 的环节 = 断点**，报告会给出该环节的具体动作，照着做一周再回来看数据。
- **五步全对、落笔却错** → 问题在计算、书写、单位，不是思维。
- **五步错得多、落笔却对** → 多半是蒙对或背过答案，换同考点的题再测。
- 概念卡「生疏」多的考点，往往就是五步里第 1、3 步反复错的原因——**概念和流程要一起补**。

## 七、每周学校发了新卷怎么办（推荐流程）

**先说结论：卷子当天就能做成"可练版"，精修可以等周末。** 因为这一步做成了命令，不用手工录题。

### 第 1 步（约 1 分钟）：一条命令，出"草稿版"

把新 docx 放到任意位置（下载文件夹也行），在仓库根目录跑：

```powershell
pwsh -File 物理\工具\weekly.ps1 -Docx "C:\下载\第10周.docx"   # 换成你自己文件的位置
```

它自动完成：docx 归档进 `题库/` → 裁出每题原题图与答案图 → 从原卷答案表生成题包 → 重新构建页面。
刷新 `物理思维脚手架.html`，「试卷练习」里就多了这一周（卡片上有黄色「草稿题包」提示）。

**草稿版能做什么**：选择题已能自动判分（答案取自原卷答案表）；填空/解答题先按"对答案不判分"——点「看答案」就能对照原卷答案图，做错的照样进错题本。

### 第 2 步（周末 15–25 分钟，可选）：升级成"精修版"

精修 = 给填空/解答题补上**可判分的数值字段**和**分步解析**（这样孩子填答案就能自动判对错，报告也统计得到），外加每题一句**考点**和 1–3 条**应用公式**（题目 JSON 里的 `point` / `formulas`，显示在解析区最上面那块蓝框里）。
可以让 AI 助手按 `物理/源/内容作者必读.md` 做，也可以自己改 `题库/pack-wN.json` 后跑 `node 物理/工具/build.mjs`。

### 几条经验（能省很多时间）

1. **文件名尽量规范**（`第10周.docx`），命令会自动识别成 `pk-w10`；不规范就加 `-PackId pk-w10`。
2. **不用每周都加"五步母题"**：现有 15 组已覆盖主要题型，只有出现新课型（比如电学计算）时再补 1–2 组。
3. **概念卡随错点补**：一周 2–3 张，只补这周错得最多的概念，不要一次写 20 张。
4. **别重跑全部周次**：命令只处理你给的那一份 docx；已有题包不会被覆盖（要覆盖加 `-Force`）。
5. **加完跑一次闸门**：`pwsh -File 物理\工具\check.ps1`（自动找 node/python，依次跑构建、答案体检、完整性检查），看到「全部通过 ✓」再给孩子用。
6. 每周新增内容会一起算进「训练报告」，所以**坚持用同一个网页文件**（浏览器记录是按文件所在的网址存的，别每周换个新文件）。

## 八、这个工具准不准？（可核验）

**先把责任分清**：这里"题目、图、答案"和"解析、考点归类、五步设计"是两回事——前者能追溯到原卷，后者是教学加工。

| 内容 | 来源 | 能不能核 |
|---|---|---|
| 题干、选项、插图、表格 | **原卷裁图**（不重画、不改写） | 和手里的 docx 逐字对照 |
| 选择题答案（78 题） | docx 文末**答案表**（脚本解析，不是"我看题算的"） | 跑 `python 物理\工具\check_answers.py`，必须"全部一致 ✓" |
| 填空/解答答案（40 题） | 原卷文末**参考答案图**（页面里可展开） | 点「看答案」直接看原卷答案，孩子自己就能对 |
| 可判分的数值字段 | 从原卷答案图转录 | `物理/核验清单.md` 第五节列出全部；抽看 3 题即可 |
| 解析文字 | 优先转写原卷【详解】，没有才补写 | `核验清单.md` 里标了哪些题没有原卷详解 |
| 考点、应用公式（118 题各 1 句 + 1–3 条式子） | **AI 按原卷解析归纳** | 建议请物理老师抽查 3 套卷，重点看式子里的适用条件（如「不计滑轮重」「l 是垂线段」） |
| 概念卡、五步母题 | **AI 归纳**（初三教材范围内的结论） | 建议请物理老师抽查 10 张卡 + 2 组母题 |

`物理/核验清单.md` 是这份核验的**明细账**：总览、每套卷的答案来源、需要人工看的题、原卷疑点、每次要跑的检查命令。随时可重新生成：`node 物理\工具\核验报告.mjs`。

**原卷本身有错的地方，我们不改**：第 1 周第 8 题排在"单选题"下但答案表给 BC、第 4 周第 10 题答案表与图像矛盾、参考答案把第 14 题的答案误编成"15．"……这些都只写进题包 `备注`，答案照原卷——保证孩子看到的口径和老师/原卷一致。

**一句话**：题目和答案放心用（可追溯）；解析和概念卡当"助教讲稿"，哪句别扭以老师为准，告诉我改。

## 九、常见问题

**Q：图片显示不出来？**
A：`图片/` 文件夹没和网页放在一起，或者被移动/改名了。把整个 `物理/` 文件夹一起搬即可。

**Q：记录丢了？**
A：记录存在浏览器里（localStorage）。清缓存、换浏览器、用无痕模式都会丢。建议每周在「训练报告」里导出一次记录。

**Q：想发到手机？**
A：把 `物理思维脚手架.html` 和 `图片/` 文件夹一起发过去，用手机浏览器打开网页文件。记录是各设备独立的。

**Q：加了新卷子怎么办？**
A：一条命令：`pwsh -File 物理\工具\weekly.ps1 -Docx "<你的文件>\第10周.docx"`（会自动裁图、生成草稿题包、重建页面）；精修流程见 `物理/源/内容作者必读.md`。跑完用 `pwsh -File 物理\工具\check.ps1` 做一次体检。

**Q：换电脑 / 两台电脑一起用怎么办？**
A：这是 git 仓库，`git clone` 下来就包含源码、题包、全部裁图、构建好的网页和脚本——**只给孩子用的话什么都不用装**，双击网页即可。
需要改内容/加新卷时再装：node（必须）、Python + python-docx（答案体检）、Word（只有裁图这步要）。
所有脚本都从"自己所在位置"推导项目路径，并自动在 PATH / 常见安装位置找 node、python、浏览器，**不写死任何机器路径**；换电脑后先跑 `pwsh -File 物理\工具\check.ps1` 自检。
两人同时改时：各改各的 `题库/pack-wN.json`，`物理思维脚手架.html` 是构建产物（别手改），最后统一 `check.ps1` 重建；冲突以 JSON 为准重建即可。详见 `物理/工具/README.md` 第 8 节。

**Q：答案和老师讲的不一样？**
A：本工具的答案全部抄自原卷文末的「参考答案」，**以老师讲解为准**；答案有争议的题标了"自评"，不自动判分。每套卷的"备注"里记录了我们对原卷疑点的处理（例如第4周第10题：原卷答案表与图像矛盾，按原卷答案表保留，备注里写清了怎么问老师）。

**Q：概念卡为什么没有电学内容？**
A：这份题库里电学只占少数（第8、9 周各有几题），概念卡目前覆盖机械、功、内能与热学（120 张）。电学题仍可在「试卷练习」里正常做——原题、原卷答案、解析都在。

## 十、一个诚实的边界

工具能解决的是**流程缺失**：知道每一步该问什么、卡在哪一环。

如果孩子某一步反复错在同一个概念上（比如总把"力臂"当成"支点到作用点的距离"），那不是流程问题，是概念没通——这时要回到课本把概念重新讲一遍，再回来练。工具会把这个信号暴露出来（报告里最红的考点），但不替代讲概念。

另外：**图形题以原卷为准**。工具里显示的就是原卷裁图，不重画、不简化；个别题目跨页或图被裁得不完整时，请对照原始 docx。
