01

杠杆

题库里出现频率最高的模块（17 道题考平衡条件，12 道考五要素）。核心只有一句：力 × 力臂，两边相等；所有难题都是在这句话上换力臂、换支点。

杠杆平衡条件W1Q2
F1l1 = F2l2
动力 × 动力臂 = 阻力 × 阻力臂。静止或匀速转动即视为平衡，与力的方向无关。
力臂的定义W1Q15
l = 支点 O 到力的作用线的垂线段
不是 O 到作用点的连线。作图时垂足处必须标直角符号。
把力臂画成 OA、AB 的连线是整卷最高频的错法（W1Q4 的阻力臂是 OB，不是 OA 也不是 AB）。
斜拉力臂W1Q16
l1 = OB · sin α
力与杠杆成 α 角时，只有垂直于杠杆的分量产生力臂。α = 90° 时 l 最大，所需力最小。
α = 30° 时 l1 = L/2，正好与 l2 相等 → 变成等臂杠杆，别想当然判成省力。
杠杆分类W1Q1
l1 > l2 省力 · l1 = l2 等臂 · l1 < l2 费力
只看两力臂的长短，不看力的大小、方向、杠杆形状。省力必然费距离。
船桨、筷子、镊子、自拍杆都是费力杠杆——支点靠近用力的一端。
变形：求力W2Q3
F1 = F2l2 / l1
F1 与 l1 成反比：阻力不变时，动力臂越长越省力。
力矩与力矩变化W1Q6
M = F · l　　ΔM = G · Δl
两侧同时外移相同距离 Δl 时，重力大的一侧力矩增加得多 → 该端下沉。
比较的是 ΔM，不是比较力臂谁长、也不是比较谁移动得多。
均匀棒重心W1Q5
F · 2l = G · l → G = 2F，m = G/g
重心在中点，支点在没抬起的一端时，动力臂是阻力臂的 2 倍，抬起一端只需一半重力。
最后一步别忘了除以 g；选项里带 N 的是重力不是质量。
人体杠杆W2Q4
F · OB = G · OA
脚尖为支点，两个力都近似垂直于身体，力臂就是 OA、OB。手离支点越远，手撑的力越小。
多力平衡（含未知力）W2Q1
F = GM + GH　　F · AB = GH · x
先用力平衡判断该力是否独自撑住全部重物，再对支点取矩求位置 x。
支点选在“方向未知的那个力”的作用点上，这个力就不进力矩方程——这是最省事的技巧（W6Q8 同理）。
最小力W1Q2
作用点取离支点最远处，F ⊥ 杠杆 ⇔ l 最大 ⇔ F 最小
力臂最大时最省力。题目问“至少多大的力”就是让你这样取。
杆秤（换砣问题）W1Q3
m砣g · L = m物g · OA + M零g
m读 = (m砣 · L − M零) / OA
定盘星（零刻度）标定出杆和盘自重的力矩项 M零，之后才能反推读数。
换了秤砣不能直接 3 ÷ 0.8，必须先把零刻度找回来（本题 M零 = 2 kg·cm，读得 3.8 kg）。
杆秤刻度均匀W5AQ13
m ∝ x　（每 50 g 对应 5 cm → 250 g 在 26 cm）
平衡式对 L 是一次的，所以质量与力臂成正比，刻度等间距。可用比例直接换算。
平衡螺母调节W5AQ13
螺母向高的一端调
哪端翘起就往哪端移，把重心拉回支点上方。
02

滑轮与滑轮组

15 道题考定/动滑轮，12 道考滑轮组。所有结论都从两件事推出来：几段绳在吊着重物（n）、滑轮自身有多重（G动）。

定滑轮W1Q7
F = G　　s = h
轴不动。只改变力的方向，既不省力也不费距离。
动滑轮W1Q9
F = (G + G动) / 2　　s = 2h
省一半力，绳端走 2 倍距离。只有题目明确“不计滑轮重和摩擦”时才能写成 F = G/2。
漏掉 G动 是最常见失分：G=10 N、G动=1 N 时 F=5.5 N，不是 5 N。
滑轮组W5BQ11
F = (G + G动) / n　　s = nh
n = 吊着动滑轮的绳子段数。n = 2 省一半力，n = 3 省三分之二，方向由绕法决定。
数绳段数W5AQ15
n = s / h
题目给绳端移动距离和提升高度时，直接用这个式子反推 n，比数图更可靠。
反推动滑轮重W8Q17
G动 = nF − G
由 F = (G+G动)/n 变形。G动 在同一装置中不变，可用来算换重物后的效率。
最大提升重W6Q11
Gmax = n · Fmax
绳子最大承受力决定能吊多重。n = 2、Fmax = 3×10⁴ N → Gmax = 6×10⁴ N → m = 6000 kg。
算质量要再除以 g；水平移动那段重力不做功，别混进有用功。
同一根绳张力相等W1Q12
F1 = F2
不计绳重和摩擦时，同一根绳上各处拉力相同——两个测力计串在同一根绳上示数必然相同。
“串联”两个测力计不能分流，示数仍等于 G，照样超量程（W2Q7）。
绳速与功率W6Q12
v绳 = n · v物　　P = F · v绳
绳端速度是物体速度的 n 倍；已知拉力和绳速可不算功直接得功率。
绕线判断W8Q15
固定端系在动滑轮 → 向下拉且 n = 2；固定端系在定滑轮 → 向上拉
要“向下拉又省力”，绳的固定端必须拴在动滑轮的钩上。
03

功和功率

9 道题考功、9 道考功率。功率的一切比较都落到同一个分式：W 除以 t，所以“时间相同比功、功相同比时间”能省掉一半计算。

功的定义式W2Q10
W = F · s
F 与 s 必须同方向。重力方向竖直，所以水平移动时重力不做功。
水平拉物体时有用功是 f·s（克服摩擦），不是 G·s。
重力W1Q10
G = mg　（g 取 10 N/kg）
质量必须换成 kg：100 g = 0.1 kg → G = 1 N。
功率W2Q8
P = W / t
功率表示做功快慢，与做功多少、机械效率高低都无关。
不知道时间就无法比较功率大小（W5AQ5 的 D 项就是这样设的坑）。
功率的另一形式W6Q12
P = F · v
由 P = W/t = Fs/t 得到。汽车、起重机、绳端拉力的功率常用它。
由功率求功W8Q18
W = Pt
发电机、电加热器给的是功率，先乘时间得到能量，再进入效率计算。
注意“每台 / 总共”：3×10⁶ W × 3600 s = 1.08×10¹⁰ J 只是单台的量。
速度W5BQ14
v = s / t
斜面、滑轮组题的第一问常是求速度，注意 s 是沿运动方向的路程。
04

机械效率

全卷最高频模块，20 道题涉及。只有三条主干：η = W有/W总、W总 = W有 + W额、W有 只看目的（提货物就是 Gh，水平拉就是 fs）。三种装置各有一套变形。

效率定义W2Q11
η = W有 / W总 × 100%
有用功占总功的比例。效率永远小于 1（无单位，不是“效率多少焦”）。
功的分解W2Q8
W总 = W有 + W额　　W有 = W总 − W额
甲 1200−800 = 400 J，乙 800−400 = 400 J：有用功相同，效率却差一倍。
比较机械效率要回到 W有/W总 这个比值，不能只看总功或只看额外功。
竖直滑轮组效率W8Q17
η = Gh / (Fs) = G / (nF) = G / (G + G动)
三个式子等价，按题目给的数据挑一个用。第三式说明效率只由物重和动滑轮重决定。
0.6 = G/(G+20) → G = 30 N：解这个方程比绕一圈算功更快。
滑轮组最大效率W5AQ15
ηmax = Gmax / (Gmax + G动)
同一装置，物重越大效率越高（额外功几乎不变）。Gmax 由绳的最大承受力决定。
水平拉物体效率W2Q10
W有 = f · s　　η = fs / (Fs)
目的是克服摩擦力移动物体，所以有用功是 f·s；重力与位移垂直，不做功。
斜面三式W2Q9
W有 = Gh　　W总 = Fs　　η = Gh / (Fs)
s 是沿斜面移动的距离（长），h 是高度（短），h = s·sinθ（θ = 30° 时 h = s/2）。
写成 F₁s/(F₂h) 是最经典的错法——有用功里永远只有 h，总功里永远只有 s。
斜面摩擦阻力W5BQ6
W额 = W总 − W有 = fs → f = W额 / s
额外功全部用来克服斜面摩擦，所以除以斜面长 s，不是除以 h。
滑动摩擦力与速度无关，所以斜面效率也不随速度改变（仍是 75%）。
由图求总功W6Q10
W总 = W额 ÷ 额外功占比
扇形图/条形图给出各项损失比例时，先用“额外功 ÷ 它占的比例”还原总功，再求有用功。
甲：3000 J ÷ 60% = 5000 J，有用功 = 2000 J 而不是 3000 J。
三个反推W2Q14
W总 = W有 / η　　h = W有 / G　　m = G / g
综合题的标准链条：m ← G ← W有 = Gh ← W总 = W有/η ← P = W总/t ← F = W总/s。
效率与物重的关系W5AQ10
W有 = Gh 不变时，W额 ↑ → η ↓
同一重物同一高度，效率升高只说明额外功变少（装置更轻、润滑更好），有用功并没变。
05

分子动理论与内能

11 道题考内能、8 道考分子动理论。这一块几乎全是概念判断，公式少但要分清三对词：温度 / 热量 / 内能，分子 / 颗粒，做功 / 热传递。

内能的组成W4Q8
内能 = 分子动能 + 分子势能
一切物体在任何温度下都有内能，0℃ 的冰也有。内能由温度、质量、状态共同决定。
温度高但质量小，内能不一定大（W8Q13：无法比较，选“不能确定”）。
温度与分子动能W5AQ6
T ↑ → 分子平均动能 ↑ → 分子热运动加剧
温度是分子平均动能的标志。这是“温度升高内能一定增大”的依据。
改变内能的两条路W9Q1
做功 W　／　热传递 Q
摩擦、压缩、敲打、弯折 = 做功；加热、冷却、接触 = 热传递。
两者对改变内能是等效的，内能增加不一定是吸了热（也可能外界对它做了功）。
热传递三要素W4Q7
条件：存在温度差　方向：高温 → 低温　传递的是热量 Q
传递的是内能（热量），不是温度。温度相同就不发生热传递。
“甲向乙传热”只能推出甲温度高，推不出甲内能大。图线还在降温，说明环境温度比末温更低。
压缩气体做功W5AQ11
外界对气体做功 → 内能 ↑ → 温度 ↑
达到着火点即可点燃（压缩空气引火仪）。等温压缩则是“做功的同时向外放热”，内能不变。
扩散现象W4Q4
扩散 = 分子无规则运动 + 分子间有间隙
闻到气味、墨水散开、两种气体自动混匀都是扩散；分子运动永不停止。
雪花、灰尘、雾、细菌是“大量分子组成的颗粒”，它们的运动是机械运动，不是分子运动。
分子间的作用力W5AQ2
引力与斥力同时存在，看哪个起主要作用
拉不开 / 弹簧测力计示数变大 / 两铅柱粘住 → 引力为主；很难被压缩 → 斥力为主。
“只有引力”“分子间没有间隙”都是错误表述。
热胀冷缩W6Q04
ρ = m / V
温度升高体积变大 → 密度变小；质量不变，温度升高内能增大。
机械能W6Q03
Ek = ½mv2　　Ep = mgh　　E机 = Ek + Ep
匀速 → 动能不变；下降 → 重力势能减小。克服阻力做功时机械能转化为内能，总量减少。
06

比热容

13 道题考比热容、15 道考热量计算。整块内容就是一个式子 Q = cmΔt 的四种用法：求热量、求 c、求 Δt、求质量。

吸放热公式W4Q9
Q = cmΔt
Q吸 = cm(t − t0)　　Q放 = cm(t0 − t)
Δt 是温度变化量（大减小，永远为正），不是末温。
质量必须换成 kg：4.2×10³ × 0.001 × 1 = 4.2 J，用 1 g 直接算会差 1000 倍。
求比热容W4Q11
c = Q / (mΔt)
单位 J/(kg·℃)。1.26×10⁴ ÷ (2×3) = 2.1×10³ J/(kg·℃)，对应冰或煤油。
求温度变化W4Q13
Δt = Q / (cm)　　t末 = t初 + Δt
反解出来的是变化量，必须加回初温，并检查是否超过沸点（标准大气压 100℃）。
算到 20+80=100℃ 就到顶了，若超过 100℃ 说明水已沸腾、温度不再上升。
热平衡方程W4Q12
Q吸 = Q放　（不计热损失）
混合、热传递题的通用式。温度—时间图上，两条曲线最终趋于同一温度。
绝热容器里两组物质比较时用 cAmAΔtA = cBmBΔtB 反推 c 的大小。
加热器给热W5AQ12
Q = Pt
同一热源、相同加热时间 → 吸收热量相同。这是“比较比热容”实验的控制变量核心。
图线陡不陡反映的是比热容小（升温快），不是“吸热多”。功率不同时更不能比陡峭程度。
比热容的性质W4Q5
c 只由物质种类和状态决定
与质量、温度、形状、吸放热多少都无关。水 → 冰，状态变了 c 才变（冰约 2.1×10³）。
同样 Q、同样 m 时，Δt 小的那个 c 大（升温慢 = 比热容大）。
07

燃料热值

12 道题涉及。关键判断只有一条：固体液体用质量，气体用体积；热值是燃料自身的属性，与燃烧是否充分无关。

固体 / 液体燃料W5AQ14
Q放 = mq　（q 单位 J/kg）
完全燃烧放出的热量。酒精、焦炭、柴油都用这个式子。
气体燃料W5BQ15
Q放 = qV　（q 单位 J/m³）
天然气、煤气按体积算：3×10⁷ × 1.8 = 5.4×10⁷ J。
气体燃料写成 qm 是失分点；燃气表题给的是“两次读数之差”即用气体积。
热值的定义W9Q11
q = Q / m　（或 q = Q / V）
1 kg（或 1 m³）燃料完全燃烧放出的热量。食物用“每 100 g 多少千卡”表达的是同一含义。
热值与是否充分燃烧无关，烧不完只是“放出的热量少”，q 本身不变。
热值与比热容的区别W5AQ1
q：放热本领（J/kg）　　c：升温难易（J/(kg·℃)）
选火箭燃料、选“燃料好坏”看 q；选暖手宝液体、选冷却剂看 c。
08

热机与能量转化

9 道题考热机效率、7 道考能量守恒。效率的分母永远是燃料完全燃烧放出的热量，分子是你想要的那部分能量。

热机效率W8Q16
η = Q吸 / Q放 = W有用 / Q放
锅炉题分子是水吸收的热量，汽车题分子是输出的机械功，分母都是燃料放热。
只烧了 0.1 kg 时效率从 3.5% 变成 35%——分母变小，不能拿总消耗量算比。
效率链W8Q18
W有用 = η · Q放　　Q放 = W总 / η　　m = Q放 / q
发电机组耗煤量的标准解法：先 W=Pt，再除效率得放热，最后除以 q 得质量。
能量流向图W6Q10
η = 100% − 各项损失占比
100% − 33% − 30% − 7% = 30%，再乘 Q放 得有用功。
四个冲程W9Q3
吸气 → 压缩 → 做功 → 排气
压缩：机械能 → 内能；做功：内能 → 机械能（内能对外做功，温度降低）。
压缩、排气靠飞轮惯性；只有做功冲程是燃气推动活塞对外做功。化学能 → 内能只发生在做功冲程点火后。
能量守恒W5AQ4
E总 不变：E输入 = E有用 + E损失
能量只能转移或转化，不能凭空产生、也不能消失。
“守恒”不等于“没有损失”，散失的内能不能自动再用来做功；凡是“不需要能量”的说法都违反守恒。
常见能量转化W5BQ5
燃烧：化学能 → 内能　热机：内能 → 机械能
充电：电能 → 化学能　供电：化学能 → 电能　植物：光能 → 化学能
逐个核对装置再选，别把发电机/电动机当成热机。
09

电学初步

题库后半段夹带的电学小题（6 道），都是定性判断加一个并联电流公式，属于送分但要细心。

电荷间的相互作用W8Q3
同种电荷相斥，异种电荷相吸；带电体吸引轻小物体
排斥能确定“同种”，吸引只能说“可能”——被吸引的物体可能带异种电荷，也可能不带电。
电流方向W8Q12
电流方向 = 正电荷定向移动方向 = 电子移动方向的反方向
电子从 B 跑到 A，则电流从 A 经外部电路流向 B（M → N）。
并联电流W9Q8
I = I1 + I2
干路电流等于各支路之和；各支路互不影响，拆掉一条另一条仍工作。
同一指针 0~3 A 档读数是 0~0.6 A 档的 5 倍：指 0.3 实为 1.5 A，再减支路 0.5 A 得 1.0 A。
开关位置W9Q7
与谁串联就控制谁；在干路上控制全部
判断电路要先顺着电流找分支：有分支就是并联，无分支就是串联。
压强与单位换算W5AQ11
