## 八、每次改动后要跑的闸门（缺一不可）

```powershell
# 一条命令跑全部闸门（自动探测 node/python，换电脑不用改路径）
pwsh -File 物理\工具\check.ps1

# 或者手动逐步：
node 物理\工具\build.mjs            # 1) 结构与数据校验 + 生成页面
python 物理\工具\check_answers.py   # 2) 选择题答案 vs docx 答案表（必须「全部一致 ✓」）
python 物理\工具\audit_packs.py     # 3) 每题是否有原题图 / 答案
node 物理\工具\核验报告.mjs         # 4) 重新生成本文件
```

> 没装 Python 时：前两项可跑，答案体检会跳过（`check.ps1 -NoPython`）。装依赖：`python -m pip install python-docx`。
