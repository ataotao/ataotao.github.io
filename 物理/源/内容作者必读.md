# 内容作者必读（把一套周练做成题包）

> 目标：把 `物理/题库/第N周.docx` 变成 `物理/题库/pack-wN.json`，让工具能拿着原题训练学生。
> 配套规范：`物理/源/SPEC.md`（字段定义、考点清单、验收标准）。

## 一、你手上会有什么

1. **原题素材**：`物理/_recon/raw/<packId>.json`（和同名 `.md`）
   每题包含：题号、类型、题干文本（`[图]`/`[式]` 表示这里有图片/公式，要看图）、选项、答案键、答案文本、原题图路径、参考答案图路径。
2. **原题裁图**：`物理/图片/<packId>/q01.png`、`q01-a.png`（答案图）
3. **规范**：`物理/源/SPEC.md` + 模板 `物理/题库/pack-模板.json`

## 二、流程（一题一题来，别整卷一次写完）

1. 打开 `_recon/raw/<packId>.md` 通读一遍，标出哪几题要看图（带 `[图]` 的、选择题选项里有 `[图]` 的、解答题有图的）。
2. 对每一题：
   - 看 `qNN.png`（必要时 `read_image`）确认题意；
   - 看 `qNN-a.png` 拿到**原卷答案**（这是权威答案，不要自己另算一个）；
   - 写 question：`askImg`、`ask`（纯文本，能抄就抄）、`opts`/`ans`（选择）或 `fields`（填空/解答，把答案里的最终数值拆成字段）；
   - 写 `solution` 2–4 条（原卷有【详解】就转写；没有就写"下一步该想什么"），`tip` 一句话关键；
   - 选 `focus`（这题最容易断在第几步）、`tags`（1–3 个，必须从清单选）、`diff`（1–3）。
3. 全部写完：在仓库根运行 `node 物理/工具/build.mjs`（`node` 不在 PATH 时直接跑 `pwsh -File 物理/工具/check.ps1`，它会自动找 node/python 并跑完所有检查）。校验报错就按提示改。
4. 截图自查：`pwsh -NoProfile -File 物理/工具/shot.ps1 -Hash "exam/<packId>" -W 1280 -H 1200 -Out 物理/_recon/<packId>.png`，用 `read_image` 看两三题是否正常显示原题图与答案。

## 三、判分字段怎么写（物理专用）

| 情况 | 写法 |
|---|---|
| 一个数值答案 | `{"type":"num","label":"拉力 F =","ans":30,"unit":"N","tol":0.01}` |
| 百分数答案 | 写数字本身：η=80% → `"ans":80,"unit":"%"`；若答案是 0.8，则 `"ans":0.8` |
| 科学计数法 | `"ans":8400`（学生填 8.4×10³ 也能判对） |
| 带式子的多空 | `{"type":"coef","label":"重力","tpl":"G = {0} N","ans":[20]}` |
| 文字答案（如"改变力的方向"） | `{"type":"text","label":"好处","ans":["改变力的方向","改变力的作用方向"],"mode":"contains"}` |
| 画图/说理/答案不唯一 | 整题 `"type":"selfcheck","selfCheck":true`，只给 `ansImg`+`solution`，不判分 |

**只填"能唯一判定的最终答案"**。中间过程写进 `solution`，不要做成字段。
一个解答题多个问：按 (1)(2)(3) 拆成多个 fields，全部答对才算这题对。

## 四、答案正确性（最重要）

- 选择题：以文末表格的答案键为准（raw.json 里的 `answerKey`）。多选（如 "BC"）→ `"ans":[1,2]`。
- 填空/解答：以 `qNN-a.png` 上的原卷答案为准。**看不清就去看高清原图**（页图在 `_recon/pages/<packId>/`）；还看不清就标 `selfCheck` 并在 `note` 里写"答案以原卷为准"，不要猜。
- 你**不可以**为了"答案好看"改动原卷答案。发现原卷答案有疑点，写进题包 `note` 字段交给 Lead。

## 五、解析（solution）写法

不是写标准答案，是写**下一句该想什么**。2–4 条，每条一句话，尽量口语：

```
["看到「匀速」先写平衡：F = f = 20 N",
 "滑轮组 n=2，绳端移动 s = 2h = 4 m",
 "W总 = Fs = 20×4 = 80 J，η = W有/W总 = 60/80 = 75%"]
```

`tip` 只写一句最容易错的地方：`"别把 s 和 h 搞混，s = nh"`。

## 六、focus 怎么定（这题最容易断在哪）

- `model`：认不出模型/概念边界（温度/热量/内能混、定滑轮/动滑轮混）
- `cond`：条件没读全、隐含条件漏（不计摩擦、匀速、正常工作、标准大气压）
- `rule`：公式选错、用错适用条件（η=W有/W总 里谁是有用功）
- `calc`：单位换算出错、公式变形错、算错
- `check`：结论离奇没发现（效率>100%、速度 100 m/s、质量 0.5 g）

一题只选一个**主要的** focus。
