用 Chrome headless + 注入探针实跑，核对五个页面是否也存在物理的 2 个问题。结论：

| 页面 | 构建方式 | 问题1（回访锁定/直接给答案） | 问题2（无累计错次/改对即消失） |
|---|---|---|---|
| 物理思维脚手架 | 源/ + 工具/build.mjs | 有 → 已修 | 有 → 已修 |
| 历史·核心考点训练（⑥套卷） | 工具/core-template.html + 工具/build.mjs | **有**：`S.paper.log[qid]` 永久 done → 选项 disabled、答案+解析直显；无「重做本题」 | 无：`P.paper[qid].wrong` 累计，`streak<2` 才出「只做错题」池；但 UI 不显示累计错次 |
| 道德与法治·核心考点训练 | 同上 | 无套卷数据（DATA.paper 不存在）；卡片四种模式不存作答，上一题回来是空白 | 同上（有累计，无展示） |
| 数学·函数思维脚手架 | 单文件（无源） | 无：`openPaperQ()` 每次新建 `S.pq`（sel=null/ent={}/phase=ask） | 有累计历史 `DB.paper`（append），但错题本按历史 false 记录、无累计错次、无重做入口 |
| 英语·九上英语过关练习 | 练习工具/build.mjs | **部分**：已答 → 选项 disabled + 解析自动展开；有「重做本题」，但**当场答完不出现**，要切视图/刷新才出现 | 有累计缺口：错题本无累计错次；仅"练习错"的题改对后即从错题本消失（原卷错的永久留） |
| 公式记背 | 工具/formula-template.html | 无：`S.fillCard` 变化即重置，不落库 | 同上（有 p.wrong，无展示；连对2次出库） |

要点：

- 历史套卷的逃生口只有「从头开始」（清整轮 log）或切范围到「只做错题」（`buildPaper` 会 `log={}`），没有单题重做。
- 探针脚本：`_verify/mk-probe-history.mjs`、`_verify/mk-probe-others.mjs`（生成注入页后用 chrome --dump-dom 读结果）。

## 实际改造（用户勾选全部四项，已完成并逐项验证）

- **历史 ⑥套卷**（`工具/core-template.html` → `node 工具/build.mjs` 重建 道法+历史）：

### 补充：道法/历史 卡片模式的累计错次
- 数据层有：`P.cards[id]={seen,ok,wrong,streak,last,mode}`，答错 `wrong++`，答对不复位（仅填空模式「我其实答对了（算对）」会 `wrong-1`）。
- 展示层几乎没有：只有 ⑤清单 顶部「最该补的 10 张」写「错 N 次」；练习题头、④错题强化题干都不显示。
- 错题池：④错题强化 = `wrong>0 && streak<2`（连对 2 次自动出库，无手动清、无错题本列表页）；出库后 wrong 保留，再错重新入池继续累加。
- 实测（连错 3 次）：`{"seen":3,"ok":0,"wrong":3,"streak":0}`，清单显示「错 3 次」。

### 追加：④错题强化 里补「试卷错题」区块（历史）
- 用户反馈"历史的错题没出现在④错题强化栏"——原因：④ 的队列只来自 `DATA.cards`，套卷错题在 `P.paper`，两套数据。
- 新增 `paperWrongSection()` / `appendPaperWrong(st)`：`render()` 在 `S.mode==='wrong'` 时追加一块「试卷错题（N 道）」，每行 题号·单元·累计错·「回炉这题」；顶部「打开套卷错题本 →」。空态文案改为"考点卡这边清空了，下面还有 N 道试卷错题"。
- 「回炉这题」→ `S.mode='paper'; range='weak'; buildPaper(); 定位到该题; echo=null`。
- 坑：`.row` 类只在 `.bar .row` 里定义了 flex，卡片里用 `<div class="row">` 不会横排 → 需要显式 `style="display:flex..."`。
