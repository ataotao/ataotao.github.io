## 复核：物理训练「报错」实为缓存（21:55）

- 线上 200、与本地 `diff --strip-trailing-cr` 0 差异；无头 Chrome 渲染正常（DOM 131 KB）。
- 用 CDP 真点了一遍：物理五个模块切换正常，出题后 `svg=1 / 图形元素 22`；数学三个模块正常；
  控制台唯一报错是 `/favicon.ico` 404（站点根只有 favicon.png，无害）。
- 结论：用户看到的是构建窗口期抓到的 503 被浏览器/Fastly 留住（`Cache-Control: max-age=600`），硬刷新即可。
- 排查手法（可复用）：`chrome --headless=new --remote-debugging-port=9333` + Node 全局 WebSocket 走 CDP，
  `Runtime.enable` + `Runtime.exceptionThrown` 收异常，再 `Runtime.evaluate` 点按钮、数 `svg`。临时脚本用完即删，不入库。
