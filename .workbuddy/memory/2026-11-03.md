## 物理思维脚手架：试卷练习「重做」与「累计错次」

- 问题定位（用户反馈 2 条均复现）：
  1. 试卷题再进来会带着上次的选项/填空（choiceArea/fieldsArea 直接吃 `rec`），且 `renderQ` 无条件回显判分+解析 → 看起来「已选中、无法重做」。
  2. 试卷错题在 `examAnswer` 里一答对就 `delWrong` 清掉，且没有累计字段，导致改对后无法反复回炉。
- 改法：
  - `源/js/00-core.js` `PHYS.progress.examAnswer`：新增 `okN / wrongN / lastOkAt / lastWrongAt`，`wrong` 条目记 `n=累计错次`、`lastOk`；**答对不再自动清错题**（与概念错卡一致），只由用户在「错题回炉」勾「我会了」手动清。
  - `源/js/50-exam.js`：
    - 新增 `cumWrong/cumOk/inWrongBook/wrongIdxOf`（老记录兜底从 ok/tries 估起点）。
    - `renderQ` 引入 `V.echo`：只有刚提交完或主动点「看上次的答案与解析」才回显；其余一律空白作答，并给提示条「这题上次做错，累计错 N 次」+ 重做/看解析按钮。上一题/下一题/跳题清空 echo。
    - `packStat` 增 `wrongBook / cumWrong`；题包卡标签改为「N 道还错着 / 已改对·错题本还有 N 道」，按钮「回炉错题 N 道」。
    - 题头、题号清单 tooltip、整卷结果、错题本、首页最近错题都显示「累计错 N 次 · 已做 N 次 · 对 N 次」；结果页新增「已改对但仍留在错题本」区块。
  - `源/js/20-shell.js` 首页错题行加累计错次；`使用说明.md` 同步语义。
- 后续微调（用户要求）：重做提示条**不显示「你上次填的是：A」**——上次作答只在提交后回显或点「看上次的答案与解析」时出现在解析区，避免提示条提前泄底。
- 关键约定：`物理/物理思维脚手架.html` 由 `node 物理/工具/build.mjs` 从 `源/` 生成，**改页面必须改 `源/js/*.js` 再构建**，否则会被覆盖。
