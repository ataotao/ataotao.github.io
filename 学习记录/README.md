# 学习记录（导出归档）

这个目录是各科训练器「导出记录」的落点。训练台插件（`工具/dsh-plugin/`）只读这里，
算出分科正确率、薄弱知识点、连续天数。

## 为什么要把记录导出来

孩子的作答记录存在浏览器 `localStorage` 里：清缓存、换电脑、换浏览器就没了，
也没法和历史比。导出成 JSON 放进仓库，就等于给学习过程留了一份可回溯、可统计的档案。

## 怎么导出

各科页面都是单文件 HTML，双击打开，找到「导出记录」按钮（物理在报告页 ⑤「记录（换设备用）」）：

| 科目 | 页面 | 按钮 | 默认文件名 |
|---|---|---|---|
| 历史 | `历史/核心考点训练.html` | 导出记录 | `历史-练习记录-YYYY-MM-DD.json` |
| 道德与法治 | `道德与法治/核心考点训练.html` | 导出记录 | `道德与法治-练习记录-YYYY-MM-DD.json` |
| 公式记背 | `公式记背/公式记背.html` | 导出记录 | `数学-公式记录-YYYY-MM-DD.json` |
| 物理 | `物理/物理思维脚手架.html` | 报告页 ⑤ → 导出记录（JSON） | `物理训练记录-YYYY-MM-DD.json` |
| 数学·函数脚手架 | `数学/函数思维脚手架.html` | 训练报告页 → 导出记录（JSON） | `数学-函数脚手架-记录-YYYY-MM-DD.json` |
| 英语 | `英语/九上英语过关练习.html` | 错题本 / 页脚 → 导出记录（JSON） | `英语-练习记录-YYYY-MM-DD.json` |
| 数学·今晚急救包 | `数学/今晚急救包.html` | ⚠️ 仍无记录导出（临时应急包，暂不纳入统计） | — |

把导出的文件直接放进本目录即可，**文件名不用改**（插件按内容识别，文件名只作科目兜底）。

> 更省事的做法：打开仓库根的 `开始.html`，点「备份全部记录」——它会把六科记录打成一个
> `全部记录-YYYY-MM-DD.json`（`kind:"backup"`），拖进本目录即可，训练台会自动拆成各科统计。
每周或每次集中练习后导一次，建议同一天导一次即可。
导出有两种形态，插件按**内容嗅探**都认（不靠文件名）：

- **带外壳**：`schema: "lt.practice-records/1"`，`data` 里是原始 store ——
  函数思维脚手架、坐标图象训练、英语两份、语文思维脚手架、`开始.html` 的「备份全部记录」；
- **裸 DB**：`{v:1, recs, wrong, meta[, days]}` —— **物理闪练卡、数学闪练卡、化学闪练卡**。

> 2026-11-18 实测更正：这里此前写的是「所有科目的导出都带外壳」，不对。上面三份训练器
> 从来没有外壳，直接吐 `localStorage` 里的原样结构（在三份训练器里搜 `lt.practice-records`
> 与 `schema:` 均零匹配）。导入实现必须两种都收。

## 插件怎么统计

- 每个「科目 + 工具」只采用**最新一份**快照（导出是整份覆盖，不是增量）；
  旧文件保留但会标「旧快照，统计时只取最新一份」，不会被重复累加。
- 正确率 = 累计答对 ÷ 累计作答；薄弱知识点优先按单元/题包聚合（插件用仓库里的
  `考点数据.json`、`物理/题库/pack-*.json` 补 id → 单元映射）。
- **首次就答对**：历史/道法/公式从 2026-11-04 之后的新作答开始记（记录里 `firstOk`）；
  更早的记录没有这个字段，只算累计正确率。
- 连续天数、按天练习量：历史/道法/公式/物理用记录里的 `days`；
  函数脚手架与英语用逐次时间戳现算（英语的 `at`/`atList` 是 2026-11-04 之后才有）。

## 已知限制（见 `docs/plans/学习记录格式清点.md`）

- 历史 / 道法 / 公式记背只有累计计数，没有逐次事件 → 时间线只能到「按天」；首次正确率靠
  `firstOk` 字段（本次改造后才开始累积）。
- 急救包没有导出，暂时进不了统计。
- 记录文件不含题目元数据，单元映射靠仓库现有 JSON；改了考点 id 后旧记录会归到 id。
- 各科导入都是整份覆盖，不合并两台设备的记录。

## 隐私

记录里是孩子自己的作答数据。**合并进 `ataotao/ataotao.github.io` 之后，本目录所在仓库是公开的**
（它对外发 Pages），所以：

- 真实作答记录**不再提交到本目录**，改放进私有的数据仓 `learning-records`（见 ADR-0007）：
  私有仓 `ataotao/ataotao.github.io_learning-records`，本机 clone 在 `C:/learn/ataotao.github.io_learning-records`；
  `raw/` 放历史导出种子（只增不改），`devices/` 放各设备快照。可用环境变量 `LT_RECORDS_DIR` 覆盖根目录。
- 本目录只留这份说明；`.gitignore` 已排除本目录下所有 JSON，防误提交；
- 历史导出只进私有仓，**绝不进站点仓**——这是硬约束，不是习惯。
