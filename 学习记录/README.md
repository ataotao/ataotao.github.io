# 学习记录（导出归档）

这个目录是各科训练器「导出记录」的落点。训练台插件（`工具/dsh-plugin/`）只读这里，
算出分科正确率、薄弱知识点、连续天数。

## 为什么要把记录导出来

孩子的作答记录存在浏览器 `localStorage` 里：清缓存、换电脑、换浏览器就没了，
也没法和历史比。导出成 JSON 放进仓库，就等于给学习过程留了一份可回溯、可统计的档案。

## 怎么导出

各科页面都是单文件 HTML，双击打开，找到「导出记录」按钮（物理在报告页 ⑤「记录（换设备用）」）：

| 科目 | 页面 | 按钮 | 默认文件名 |
|---|---|---|---|
| 历史 | `历史/核心考点训练.html` | 导出记录 | `历史-练习记录-YYYY-MM-DD.json` |
| 道德与法治 | `道德与法治/核心考点训练.html` | 导出记录 | `道德与法治-练习记录-YYYY-MM-DD.json` |
| 公式记背 | `公式记背/公式记背.html` | 导出记录 | `数学-公式记录-YYYY-MM-DD.json` |
| 物理 | `物理/物理思维脚手架.html` | 报告页 ⑤ → 导出记录（JSON） | `物理训练记录-YYYY-MM-DD.json` |
| 数学·函数脚手架 | `数学/函数思维脚手架.html` | ⚠️ 目前只能导出 TXT 报告 | — |
| 数学·急救包 / 英语 | — | ⚠️ 目前没有记录导出 | — |

把导出的文件直接放进本目录即可，**文件名不用改**（插件按内容识别，文件名只作科目兜底）。
每周或每次集中练习后导一次，建议同一天导一次即可。

## 插件怎么统计

- 每个「科目 + 工具」只采用**最新一份**快照（导出是整份覆盖，不是增量）；
  旧文件保留但会标「旧快照，统计时只取最新一份」，不会被重复累加。
- 正确率 = 累计答对 ÷ 累计作答；薄弱知识点优先按单元/题包聚合（插件用仓库里的
  `考点数据.json`、`物理/题库/pack-*.json` 补 id → 单元映射）。
- 连续天数、按天练习量来自各科记录里的 `days` 计数。

## 已知限制（见 `docs/plans/学习记录格式清点.md`）

- 历史 / 道法 / 公式记背只有累计计数，没有逐次事件 → 算不出「第一次就答对」和时间线。
- 函数脚手架数据最细（逐次事件 + 用时），但只导出 TXT；英语只有错题 Markdown；
  急救包没有导出。这三项需要改各自 HTML，属于后续增强。
- 记录文件不含题目元数据，单元映射靠仓库现有 JSON；改了考点 id 后旧记录会归到 id。

## 隐私

记录里是孩子自己的作答数据。本仓库是私有仓库；不要把这些文件贴到公开渠道。
