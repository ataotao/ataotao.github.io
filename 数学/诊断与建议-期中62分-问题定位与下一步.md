## 0 结论先行

1. **「读图」没问题，问题在「写式」。** 选择 32/40（80%）；坐标图象训练 90%。
   但凡是「从文字/条件写出解析式、设元列式」的题（14、15、20、21、23，共 **44 分**），只拿到 **3 分（6.8%）**。
2. **最后 40 分大概率没动笔，不是不会。** 23/24/25 全 0，而 23(1)（60−x、1.5x，2 分）和
   25(1)（把 x=2 代进 y=x²−2x−7，3 分）是**读题即写**的点，24(1)（∠BPC=15°，2 分）也只是两步角度推导。
   17 题满分、19 题判别式 6/8 的孩子，不可能连「代个值」都不会——这是**考场调度**问题，不是知识问题。
3. **「90%」不能当「函数图象没问题」的证据。** 那份工具测的是「坐标↔格点」的点击动作：
   五层全部参数化生成、全部点选/数字条作答，**零处要求写解析式、零处画图、无分段、无反比例、无交点计算**；
   90% 的分母是单轮 10 题（9/10），95% 置信区间约 **60%–98%**。
4. **下一步不是再做一个「函数图像」工具**，而是补两个方向：
   **① 写解析式（生成方向）**、**② 大题前两步 + 限时调度**。
   `函数思维脚手架` 的「录得分 / 分步判分」能接住数据，但这两个训练入口它没有。
5. **先做一件事：拍答题卡 23–25 那两页。** 空白 → 时间问题；写了 → 建模问题。
   这一张照片决定接下来两周练什么，比任何分析都值钱。

## 2 为什么「90%」和「函数题几乎全丢」不矛盾

家长的原假设是「函数图象基础太差」，但工具测出 90%。两者不矛盾，因为**测的不是同一件事**：

| 维度 | 坐标图象训练.html | 期中卷 21–25 |
|---|---|---|
| 输入 | 已经画好的图 / 已给坐标 | 文字情境、条件、参数 |
| 输出 | 点一个点、填两个数字、选一个选项 | **写出解析式、写出过程、求范围/最值** |
| 认知动作 | 识别（读图 → 判断） | **生成**（条件 → 式子）+ 多步串联 |
| 判分 | 整题全对（不认部分分） | 分步给分（写对一步就有分） |
| 时间 | 无限时，无每题计时 | 120 分钟 150 分，限时 |
| 覆盖 | 坐标↔格点、k/b 字面意义 | 反比例、分段、交点面积、利润建模、含参二次、几何旋转 |

三个直接证据（来自代码审计）：

1. **零处「写式」**：全文交互只有画布 tap、数字条、选项按钮三种；没有输入框，没有「写出解析式」，
   也没有作图判分。L3 的直线是代码自动画的，孩子只点一个点。
2. **零处「分段 / 反比例 / 交点」**：grep 全文无「分段」「k/x」「判别式」「平移」。
   20、22 这两道共 18 分的题，工具里没有对应入口。
3. **90% 的样本只有 10 题**：结算页分母是本轮题数（L1/L2 = 10 题），6 题层只可能出 83%/100%。
   9/10 的 95% 置信区间约 60%–98%。**1 题就是 10 个百分点**，这个数字本身不稳。

**所以 90% 能推出**：在 −6…6 整数格点上，「坐标→位置」「位置→坐标」这个动作已经自动化；
62 分卷里 5、6、11、13 一类题不再卡在「点不出」。
**不能推出**：由条件写解析式、作图、图象信息建模、含参讨论、限时稳定性、分步得分——这六件事工具里都没有入口。

> 一句话：**孩子「认得出图」，但「造不出式」。** 期中卷的函数题，考的是后者。

## 3 三个真实断点（对着题号说）

### 3.1 生成断点：文字/条件 → 解析式（44 分拿 3 分）

| 题 | 要求的第一步 | 孩子拿到 |
|---|---|---:|
| 14 | 建系 → 设抛物线 → 代点求灯距 | 0/4 |
| 15 | 由 S(x) 求停止时间 + 最后 2 秒距离 | 0/4 |
| 20 | 反比例段 y=k/x 代点求 k + 写范围 | 2/8 |
| 21 | 顶点式 y=a(x−h)²+k 代点求 a | 1/8 |
| 23 | 用 x 表示盈利 (60−x)、销量 (30+1.5x)，再列 W(x) | 0/12 |

共同点：题目给的是**情境/条件**，要求「先设、再列、再求」。孩子停在「求出几个点」，没到「写出式子」。
这不是计算问题（17 题满分证明计算没问题），是**表征转换**问题：把文字/图形语言翻成代数语言。

### 3.2 调度断点：最后 40 分没走到（其中 7 分不该是 0 分）

23/24/25 三题共 40 分，得 0。但：

- 23(1)：降价 x 元 → 每把盈利 **60−x** 元；每降 2 元多售 3 把，所以降价 x 元多售 **(x/2)×3 = 1.5x** 把。两个空，各 1 分。
- 24(1)：正方形 + 等边三角形，求 ∠BPC = 15°。2 分，两步角度推导。
- 25(1)：a=−1 时把 x=2 代进 y=x²−2x−7 得 −7，再判断 (2,−6) 不在图象上。3 分。

这 7 分里，23(1) 和 25(1) 是「读题即写」，24(1) 是「两行推导」；对 17 题满分的孩子都不该是 0 分。
全 0 只有一个合理解释：**没写到**。
最可能的时间黑洞是填空 14/15/16（两道应用建模 + 一道新定义压轴填空），
这三题既是失分点，又是耗时点——**花了很多时间，还没拿到分**，然后把后面 40 分挤掉了。

### 3.3 分步断点：解答题 86 分拿 22 分

解答题得分率 25.6%。丢掉的 64 分里，有相当一部分不是「不会」，是「没写完整 / 最后一问没做」：
18(2)、19(2)、20(2)、22(2) 都是「前面会、最后一步断」。
考试是分步给分的，**写对一步就有 1–3 分**；空着是 0 分，写错也是 0 分，但写对一步不是。

## 4 先做一个 10 分钟判别实验（再决定练什么）

现在有两种可能：**时间不够**（没写到）或 **建模不会**（写了但错）。两者练法完全不同，先分开。

**实验 A（1 分钟，最重要）**：翻答题卡 23–25 那两页。
- **空白** → 时间/调度问题：优先做 5.1 的 P3（限时整卷）+ 5.4 的「3 分钟跳题」规则。
- **写了** → 建模/入口问题：优先做 5.1 的 P2（写解析式 + 前两步）。

**实验 B（10 分钟，如果答题卡不在手边）**：让孩子做 23 题，原卷、不限时、不给提示。

| 观察点 | 说明什么 |
|---|---|
| 23(1) 写出 60−x、1.5x | 会读题、会代数表达 |
| 23(2) 列出 (60−x)(30+1.5x)=2250，解出 x=10 / 30，按「让顾客实惠」取 30 | 会列式、会解方程、会取舍 |
| 23(3) 由 30+1.5x≤57 得 x≤18 且为偶数，x=18 时 W=2394 | 会范围约束下的最值 |

- 三问都会 → 考场上「没写到」，问题在调度（时间分配 + 跳题策略）。
- (1) 会、(2) 不会 → 建模断点（列式），练「设元列式」。
- (1) 都不会 → 读题/表达断点，练「用 x 表示」的最基础动作。

同时让孩子把 21(1) 的 y₂ 解析式写出来（3 分钟），能写 → 待定系数已会，只是没写；
不能写 → 补「顶点式待定系数」这一条公式。

### 5.2 「写解析式」训练层：具体形态

参数化生成（题量无限、防背答案、录入成本≈0），每题 30 秒，一轮 10 题：

| 题型 | 例子 | 判分 |
|---|---|---|
| 顶点式 | 顶点 (−2,0)，过 (0,−2) → 写 y = a(x+2)²，求 a | 输入 a 或整式 |
| 反比例 | 图象过 (4,2) → 写 y = k/x，求 k | 输入 k |
| 利润建模 | 每把盈利 60−x、日销 30+1.5x → 写日盈利 W(x) | 输入整式 |
| 分段 | 上升段过 (0,20)、(10,45) → 写第一段解析式 | 输入 k、b |

需要新增**表达式判分**：去空格、全角转半角、系数顺序归一（`y=-1/2(x+2)^2` 与 `y=-(x+2)^2/2` 等价）、
数值容差。这是这个工具唯一的真难点，但比录一套卷子的 JSON 便宜一个数量级。

### 5.3 「大题前两步」模式：更轻的替代

如果不想改代码，纸笔也能做，但工具能保证「每天都做」：
抽一道 21–25，**只显示前 2 个得分点要求，不求解**，孩子写完点「我写了」，对答案自评踩点（0/部分/全）。
3 分钟一道。直接对着「23(1) 都不写」这个习惯。

### 5.4 训练组合（替换现有执行卡的三段）

现有执行卡是「基础快练 10′ + 入口 8′ + 错题 7′」。这次数据说明**基础快练可以减半**（识别已达标），

| ⑤ 稳定 | +2 | 客观题维持 62.5%→70% | 低 |
| **合计** | **90** | 一分都不需要「攻克压轴」 | — |

关键判断：**+7 分在「动笔」，+8 分在「写式」，只有 +5 分需要补具体知识点。**
所以未来两周的重心是「写」和「调度」，不是「再刷一套函数题」。

## 7 边界与风险

1. **没有答题卡，结论是「高概率」不是「确定」。** 23–25 是否空白、填空 14/15 是错还是空，都看不到。
   第 4 节的判别实验能把不确定度降下来。
2. **90% 的样本只有 10 题**，别把它当稳定能力值；它的价值是「排除读图问题」，不是「证明函数没问题」。
3. **别把「函数图象差」的标签贴给孩子。** 数据显示的恰恰相反：读图是他的强项，弱项是「把话变成式子」。
   前者已经证明过，后者是可以练的。
4. **工具改造别抢跑。** 先做 P0（拍照 + 录分 + 核对），P1/P2 等判别实验的结论出来再动；
   否则可能花一周做一个「建模工具」，结果发现真正的问题是时间不够。
5. **录入成本 ≤ 练习时间的 1/4。** 这是 `诊断与建议-九上期中49分.md` 定的线，仍然适用。
