# 函数思维脚手架 · 使用说明

> 一个单文件网页工具：把函数题拆成「读条件 → 画图像 → 选模型 → 定步骤 → 检验」五步来训，另有「试卷练习」（原题 + 分步给分 + 解析）、「得分档案」（按分值看板块得分率）和「题库管理」（导入/导出/校验题包）。

---

## 一、怎么打开

双击 **`函数思维脚手架.html`**，用 Chrome / Edge 打开。

- 不需要联网、不需要安装，题目、画图程序、判分逻辑全在这一个文件里。
- 手机上也能用：把文件发到手机用浏览器打开。
- 记录保存在这台设备的浏览器里（关掉网页不丢），清缓存/换电脑会丢——报告页有「导出记录（TXT / JSON）」和「导入记录（JSON）」（换电脑前先导出 JSON，见「六、报告怎么读」最后一节），题库页有「导出题包」。

## 二、它到底在解决什么

「听课懂、做题不会」不是知识没听懂，而是**做题时那条检索链没建起来**：听课是跟着老师走一遍，做题得自己完成

**读条件 → 画图像 → 选模型 → 定步骤 → 检验**

这条链断在哪一环，多刷题补不上，只会把同一个错误刷得更熟。所以工具做了三个刻意的设计：

| 设计 | 为什么 |
|---|---|
| **每题五问，走完五步才允许落笔** | 强制把「想」和「算」分开。孩子原来的习惯是一看题就动笔，写着写着不知道自己在算什么 |
| **提示分三级，先自己想 20 秒** | 一级指方向、二级给方法、三级才说这一步怎么做 |
| **只统计「第一次就答对」** | 提示后答对不算会。这样报告里的百分比才有诊断价值，不是自我安慰 |

## 四、怎么用（首页任务卡 + 五个模式）

**首页现在是一张「本次任务 · 约 25 分钟」的卡，按顺序做就行，不用自己挑（不是每天做也没关系，隔几天再做会自动换）：**

```
1  基础快练 10′   闪练 15 题：五池各抽 3 题，先补上次错的（同一天内顺序固定）
2  一题深练  8′   自动挑最久没练、错得最多的那一组五步母题
3  错题回炉  7′   按 1/3/7/14 天到期：直接打开今天该重做的那一题
```

**首屏顺序（手机上也一样）：任务卡在最上面，五步说明排在卡片后面。** 打开网页第一眼就是三个「开始」，
不用先往下滚过一整段「这工具解决什么问题」。想先看原理就往下滚，想直接开工就点第 1 项。

### 深链：一条链接直接落到某个屏

在网址后面加 hash，打开就不用再点一遍（双击打开时、或从别的页面/笔记里链过来都行）：

| 深链 | 效果 |
| --- | --- |
| `…/函数思维脚手架.html#view=task` | **直接开始任务第一项**：基础快练（闪练 15 题），不停在首页 |
| `#view=drill` | 直接进闪练（同第一项） |
| `#view=paper` / `#view=report` / `#view=library` | 直接进「试卷练习」/「训练报告」/「变式题库」 |

例：`file:///…/数学/函数思维脚手架.html#view=task`。只在**打开页面时**读一次 hash，运行中切屏不回写地址栏；
不带 hash 时行为和以前完全一致，刷新会按 hash 重进对应屏（契约见 `docs/plans/开始页与深链契约.md`）。

**每次打开（或隔几天再做），这卡里的内容会变：**

- **闪练**：题库 67 题，分五池——

  | 池 | 内容 | 题数 | 对应期中卷板块 |
  |---|---|---:|---|
  | P1 | 一次函数 | 12 | 函数与图象 76 分 |
  | P2 | 反比例函数 | 12 | 同上 |
  | P3 | 二次函数 | 17 | 同上 |
  | P4 | 方程与应用 | 13 | 方程与应用 30 分 |
  | P5 | 图形变换 | 13 | 图形的变换 26 分 |

  每轮从五池**各抽 3 题**（共 15 题）。池内顺序：

  1. 上次做错的（最优先；但一个池最多占 2 个位置，保证每轮至少 5 道新题）；
  2. 从没做过的；
  3. 做对过、且不在最近两轮里；
  4. 最近两轮刚做对过的（排最后）。

  实测：**全对时，下一轮和上一轮重复 0 题**；**全错时，下一轮 10 道复习 + 5 道新题**。
  种子 = 日期 + 今天第几轮，所以**同一天做第二遍也会换题**；隔几天再做更会换（所有题都按"多久没做"重新排）。

- **可以手动换题（不限次数）**：每题下方有「换一题」，只换同池的题；换掉的题不会丢——记下来**下一轮优先回来**，等你真的做了它，标记自动清掉。
  换到把池子里的题换完为止（每个池 12–17 题），所以不会无限空转。
- **「换一套」**：整轮重抽 15 题，且**排除当前这套**（两套不重叠）；已经判过分的记录仍然保留。
- **每题都有次数标识**：「这道题做过 3 次：对 2 · 错 1」，第一次做就显示"第一次做这道题"。
- **闪练的反馈会点出易错点**：判完显示「k 的符号」「顶点式的 h」这类标签，并把"你选的那条错在哪"单独说一句；结算页也会按易错点列错题。
- **深练选题**：按"多久没练 + 错过几次"打分，挑最该补的那一组，而不是永远从第 1 组开始。
- **错题回炉**：只认**到期**的错题。第一次错隔 1 天复习，之后 3 天、7 天、14 天；今天刚错的不会今天逼着重做，卡上会写"明天开始按 1/3/7 天回炉"。到期时按钮直接跳到那一题（带题号与得分）。

任务卡下面的几个小按钮才是完整模式：试卷练习 / 变式题库 / 训练报告 / 题库管理。

**第一周（把五步走顺）：**

| 时间 | 做什么 | 目的 |
|---|---|---|
| 第 1 天 | 只做「一题深练」第 1 题，慢一点，允许点提示 | 把五步走顺，知道每一步在问什么 |
| 第 2–5 天 | 每天任务卡走完（约 25 分钟），五步训练 1 题即可 | 让流程变成习惯，不追求快 |
| 学校发了卷子 | 用「试卷练习」对答案：**先做完整张卷子，再一题一题录答案和得分** | 得分自动进「得分档案」和错题本 |
| 只想先记分数 | 在题目列表点「录得分（按卷面）」，把每题得分填进去（0 到该题分值），不用重做 | 两分钟录完，报告里立刻有板块得分率 |
| 第 6 天 | 看「训练报告」：板块得分率 + 最弱那一环 | 补断点，而不是均匀用力 |
| 第 7 天 | 「变式题库」用「一组一组闯」：先自己说"变了什么、没变什么"，再展开对照 | 这是"举一反三"的具体练法 |

**第二周起：** 每天仍按任务卡走；周末加一次半卷或整卷限时（45–100 分钟），周日晚用报告复盘一次。**错题按 1/3/7/14 天回炉**，不要同一天连做三遍。

**「变式题库」怎么用（两组玩法）：**

- **A. 动手练（推荐先玩这个）**：点「选一个变式，直接练」→ 选任意一个变式 → 自己在纸上做 → 填答案「提交」，
  自动判分；做错红格子标出，同时给出「变了什么 / 没变什么 / 答案 / 一句话」，再点「练下一个变式」继续。
  做对会自动记成「已说清」，做错记成「还没底」，顶部进度条就是 16 个变式的完成情况。
- **B. 一组一组闯（说题模式）**：一次只做一组，先读母题，再把两个变式「变了什么、没变什么」各说一句，
  点「对照」展开验证；说清了点「已说清 ✓」，没底点「还没底 ?」。只用嘴说、不动笔时用这个。
- 顶部左边的「浏览全部（列表速查）」是复习模式：摊开所有"变了/没变/答案"，适合讲给别人听。
- 8 组走完后去「试卷练习」限时做整题；做错的题回来找对应母题，只看没底的变式。

**引导训练里的两个细节：**

- **不用按顺序做题。** 每一题顶部都有一条换题工具条：`← 上一题`、题号 `1…8` 直达、`下一题 →`、`题目清单 ▾`。
  题号上会标出做过的情况（绿＝落笔全对，红＝有错），清单里能看到每题的主题和标题，想补哪一题点哪一题。
  如果当前这题还没走完，换题会先问一句，确认后才丢掉当前进度（已记录的成绩不受影响）。
- **排序题判的是“前提”，不是死顺序。** 比如待定系数法的五步里，第 2、3 步（A、B 两点分别代入）谁先谁后都算对，
  因为它们互不为前提；但「写出解析式」跑到「解方程组」前面就会判错，并直接说清：
  `第 4 步放错了：『写出解析式 y = -x + 2』不该在这儿。它得排在『解方程组…』后面`。
  解析里的正确顺序会用 `⇄ 可换` 标出哪几步可以互换——背的是"谁必须在谁之前"，不是机械背第几步。
- **卡住了点「看思路」（题目卡片右上角）。** 它把这题一次讲透：入口（这题在考什么、用哪个模型）→ 五步各自该做什么
  → 本题关键；参考答案和分步解析折叠着，先自己想再展开。看思路不算答错，但报告里会给这题标上「看过思路」，
  方便区分“真会”和“看会的”。再点一次收起，继续做题不受影响。

**重要用法区别：**
- **引导训练**是「练流程」——工具一步步问，孩子一步步答，答错会指出错在哪一步。
- **试卷练习**是「校验收」——孩子先在纸上完整做，再用工具录答案、对解析、看错题本。**不要边做边看解析**。
- **变式题库**是「练迁移」——不看完整解，只回答"这道变式和母题比，变了什么、没变什么"；能说清才算过。
- 试卷练习里标「自评题」的（如第 12 题翻折、部分压轴问），工具不判分，只给解析，答案口径以老师讲的为准。

## 五、家长怎么配合（比工具本身更重要）

1. **不报答案，只问三句**：
   - 这道题一共给了哪些条件？（第 1 步）
   - 图长什么样？你能画出来吗？（第 2 步）
   - 你现在要找的中间量是什么？（第 4 步）
2. **孩子点提示不要批评**，但要追问："在看提示之前，你想到了什么？"——想不起来，说明这一步是真的空。
3. **只看趋势不看分数**。五步里哪一步最红就补哪一步；不要因为落笔算错就罚做计算题（那会把"思维问题"误判成"努力问题"）。
4. **每周一次"讲题"**：让孩子对着工具的五步，给你讲一道做过的题。讲不清的那一步，就是断点。
5. 试卷练习**先做后录**：一次录一整张，别做一题对一题，否则就成了"边看答案边做题"。

## 六、报告怎么读

报告里现在有两套数：**五步（流程）** 和 **得分（分值）**。先看得分，再看五步。

- **得分档案**（按分值，不按题数）：板块得分率 **低于 40% = 断点**，40–70% = 半会，70% 以上才算稳。
  板块 = 题的 `kp` 第一个值（函数与图象 / 方程与应用 / 图形的变换 / 几何综合），所以它回答的是"哪一块在丢分"。
  数据有两个来源：做题判分（每题填答案）和「录得分」（按卷面直接填分），同一题以最后一次为准。
- **「会但没拿满」**：得分 > 0 但没拿满的题。这一栏比错题本更值钱——它是"会做但写不全/算错"，讲一遍就能补，不是重新学。
- **错因分布**：每道判错的题可以点「入口不会 / 算错 / 看错」，报告会汇总。
  「入口不会」多 → 练"只写得分点"，不是多刷题；「算错」多 → 每天 10 分钟计算；「看错」多 → 练圈条件。
- **命中率低于 60% 的环节 = 流程断点**，工具会给三条具体动作，照着做一周再回来看数据。
- **五步全对、但"落笔有错"** → 问题在计算、书写、单位，不是思维。
- **五步错得多、落笔却对** → 多半是蒙对或背过答案，要警惕，换变式再测。
- **得分档案**只统计"每题最后一次"，同一天重复做不会重复计分；**试卷错题本**按题聚合历史——同一题错过 2 次就记「累计错 2 次」，做对之后也**不会自动消失**，每条都有「重做 →」直接回到那道题。
- "四种表示转换"那一行是闪练数据；试卷练习那一行的"正确率"是按**题数**算的，只作参考——看分请看得分档案。

### 记录备份 / 换电脑（导出、导入 JSON）

报告页最下面那块是记录的出入口：

- **导出记录（TXT）**：给人看的文本报告（各环节正确率 + 做过的题），和以前一样，保留。
- **导出记录（JSON）**：完整备份，文件名 `数学-函数脚手架-记录-YYYY-MM-DD.json`。顶层格式固定：

  ```json
  {
    "schema": "lt.practice-records/1",
    "subject": "数学",
    "tool": "函数思维脚手架",
    "exportedAt": "2026-11-04T06:27:11.000Z",
    "data": { "log": [], "recs": [], "drill": [], "paper": [], "packs": [], "lib": {}, "vrec": [], "skipped": [] }
  }
  ```

  `data` 就是浏览器里存的记录本体（作答日志、做题记录、闪练、试卷作答、导入的题包、变式自评、跳过的题），**整份原样带上、不裁剪**。
- **导入记录（JSON）**：选一份之前导出的 JSON，**整份覆盖**当前记录（不是合并）。导入前先校验：`schema` 必须是 `lt.practice-records/1`、科目必须是「数学」、`data.log` / `data.recs` 必须是数组、`data.drill` / `paper` / `packs` / `vrec` / `skipped` 若存在必须是数组、`data.lib` 若存在必须是对象。任何一条不合格都会用中文逐条说明原因并**整份不导入**，现有记录一个字都不会改。
- **什么时候用**：换电脑、重装系统、清浏览器缓存之前，先导出一份 JSON 存网盘或发给自己；新设备上打开这个 HTML →「训练报告」→「导入记录（JSON）」→ 选文件，记录就回来了。报告页还没有任何数据时这块也会显示——正是为了这个时候能把备份导进来。

## 七、题库管理（题多了怎么管）

打开右上角「题库管理」。三件事：

### 1. 看
列出所有题包：内置 / 导入、题数、来源、已做进度。内置题包不能删，导入的可以删。

### 2. 导入
两种方式，任选：
- 点 **选择文件**，选一个 `.json`；
- 把 JSON 直接粘进文本框，点 **校验并导入**。

**导入前会自动校验**：哪一题、哪个字段不合格，会逐条列出来（最多显示 20 条），一条错就整包不导入——避免半截数据污染题库。

规则：
- **题包 id 相同 = 覆盖**（同名包重新导入不会重复）。
- **题目 id 全局唯一**：新包里的题 id 不能和已有题包撞车（撞了会报错，改个前缀即可）。
- 导入的题包立刻出现在「试卷练习」里，可以像内置的一样练。

### 3. 导出
点「导出全部题包（JSON）」，得到一个文件，包含内置 + 导入的所有题包。用途：备份、换电脑、发给同学、给别人改。

### 4. 加题的工作流（从 PDF 到题包）

1. 打开 PDF，把题干抄成纯文本。公式可以直接打：`x²`、`√2`、`≤`、`1/2` 都能存成文字。
2. 复制 `题库/pack-模板.json`，改成一个新文件（比如 `题库/pack-期中卷.json`）。
3. 按下面的规范填题目；有图的题先想想能不能用 `plot` 画出来（函数图象），卷面那种几何示意图就用 `fig` 按原卷描（见 8.6，用 `题库工具/figs.py` 生成），实在画不了就写「图见原卷」。
4. 回到工具 →「题库管理」→ 选择文件 → 校验并导入。
5. 有报错就照提示改（提示会告诉你第几题、哪个字段、期望什么）。改完再导入。

> 一次做 5–10 题比较合适；一整套卷子一次导入也没问题。

## 八、加题规范（v2）

### 8.1 层级

```
题包 pack  { id, name, source, exam, note, questions:[题…] }
   └ 题 question { id, no, group, type, ask, … }
        ├ 选择题：opts + ans
        └ 填空/解答题：fields[n]
```

### 8.2 题包（pack）

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | 字符串 | 题包唯一标识，建议 `pk-拼音-编号`，如 `pk-qimo-01`。**同 id 导入 = 覆盖** |
| `name` | ✅ | 字符串 | 显示名，如「期中复习卷（一）」 |
| `source` | | 字符串 | 来源，如 `题库/期中卷.pdf` |
| `exam` | | 字符串 | 副标题，如「10 月 14 日 数学练习」 |
| `note` | | 字符串 | 备注（未收录的题、图形口径等） |
| `questions` | ✅ | 数组 | 非空 |

### 8.3 题（question）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 全局唯一，建议 `题包前缀-题号`，如 `qz1` |
| `no` | | 卷面题号（显示用），如 `'12'` |
| `group` | | `'选择'` / `'填空'` / `'解答'` |
| `type` | ✅ | `'choice'`（选择）/ `'fill'`（填空）/ `'solve'`（解答） |
| `score` | | 本题分值（数字）。**建议每题都填**，报告里的得分率才算得出来 |
| `kp` | | 知识点数组，如 `["函数与图象","二次函数"]`。**第一个决定报告里的板块**（函数与图象 / 方程与应用 / 图形的变换 / 几何综合） |
| `formula` | | 应用公式。解析页顶部的「考点 · 应用公式」重点块会逐行加粗显示；多行用 `\n` 分隔，建议 1–4 行：`"① 对称轴 x = −b/(2a)\n② Δ = b² − 4ac > 0 ⟹ 两个不等实根"` |
| `ask` | ✅ | 题干。换行用 `\n`；公式直接写成文字 |
| `opts` + `ans` | 选择题必填 | `opts` 是选项文字数组，`ans` 是正确项下标（**从 0 开始**） |
| `fields` | 填空/解答必填* | 判分字段数组，见 8.4（*也可以改用 `steps`） |
| `steps` | | 分步给分：`[{pt:2, label, type, ans, …}]`，每步一个 `pt`。有 `steps` 时优先用它，`pt` 之和应等于 `score` |
| `solution` | ✅ | 解析，字符串数组，一条一段，建议 2–6 条 |
| `tip` | | 一句话提示（「这一步的关键」），会显示在解析末尾 |
| `focus` | | 主要考点，取值 `trans` / `graph` / `model` / `plan` / `check`，会计入报告统计 |
| `diff` | | 难度 1–3，显示为 ★ |
| `selfCheck` | | `true` = 不判分，只给解析（图形/口径有争议的题用） |
| `plot` | | 配图，见 8.5 |
| `fig` | | 原卷插图（`{w, h, svg}`），见 8.6；有 `fig` 时 `plot` 不再显示 |
| `table` | | 表格：`{head:[…], rows:[[…],…]}` |
| `stem` | | 补充说明（显示在题干下面） |

### 8.4 字段（fields）与分步（steps）

**`fields`（简单题）**：可以有多个字段，每个字段单独判分，全对才算这题对；`score` 会在这些字段间**整数均分**（例：8 分 3 个空 → 3/3/2）。

| 类型 | 写法 | 判分方式 |
|---|---|---|
| 数字 | `{type:'num', label:'k =', ans:2}` | 数字相等（容差 1e-6）；**支持分数输入**，答 `1/2` 等于 `0.5` |
| 带模板的式子 | `{type:'coef', label:'解析式', tpl:'y = {0}x + {1}', ans:[-1,2]}` | 逐个空判数字 |
| 选择 | `{type:'choice', label:'所在象限', options:['一、三','二、四'], ans:0}` | 选中项下标一致 |

**`steps`（要按步给分的大题）**：结构就是上面三种字段，多一个 `pt`（这一步几分）。

```js
steps: [
  { pt: 2, type:'coef', label:'(1) 设解析式', tpl:'y = a(x - {0})^2 + {1}', ans:[5, 4] },
  { pt: 3, type:'num',  label:'(2) 求 a',     ans:-0.16 },
  { pt: 3, type:'num',  label:'(3) 求通行高度', ans:3.04 }
]
```

判分后：对的步骤累加 `pt`，错的记 0，每题顶部显示「得分 5 / 8」，下面逐行标 ✓/✗ 与 `+3 / 3`。
**这就是真实考试的分步给分**——写对两步也能拿到分，不会因为最后一问没做完全判错。
`pt` 之和与 `score` 不一致时，导入会给出警告（不阻止导入），`qb.py verify` 也会提示。

`coef` 的规则：`tpl` 里的 `{0}`、`{1}`… 是空位，**占位符个数必须等于 `ans` 长度**，按顺序对应。

```js
{type:'coef', label:'(1) 解析式', tpl:'y = {0}x + {1}', ans:[-1, 2]}   // 显示 y = [ ]x + [ ]
{type:'coef', label:'(2) 交点',   tpl:'({0}, {1})',       ans:[1, -2]}
```

区间、集合、多个答案这种没法判数字的，用 `choice` 给 4 个选项，或加 `selfCheck:true` 只给解析。

### 8.5 图形（plot）

```js
plot: { expr:'2x-3',                 // 曲线（字符串表达式）或用 f:function 只在 HTML 内可用
        x0:-5, x1:5, y0:-5, y1:5,    // 坐标范围（默认 -5~5）
        sx:1, sy:1,                  // 网格间距（默认 1）
        w:320, h:220,                // 尺寸（默认 300×230）
        marks:[{x:-1,y:3,l:'A'}],    // 标点 + 标签
        rects:[{x:2,y:3}] }          // 从原点画到 (x,y) 的虚线矩形（反比例面积题）
```

`expr` 支持的运算：`+ - * / ^`、括号、`x`、`sqrt()`、`abs()`；**支持省略乘号**：`2x`、`0.5x^2`、`2(x+1)`。

```js
expr:'6/x'                    // 双曲线
expr:'-0.5x^2+2'              // 拱桥
expr:'-(x+1)^2+3'             // 抛物线
```

折线（行程图、分段函数）用点列：

```js
plot: { poly:[[0,0],[10,2000],[15,2000],[20,3000]], x0:0, x1:22, y0:0, y1:3200, sx:5, sy:1000 }
```

两条曲线：`expr` + `expr2`。`marks` 里的 `l` 是标签，留空则不显示文字。

### 8.6 原卷插图（fig）

`plot` 画的是"坐标纸风格"的函数图象（有网格、有刻度）。**卷面上的几何示意图**——墙角围花园、带阴影线的墙、带虚线对齐线的温度曲线——用 `plot` 画一定走样，改用 `fig`：

```json
"fig": { "w": 300, "h": 215, "svg": "<path d=\"...\"/><text ...>A</text>" }
```

- `w` / `h`：viewBox 宽高（就是画布尺寸，页面按这个比例显示，上限 1:1 不放大）；
- `svg`：一段 SVG 片段（**不要**写外层 `<svg>`），坐标直接用画布坐标；
- 有了 `fig` 就**不再显示 `plot`**（两个都写时页面优先 `fig`）。

这些片段用 `题库工具/figs.py` 生成，不要手敲坐标：

```powershell
# 改完 figs.py 里的三张图后：写回题包 -> 重建 -> 校验
python 题库工具\figs.py --pack 题库\pack-九上数学期中模拟练习.json --write
python 题库工具\qb.py build
python 题库工具\qb.py verify
# 只看效果（输出一张 PNG 拼图，不用开浏览器）
python 题库工具\figs.py --preview %TEMP%\fig.png
```

`figs.py` 里已经写好三张图（第 20 题墙角花园、第 21 题隧道、第 22 题冷柜曲线），都是按卷面截图的点位画的；加新卷时照着写一个 `fig_q??()` 加进 `FIGS` 即可，墙体阴影线、箭头坐标轴、虚线对齐线、斜体字母标注都有现成的小函数（`line / quad / poly / text / dot / hatch`）。

### 8.8 校验会报什么错

导入时逐条检查，常见提示与改法：

| 提示 | 改法 |
|---|---|
| 缺少 id / name / questions | 补字段 |
| ans 必须是正确选项的下标（从 0 起） | 数一下：第一个选项是 0 |
| tpl 里占位符有 2 个，ans 有 1 个 | 补齐或删掉空位 |
| coef 的 ans 必须是数组 | `ans:[−1,2]`，不要写成 `ans:-1` |
| 填空/解答题需要 fields 或 steps 数组 | 要么给 fields/steps，要么加 `selfCheck:true` |
| score 必须是正数 | 写数字，如 `4`、`8`，不要写 `"8分"` |
| kp 必须是非空字符串数组 | `["函数与图象","二次函数"]`，不要写成字符串 |
| steps 的 pt 合计与 score 不一致（警告） | 调整某个 `pt`，或改 `score`；总分不变就提示，不阻止导入 |
| plot.expr 表达式无法解析 | 检查是否用了 `×`、`÷`、中文括号；改写 `*` `/` `()` |
| fig 需要 {w, h, svg} / fig 的 w、h 必须是正数 | 三个字段都要有：`w`、`h` 是画布宽高，`svg` 是 SVG 片段 |
| fig.svg 里不能有 script 或事件属性 | 只放图形标签（line / path / text …），不要放脚本 |
| id 与已有题包重复 | 换个 id（加前缀） |

## 九、闪练题库怎么加题（`题库/drills.json`）

闪练不是随机题，是**一题只考一个辨别点**，所以每题要打两个标签：

| 字段 | 说明 |
|---|---|
| `id` | `dr-101` 这种，全局唯一 |
| `pool` | `P1` 一次函数 / `P2` 反比例 / `P3` 二次函数 / `P4` 方程与应用 / `P5` 图形变换（决定每轮抽哪几题） |
| `skill` | 易错点（见下表），同一 skill 至少 3 题，`verify` 会检查 |
| `ask` | 题干（一句话，5 秒能读完） |
| `opts` | 选项数组：`{t:'文字', why:'错在哪'}` 或 `{plot:{expr:'3x-2'}, why:'…'}` |
| `ans` | 正确项下标（从 0 起） |
| `why` | 这题的解法一句话 |
| `stemPlot` | 题干配图（可选），`{expr:'2x-1', x0,x1,y0,y1}` |
| `table` | 题干表格（可选），`{head:[…], rows:[[…]]}` |

**易错点（`skill`）一览：**

| 池 | skill |
|---|---|
| P1 | `k-sign` k 的符号 · `b-int` b 与 y 轴交点 · `x-int` 与 x 轴交点 · `k-value` 斜率/平行 · `table-type` 表格判型 |
| P2 | `k-quad` 反比例的象限 · `k-mono` 反比例的增减 · `table-type` · `k-value` |
| P3 | `a-open` 开口与最值 · `h-side` 顶点式的 h · `a-width` \|a\| 与宽窄 · `axis` 对称轴 · `x-int` · `graph-from-table` 表格→图象 |
| P4 | `delta` 判别式与交点 · `vieta` 韦达定理 · `method` 配方/求根公式 · `modeling` 列方程（建模） |
| P5 | `symmetry-point` 对称点坐标 · `rotate` 旋转后的坐标 · `translate` 平移后的式子 · `sym-type` 对称类型判别 |

写法要点：

- **干扰项必须是"真会犯的错"**：符号反、截距错、开口反、象限记混；不要随便改数字凑选项。
- 每个错项都要写 `why`（"你选的那条错在哪"），判错时会显示。
- 图用 `expr` 写，不要写 `f:function`（JSON 存不了函数）：`3x-2`、`-0.5x^2+2`、`6/x`、`-(x+2)^2+1` 都支持。

改完跑：

```powershell
python 题库工具\qb.py build     # 注入 HTML
python 题库工具\qb.py verify    # 结构 + 表达式可解析 + 图选项不重合
```

`verify` 会逐题检查：`ans` 越界、文本选项重复、表达式解析失败、**两个图选项画出来几乎一样**（采样 7 个点比对）。

## 十、一个诚实的边界

工具能解决的是**流程缺失**：知道每一步该问什么、卡在哪一环。

如果孩子某一步反复错在同一个概念上（比如总把"与 x 轴交点"当成"令 x=0"），那不是流程问题，是概念没通——这时要回到课本，把概念重新讲一遍，再回来练。工具会把这个信号暴露出来，但不替代讲概念。

另外：**图形题以原卷为准**。工具里的图是示意图，用来核对"图形长什么样"，不能替代卷面上的精确条件（比如某个点在三等分点上）。这类题建议按「自评题」处理，或在解析里把分类讨论写清楚。
（期中卷第 20/21/22 题例外：那三张图是按卷面逐点描下来的 `fig`，形状、标注、虚线都对齐原卷，见 8.6。）
