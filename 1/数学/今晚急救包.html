    1一道题 3 分钟没思路就跳。不是放弃，是先把能拿的分装进口袋。
    2解答题绝不留空白。写"设…"、"由题意得…"、"当 x = 0 时…"都比空着强。

    八条红线（每条都踩过一次）

    1y = a(x − h)² + k 的顶点是 (h, k)。看到 (x + 3)² 就是 h = −3。
    2平移加在 x 上：y = 2x² 向左 3 → y = 2(x + 3)²；向下 1 → 末尾 −1。
    3解 x² = 3x 千万别两边除以 x，会丢 x = 0。先移项再提公因式。
    4Δ = b² − 4ac，注意 c 带符号；Δ > 0 是两个不相等实根。
    5韦达：x₁ + x₂ = −b/a，那个负号最容易漏。
    6反比例 y = k/x：k > 0 在一、三象限，且每个象限内 y 随 x 增大而减小。比大小先看是否同一象限。
    7关于原点对称 (−x, −y)；关于 x 轴对称 (x, −y)；绕原点顺时针 90° → (y, −x)。
    8一次函数 y = kx + b：k > 0 上升，b 就是与 y 轴交点的纵坐标。
