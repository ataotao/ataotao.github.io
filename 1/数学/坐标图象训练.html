公式速查

点 (x, y) 怎么定位

先横后竖：x 管左右（右正左负），y 管上下（上正下负）。

例：(3, −1) = 从原点向右 3 格，再向下 1 格。

象限只看正负号

第一 (+, +)　第二 (−, +)　第三 (−, −)　第四 (+, −)

落在坐标轴上的点，不属于任何象限。

一次函数 y = kx + b

  • b：直线与 y 轴的交点，坐标 (0, b)
  • k：x 每加 1，y 就加 k（k > 0 往上、k < 0 往下、k = 0 水平）；|k| 越大越陡

走格法：从 (0, b) 出发，右 1 格、上 k 格得到第二个点，两点一连就是这条直线。

二次函数 y = a(x − h)² + k

  • a 管开口：a > 0 向上、a < 0 向下；|a| 越大越窄
  • 顶点 (h, k)：括号里取反得 h，外面的数照抄得 k
  • 对称轴：过顶点的那条竖线 x = h

求 a：把另一个点的坐标代进顶点式，a = 纵差 ÷ 横差的平方。

第 3 层题目下方蓝底的「规则」就是上面的一次函数那条；记不住才点开，别背。
