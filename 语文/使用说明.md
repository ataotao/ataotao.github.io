# 语文训练页 · 使用说明

语文目录下有两张训练卡，都是单文件、可 `file://` 直接打开，入口在仓库根 `开始.html` 的「各科入口 → 语文」分组。

## 两张卡片

| 卡片 | 用途 | 记录键 |
| --- | --- | --- |
| `语文思维脚手架.html` | 期中诊断 + 九板块框架 + 失分点闪练 + 作文逐段批改 | `ywScaffold.v1` |
| `背诵训练卡.html` | **75 篇全覆盖**（中考必背 60 + 教材必背 14 + 了解 1），按学期分组，带课标标注，跟读／遮罩／**考点默写**／重点段 | `ywRecite.v1` |

## 背诵训练卡

四种模式：`#m=read`（跟读，拼音可开关）、`#m=mask`（遮罩，可只遮关键词）、`#m=exam`（考点默写，主推）、`#m=star`（重点段清单）。
> 原「填空自测」「接龙自测」已移除，自测统一走考点默写；旧深链 `#m=fill` / `#m=chain` 会安全回退到跟读。
深链可指定篇目：`#p=chushibiao&m=read`（本周《出师表》）。跟读或遮罩时点「☆ 标为重点段」，重点段会汇总到 `#m=star`，供考前集中过。

### 考点默写（按中考命题规则，全部 75 篇均已配题）

不是自己判断挖词，而是照中考默写题型整理，依据是 2023–2026 真题与课标命题规律：

- **题型**：理解性默写（给情境题干写整句，中考区分度题型）+ 直接默写（给上句写下句）。每题标「高频/中频」和真题出处、易错字。
- **练习法**：合上原文写整句 → 提交后**逐字批改**（对的字绿、写错的字红波浪+正确字、漏字红底）→ 易错字提醒。
- **回炉**：答错自动进错题库，按 `工具/trainer/review.js` 统一内核的 **1/3/7/14 天**到期复习；连对 2 次**有效**答对（非秒答、非看提示/答案）才移出。顶部「待回炉」切换到期题，「看答案」按订正算无效，可「跳过本次」推后 1 天。作答流水 `examRecs` 永久留档。
- 依据的认知科学：提取练习（自测回忆）长期保持率远高于反复重读，配合间隔重复与即时反馈效果最佳（Dunlosky 2013 / Roediger & Karpicke 2006）。

真源 `语文/数据/背诵-考点.json`（出师表样板）+ `背诵-考点-*.json`（其余 74 篇分片，按批次生成），结构：`{id, title, items:[{q, ans, type, freq, src, trap, clue, para}]}`。
共 75 篇 488 题。`ans` 必须逐字来自 `para` 指定段原文（build 会校验），新增篇目照此格式加一个分片即可。
出处 `src` 只用「中考高频/理解性默写常考/教材核心句」等通用标注，不编造具体年份地区；非中考篇目（现代文、陈涉世家、沁园春·雪等）标「教材核心句/情境运用」。

**范围与标注**：依据《义务教育语文课程标准（2022 年版）》附录 1，收录 7–9 年级必背 60 篇（古诗词 40 + 文言文 20），
外加现代诗/文 5 篇（教材要求但不在课标）。每篇带三级标注：`中考必背`（课标 60 篇内，显示课标序号）、
`教材必背`、`了解`。顶部可按学期（七上～九下）和级别筛选；深链 `#p=guanju&t=八上&lv=中考必背`。

**改内容**：真源是 `语文/数据/` 下各 JSON（段落 `text` + 注音 `pinyin` + 挖空 `keys`）+ `背诵-考点.json` 与各 `背诵-考点-*.json` 分片（考点题，build 自动合并去重），
`课标必背60篇.json` 是篇目/学期/序号的校验基准；模板是 `背诵训练卡.template.html`，回炉内核真源 `工具/trainer/review.js`（build 内联，改它要重建所有接入方）。
改完跑 `node 语文/数据/build.mjs` 重建产物，**不要手改 `背诵训练卡.html`**。
自检：`node 语文/题库工具/check-recite.mjs`（校验 75 篇考点齐全、60 篇课标齐全、学期标注一致、考点答案逐字来自原文、四模式渲染 + 翻页/筛选题干/考点判分与回炉）。
详细范围见 `docs/plans/语文背诵训练卡-2026-11-20.md`。

## 数据口径

- 分数来源：试卷配套的 `小题分.png`，逐题加总。正卷 140、附加题 8。
- 学生作答：按答题卡原字转录，潦草处按上下文复原；不影响判分。
- 记录键：`ywScaffold.v1`，形如
  ```json
  { "v": 1,
    "stat": { "y1": { "att": 2, "ok": 1, "wrong": 1, "at": "2026-11-10T…" } },
    "days": { "2026-11-10": { "n": 12, "ok": 9 } },
    "essay": { "self": { "c0": true }, "at": "…" } }
  ```
  和化学同形（`stat` + `days`），所以 `开始.html` 的「今天做什么」「备份全部记录」都能直接算。

## 维护

改内容只改文件里 `<script>` 顶部的五组数据，不动渲染逻辑：

| 数据 | 位置 | 改什么 |
| --- | --- | --- |
| `SECTIONS` | 「数据：诊断」 | 逐题得分、你的答案、标准答案、错因、下次怎么做 |
| `METHODS` | 「数据：板块框架」 | 每个板块的步骤／模板／例证 |
| `ITEMS` | 「数据：闪练」 | 题目、选项、答案索引（`a`，从 0 起）、解析；主观题用 `ans[]` |
| `PARAS` `BADS` `ESSAY_HOW` `CHECK` `LIDI` | 「数据：作文」 | 逐段批改、病句表、四步动作、自评项、立意分档位与范例 |

改完做三件事：

1. 语法自检：`node --check`（把 `<script>` 内容抽成 `.js` 再跑），或直接在浏览器打开看控制台。
2. 四个页签都点一遍，确认没有空白页签。
3. 提交前跑 `node 工具/check-size.mjs`（本页约 93 KB，远低于阈值）。

## 注意

- 本页不含任何试卷照片或裁图（容量预算），所以「看原卷」不做。
- 不写学生真实姓名；考号只用 `header.id` 形式的说明，页面上不出现。
- 训练台（左侧栏插件）暂不解析语文记录：`BACKUP_APPS` 里还没有 `ywScaffold.v1`，
  和化学的现状一致。备份文件里有数据，只是面板不显示。
