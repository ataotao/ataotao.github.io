# 语文思维脚手架 · 使用说明

单文件训练页：`语文/语文思维脚手架.html`。引擎、数据、样式都在同一个文件里（B 类，没有构建脚本）。
入口在仓库根 `开始.html` 的「各科入口 → 语文」，也支持深链直接进某个页签。

## 五个页签

| 页签 | 内容 | 深链 |
| --- | --- | --- |
| ① 本次诊断 | 2026-2027 第一学期期中卷的逐题得分、你的答案、标准答案、错因、下次怎么做 | `#view=diag` |
| ② 板块框架 | 九个板块的动作序列：步骤／模板／这份卷子上的例子 | `#view=method` |
| ③ 失分点闪练 | 43 题，全部从这份卷子的丢分处长出来；选择题点选即判，主观题自评 | `#view=drill`、`#list=wrong`、`#tag=字音` |
| ④ 作文逐段批改 | 《这一次，我选择说「不」》5 个自然段：原文（病句标红）→ 段评 → 改法 → 升格示范；另有「立意分」两节（先切题再给分、三个题眼、同一段前文四档结尾范例）、病句清单 12 条、四步动作、交卷自评 10 项 | `#view=essay` |
| ⑤ 怎么用 | 口径、键名、导出记录 | `#view=doc` |

## 数据口径

- 分数来源：试卷配套的 `小题分.png`，逐题加总。正卷 140、附加题 8。
- 学生作答：按答题卡原字转录，潦草处按上下文复原；不影响判分。
- 记录键：`ywScaffold.v1`，形如
  ```json
  { "v": 1,
    "stat": { "y1": { "att": 2, "ok": 1, "wrong": 1, "at": "2026-11-10T…" } },
    "days": { "2026-11-10": { "n": 12, "ok": 9 } },
    "essay": { "self": { "c0": true }, "at": "…" } }
  ```
  和化学同形（`stat` + `days`），所以 `开始.html` 的「今天做什么」「备份全部记录」都能直接算。

## 维护

改内容只改文件里 `<script>` 顶部的五组数据，不动渲染逻辑：

| 数据 | 位置 | 改什么 |
| --- | --- | --- |
| `SECTIONS` | 「数据：诊断」 | 逐题得分、你的答案、标准答案、错因、下次怎么做 |
| `METHODS` | 「数据：板块框架」 | 每个板块的步骤／模板／例证 |
| `ITEMS` | 「数据：闪练」 | 题目、选项、答案索引（`a`，从 0 起）、解析；主观题用 `ans[]` |
| `PARAS` `BADS` `ESSAY_HOW` `CHECK` `LIDI` | 「数据：作文」 | 逐段批改、病句表、四步动作、自评项、立意分档位与范例 |

改完做三件事：

1. 语法自检：`node --check`（把 `<script>` 内容抽成 `.js` 再跑），或直接在浏览器打开看控制台。
2. 四个页签都点一遍，确认没有空白页签。
3. 提交前跑 `node 工具/check-size.mjs`（本页约 93 KB，远低于阈值）。

## 注意

- 本页不含任何试卷照片或裁图（容量预算），所以「看原卷」不做。
- 不写学生真实姓名；考号只用 `header.id` 形式的说明，页面上不出现。
- 训练台（左侧栏插件）暂不解析语文记录：`BACKUP_APPS` 里还没有 `ywScaffold.v1`，
  和化学的现状一致。备份文件里有数据，只是面板不显示。
