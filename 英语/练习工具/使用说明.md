# 九上英语过关练习 · 使用说明

把 `英语/题库/` 里 U1–U4 四张过关卷整理成了一个可交互的练习工具：选择题点字母即批改，填空题按横线手写与参考答案比对批改，每题配**考点 / 规则 / 解析 / 易错点**四段式讲解，错题自动归集。

> 说明：卷面上的字母、横线手写都是**你的原卷作答**，工具里的答案是另外独立整理的标准答案，只用来给你的作答打分。

## 文件都在哪

```
英语/
├─ 九上英语过关练习.html   ← 主文件，双击即用（数据已内联，离线可用）
├─ 题库/                   ← 扫描原图
└─ 练习工具/               ← 数据、脚本、预览图、本说明
   ├─ data/                ← u1–u4.json（题面）+ uX.key.json（答案）+ uX.explain.json（三段式讲解）
   ├─ preview/             ← 四个界面的截图
   ├─ index.html           ← 开发/预览版（数据单独放在 data/bundle.js）
   ├─ build.mjs            ← 生成 data/bundle.js 与上面那个单文件
   ├─ check-grading.mjs    ← 离线打印「原卷手写」逐题判分清单（复核答案用）
   ├─ shots.mjs            ← 重新生成 preview/ 截图
   ├─ serve.mjs / qa.mjs   ← 本地预览服务、无头浏览器自检
   └─ 使用说明.md
```

## 怎么用

**直接双击 `英语/九上英语过关练习.html`** 即可（Chrome / Edge 都行），不联网、不需要服务器。

改数据后想预览源码版（`index.html` 需要 HTTP 才能加载 `data/bundle.js`）：

```powershell
node 英语/练习工具/serve.mjs 4311
# 浏览器打开 http://127.0.0.1:4311/英语/练习工具/index.html
```

## 四个视图

| 视图 | 作用 |
| --- | --- |
| **练习** | 每个单元一张「试卷纸」。点 A/B/C/D 立即判分：正确变绿并打红勾，错误标红并打红叉；答完自动展开解析。题号下方的蓝字 `原 B` 是你原卷页边的作答。 |
| **批改报告** | 选择题按页边字母、填空题按横线手写逐题批改（对 / 错 / 待核对 / 未作答），点任意一行跳到该题；顶部给出选择、填空各自的正确率。 |
| **错题本** | 原卷答错的选择题 + 填空题 + 工具里做错的题自动汇总，按单元筛选、按考点聚合，可「导出 Markdown」、「导出记录（JSON）」、「导入记录（JSON）」或「打印错题」，每条带考点规则、解析与易错点。每题会标「累计错 N 次」；**做对了也不会自动消失**，确认真会了点「我会了，清掉」，清掉后再做错会自动回来。 |
| **填空自测** | 单词拼写 / 汉译英 / 句型翻译：输入后回车判分（忽略大小写、标点、`/` 分隔），或直接「对照答案」看参考答案、原卷手写、批改结果与三段式讲解。 |

作答记录存在浏览器 localStorage（键 `eng9a-practice-v1`），关掉再开仍在；页脚可清空全部记录。每题还会记下**作答时间**：`at`（该题最近一次作答，ISO 字符串）和 `atList`（该题最近 10 次作答时间，新的在前）。题号旁的「最近作答 2026-11-04 15:02」就来自它；旧存档没有这两个字段也能照常打开（缺省补空，不报错）。

## 练习页的两种显示方式：整卷 / 逐题

练习页工具栏上有 **`整卷 | 逐题`** 切换（在「只看错题 / 未做」右边）：

- **整卷**（默认）：和以前完全一样，一个单元一张试卷纸，所有选择题一次排开。
- **逐题**：一次只显示**一道题**（题干 + 选项 + 解析），上下各有一条导航：`← 上一题`、`进度 x / N`、`下一题 →`。第 1 题时「上一题」置灰，最后一题时「下一题」置灰。
  - 判分、解析、重做、作答时间与整卷用的是**同一套逻辑**：点字母即判分，答完自动展开三段式解析，答错会记进错题本并累计次数；切题再切回来，已答状态和解析都还在。
  - 适合手机上「一次只看一题、不往下滑」的练法；「只看错题 / 未做」筛选对逐题模式同样生效（进度按筛后的题数算）。
- 这个偏好单独存在 **`eng9a-view-v1`**（内容就一个 `{"mode":"one"}` 或 `{"mode":"paper"}`），**不写进 `eng9a-practice-v1` 的作答记录**，所以导出/导入记录、旧存档都不受影响；刷新后保持你上次选的模式，从没选过就是整卷。

## 深链（打开就跳到指定视图 / 单元）

在网址后面加 hash 参数，打开直接落到对应位置（`九上英语过关练习.html` 单文件版和 `练习工具/index.html` 都支持；只读 hash，不会改你的记录结构）：

| 深链 | 效果 |
| --- | --- |
| `…/九上英语过关练习.html#view=practice` | 打开就是「练习」 |
| `#view=report` / `#view=mistakes` / `#view=fills` | 打开就是「批改报告」/「错题本」/「填空自测」 |
| `#unit=U1`（U1～U4，也认 `#unit=1`） | 切到该单元，并定位到该单元**第一题**（练习页）；配 `#view=fills` 时定位到该单元第一道填空 |
| `#view=mistakes&unit=U2` | 错题本，并直接把单元筛选切到 U2 |

例：`file:///…/九上英语过关练习.html#view=mistakes&unit=U2`。只在**打开页面时**读一次 hash，运行中切视图不回写地址栏；不带 hash 时行为和以前完全一致，刷新会按 hash 重进（契约见 `docs/plans/开始页与深链契约.md`）。

## 记录导出 / 导入（JSON）

错题本工具栏和页脚都有这两个按钮，用来在浏览器之间搬、或长期归档孩子的作答数据：

- **导出记录（JSON）**：下载 `英语-练习记录-YYYY-MM-DD.json`（日期取本机当天），内容是**整份** localStorage 存档：

  ```json
  {
    "schema": "lt.practice-records/1",
    "subject": "英语",
    "tool": "九上英语过关练习",
    "exportedAt": "2026-11-04T07:00:00.000Z",
    "data": { "picks": {}, "fills": {}, "stat": {}, "cleared": {}, "at": {}, "atList": {}, "unit": "U1" }
  }
  ```

  `data` 就是 localStorage 里 `eng9a-practice-v1` 的原对象（含 `at` / `atList` 时间戳）。
- **导入记录（JSON）**：选一个上面导出的文件 → 先弹确认（会盖掉当前记录，并显示两边条数）→ **整份覆盖** `data` 到 localStorage，然后刷新当前视图、错题本计数。文件不是合法 JSON、或没有对象形式的 `data`，会中文提示「导入失败…」，**不会**动现有记录。

> 导入是整份覆盖，不是合并：想保留旧记录，先导出一份再导入。归档文件建议放仓库 `学习记录/` 目录。

## 解析怎么写的

每题展开后是四段：

- **考点**：这题在考什么（如 `it 作形式主语`、`be made of/from`、`feel 系动词`）。
- **规则**：可操作的判定规则（如「as + 原级 + as」「物作主语用 need doing」）。
- **解析**：为什么答案对、其余选项错在哪，逐个干扰项交代。
- **易错点**：你最容易怎么错、怎么避开（如「中文『这是合适的』易误选 This」「漏写 organizing」）。

## 重新生成

```powershell
cd 英语/练习工具
node build.mjs          # 生成 data/bundle.js 和 ../九上英语过关练习.html
node check-grading.mjs  # 打印填空题判分清单，便于人工复核
node shots.mjs "http://127.0.0.1:4311/英语/练习工具/index.html" "preview"   # 重拍预览图
node qa.mjs "http://127.0.0.1:4311/英语/练习工具/index.html" ".qa"          # 交互自检
```

`build.mjs` 里的 `DROP` 表用于剔除不属于本卷的残片。
