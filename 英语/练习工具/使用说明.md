# 九上英语过关练习 · 使用说明

把 `英语/题库/` 里 U1–U4 四张过关卷整理成了一个可交互的练习工具：选择题点字母即批改，填空题按横线手写与参考答案比对批改，每题配**考点 / 规则 / 解析 / 易错点**四段式讲解，错题自动归集。

> 说明：卷面上的字母、横线手写都是**你的原卷作答**，工具里的答案是另外独立整理的标准答案，只用来给你的作答打分。

## 文件都在哪

```
英语/
├─ 九上英语过关练习.html   ← 主文件，双击即用（数据已内联，离线可用）
├─ 题库/                   ← 扫描原图
└─ 练习工具/               ← 数据、脚本、预览图、本说明
   ├─ data/                ← u1–u4.json（题面）+ uX.key.json（答案）+ uX.explain.json（三段式讲解）
   ├─ preview/             ← 四个界面的截图
   ├─ index.html           ← 开发/预览版（数据单独放在 data/bundle.js）
   ├─ build.mjs            ← 生成 data/bundle.js 与上面那个单文件
   ├─ check-grading.mjs    ← 离线打印「原卷手写」逐题判分清单（复核答案用）
   ├─ shots.mjs            ← 重新生成 preview/ 截图
   ├─ serve.mjs / qa.mjs   ← 本地预览服务、无头浏览器自检
   └─ 使用说明.md
```

## 怎么用

**直接双击 `英语/九上英语过关练习.html`** 即可（Chrome / Edge 都行），不联网、不需要服务器。

改数据后想预览源码版（`index.html` 需要 HTTP 才能加载 `data/bundle.js`）：

```powershell
node 英语/练习工具/serve.mjs 4311
# 浏览器打开 http://127.0.0.1:4311/英语/练习工具/index.html
```

## 四个视图

| 视图 | 作用 |
| --- | --- |
| **练习** | 每个单元一张「试卷纸」。点 A/B/C/D 立即判分：正确变绿并打红勾，错误标红并打红叉；答完自动展开解析。题号下方的蓝字 `原 B` 是你原卷页边的作答。 |
| **批改报告** | 选择题按页边字母、填空题按横线手写逐题批改（对 / 错 / 待核对 / 未作答），点任意一行跳到该题；顶部给出选择、填空各自的正确率。 |
| **错题本** | 原卷答错的选择题 + 填空题 + 工具里做错的题自动汇总，按单元筛选、按考点聚合，可「导出 Markdown」或「打印错题」，每条带考点规则、解析与易错点。 |
| **填空自测** | 单词拼写 / 汉译英 / 句型翻译：输入后回车判分（忽略大小写、标点、`/` 分隔），或直接「对照答案」看参考答案、原卷手写、批改结果与三段式讲解。 |

作答记录存在浏览器 localStorage（键 `eng9a-practice-v1`），关掉再开仍在；页脚可清空全部记录。

## 解析怎么写的

每题展开后是四段：

- **考点**：这题在考什么（如 `it 作形式主语`、`be made of/from`、`feel 系动词`）。
- **规则**：可操作的判定规则（如「as + 原级 + as」「物作主语用 need doing」）。
- **解析**：为什么答案对、其余选项错在哪，逐个干扰项交代。
- **易错点**：你最容易怎么错、怎么避开（如「中文『这是合适的』易误选 This」「漏写 organizing」）。

## 批改统计（选择题 39 题 + 填空题 47 题）

- 选择题：**32 对 / 7 错**。错题：U1 第 11、20、21；U2 第 6、8；U3 第 15；U4 第 5。

- 共 **13 道错题**进错题本。

## 答案复核（2026-11-02）

做过两轮：我自己逐题核对 + 两位独立复核员对着原扫描逐字校对（题干、选项、页边字母、答案）。结论与修正：

- 选择题 39 道全部独立重做核对，答案一致；页边字母与转写一致。U1 第 12 题页边写 B、但选项区 A/B 被划掉、D 前有勾（改答痕迹），按你确认作 **D** 记。
- 填空题修正了几处**会把你正确答案判错**的问题：
  - 首字母已给的填空先补全印刷首字母再比对（`s___+hows → shows`、`r___+emoved → removed`、`p___+ractice → practice` 等）；
  - U1 第 16 题只保留最终作答 `having a talent`（原先划掉的内容混入导致误判）；
  - U4「完成句子」第 10、12、13 题卷面横线数重新数过：分别为 5 / 3 / 4 空，答案随之拆成 `has / a / good / habit / of`、`ask / for / advice`、`in / charge / of / organizing`；
  - 补充等价写法（`sure/certain`、`need watering`、`Besides watching`、`having a talent` 等）。
- 复核清单可随时再跑：`node 英语/练习工具/check-grading.mjs`。

## 重新生成

```powershell
cd 英语/练习工具
node build.mjs          # 生成 data/bundle.js 和 ../九上英语过关练习.html
node check-grading.mjs  # 打印填空题判分清单，便于人工复核
node shots.mjs "http://127.0.0.1:4311/英语/练习工具/index.html" "preview"   # 重拍预览图
node qa.mjs "http://127.0.0.1:4311/英语/练习工具/index.html" ".qa"          # 交互自检
```

`build.mjs` 里的 `DROP` 表用于剔除不属于本卷的残片。
