# 九上英语过关练习 · 使用说明

把 `英语/题库/` 里 U1–U4 四张过关卷做成「一次只看一道题」的练习页：选好答案**再提交**才判分，判完立刻给**考点 / 规则 / 解析 / 易错点**四段讲解，做错的题自动进复盘。不用滚动长卷，手机上也不会被解析块挤走下一题。

> 卷面上的字母、横线手写是你的**原卷作答**；工具里的答案是另外独立整理的标准答案，只用来给你的作答打分。原卷作答**只在提交之后**才显示。

## 一、文件在哪 / 怎么打开

```
英语/
├─ 九上英语过关练习.html   ← 双击这个就能用（数据已内联，离线、不用服务器）
├─ 题库/                   ← 四张卷的扫描原图（九上_U1.jpg … 九上_U4.jpg）
└─ 练习工具/
   ├─ index.html           ← 源码版（数据单独放在 data/bundle.js，要 HTTP 才能加载）
   ├─ data/                ← u1–u4.json（题面）+ uX.key.json（答案）+ uX.explain.json（讲解）
   │                          + id-migration.json（旧题号→新题号）+ SCHEMA.md（数据格式）
   ├─ preview/             ← 六张界面截图
   ├─ build.mjs            ← 拼数据包 + 生成上面那个单文件
   ├─ check-grading.mjs    ← 离线打印「原卷手写」逐题判分清单（复核答案用）
   ├─ serve.mjs            ← 本地预览服务
   ├─ qa.mjs / shots.mjs   ← 无头浏览器自检 / 重拍截图
   └─ 使用说明.md          ← 本文
```

**直接双击 `英语/九上英语过关练习.html`** 即可（Chrome / Edge 都行），不联网、不需要服务器。

- 只想看源码版：先 `node 英语/练习工具/serve.mjs 4311`，再打开 `http://127.0.0.1:4311/英语/练习工具/index.html`。
- 网页发布版（`http://` / `https://`）也能用，但「看原卷」入口会自动隐藏——原卷大图没有随发布上线（不隐藏会 404）。

## 二、两种模式：过关 / 模拟考

做题页顶部有两个按钮：

| 模式 | 判分时机 | 什么时候用 |
| --- | --- | --- |
| **过关**（默认） | 选好 → 点「提交」（或 `Enter`）→ **立刻判分**并展开四段式解析 | 平时练，边做边学 |
| **模拟考** | 全程**不给答案、不给解析**；交卷时一次性判分 → 先出结算页 → 再逐题讲评 | 考前自测，看真实水平 |

- 上次用的模式会被记住（存在 `eng9a-view-v1`），下次打开还是它。**模拟考每次进去都是新一轮**。
- 换模式、换单元都会**从第一题重新开始**；没提交的作答会丢（已经提交过的记录不受影响）。
- 卷面没有分值，所以只算「对了几题」，**不算得分**。

## 三、一题一屏怎么操作

1. 题卡头：`大题 · 第 N 题` + 题型（选择/填空）+ 单元名。
   **语篇填空（U2「语法填空」）例外**：它是一整段短文、6 个空直接嵌在句子里，一张卡就是整篇——和原卷一样，先通读、再填空，不是一空一张卡。
   顶部那一行还有三个入口：**答题卡**、**原卷**（文件打开时才显示）、**只看填空**（筛出填空题，进度会跟着变）。
2. **选择题**：点 A/B/C/D 只是**选中**（蓝框），不是判分。**填空题**：按卷面横线数给几个输入框（一空一个框），逐空填。语篇填空则在短文里逐空填，`Enter` 跳到下一空，最后一空回车即提交。
   语篇题提交后，短文下面按空列出「你的答案 / 答案 / 考点」，点开可看该空的规则、解析与易错点；没有参考答案的空标琥珀色「待核对」，不硬判。
3. 点「提交」才判分：对的绿、错的红，下面展开四段式解析，最下面一行是「原卷作答：…」。
4. 判完底部按钮变成「下一题 →」；想再做一次点题卡下方的「重做本题」（会重新计一次作答）。
5. 底部固定条（`env(safe-area-inset-bottom)`，手机上不会被 iPhone 那条横杠盖住）：`←` 上一题 ｜ 提交 / 下一题 ｜ 答题卡 ｜ 进度 `x / N`。宽屏（≥1100px）时答题卡不再放在底部条里，而是**常驻右侧**。
6. 底部条上的 `x / N` 是**当前单元**的进度，不是四张卷的总数。

模拟考的区别：底部条是 `←` ｜ 下一题 ｜ 答题卡 ｜ 交卷；点选项只是记下你的答案，**可以反复改**；题卡下方的「标记不确定」给拿不准的题打上「已标记」，交卷前好在答题卡上回看。

交卷后的「对 X / Y」**只算这一轮**，不掺以前的记录；错题 chips 里既有本轮错的、也有本轮没做的。结算页按 `Esc` 可以收起来回到题卡（要重新做就点「再来一轮」）。交卷前，题卡下方不会显示「转写备注」——那些备注里可能提到原卷手写答案，属于剧透。

## 四、键盘

| 键 | 作用 |
| --- | --- |
| `1` `2` `3` `4` 或 `A` `B` `C` `D` | 选中选项（仅选择题、且还没提交时） |
| `Enter` | 还没提交 → **提交**；已提交（或模拟考中）→ **下一题** |
| `←` / `→` | 上一题 / 下一题 |
| `Esc` | 关答题卡 |

填空题的输入框里：`Enter` 先跳到**下一空**，最后一空再按 `Enter` 才提交。答题卡打开时只响应 `Esc`。

## 五、答题卡

底部条点「答题卡」，从下方弹出抽屉（宽屏 ≥1100px 时改为右侧常驻的答题卡）：

- **按大题分组**（卷面没有大题标题的题，归到「卷面开头，无大题标题」）；
- 格子状态：未答（白）/ 已答（蓝）/ 对（绿）/ 错（红），当前这题有深红描边；
- 点格子直接跳到那一题，抽屉自动收起。

## 六、模拟考：交卷与结算

1. 做完（或做不下去）点底部「交卷」。一题都没答会先问一句「还没答任何题，仍然交卷？」。
2. 交卷时**一次性判分并写记录**，然后出**结算页**：`对 X / 总 Y`、用时几分几秒、已答几题；下面列出这一轮错的题号（点一下直接跳到那题讲评）；全对则显示「全对，这一单元可以过了」。
3. 结算页三个按钮：
   - **逐题讲评** → 回到第 1 题，已答的题带解析和「原卷作答」，逐题过一遍；
   - **再来一轮** → 清空本轮作答、重新计时；
   - **去复盘** → 跳到复盘视图。

## 七、复盘：两个 tab

顶栏「复盘」进去，两个 tab 共用一个单元筛选（全部 / U1 / U2 / U3 / U4）：

**① 错题**：原卷**答错的选择题**（页边字母和答案不符）+ 你**在工具里做错过的题**，汇总成卡片。每张卡片写你的作答、原卷作答、正确答案、规则/解析/易错点、累计错几次，下面两个按钮：

- 「去重做」→ 跳到那道题（自动切回过关模式，马上能重做）；
- 「我会了，清掉」→ 从错题里清掉（再做错会自动回来）。

> **做对了不会自动消失**：要自己判断「真会了」再点清掉。

「累计错几次」按**工具里**答错的次数算；只在原卷答错、工具还没做过的题会显示 0 次。

原卷答错的**填空题**也会进「错题」：按原卷手写与参考答案比对，判错的就算错（整句翻译类只标「待核对」，不硬判错）。

**② 原卷批改**：按原卷手写逐题给判定，点任意一行跳到那道题：

| 判定 | 含义 |
| --- | --- |
| 对 / 错 | 原卷作答与参考答案一致 / 不一致 |
| 待核对 | 开放题，或整句翻译与参考答案不同但可能只是换了个说法 |
| 未判 | 原卷空着、字迹看不出，或本来就没有参考答案（不硬判） |

工具栏还有「导出 Markdown」（把错题整理成 `.md`，同时复制到剪贴板，方便贴给老师）和「打印」。

## 八、「原卷作答」什么时候出现

- **提交之后**才出现：过关模式在本题提交后，模拟考在交卷后。
- 内容来自 `data/u*.json` 里记的卷面批改结果：选择题是题号左侧页边的手写字母，填空题是横线上的手写内容；没写或看不清显示「（未作答/看不清）」。
- 题卡下方的「看原卷」打开 `英语/题库/九上_U{unit}.jpg` 扫描原图（浏览器原生缩放）；网页发布版自动隐藏这个入口。

## 九、记录：存在哪、怎么备份

作答记录存在浏览器 localStorage，键 **`eng9a-practice-v1`**，关掉再打开还在。**换浏览器 / 清缓存就没了**，所以定期导出。

| 字段 | 内容 |
| --- | --- |
| `picks` | 每题最近一次选择题答案 |
| `fills` | 每题最近一次填空作答（数组，按空） |
| `stat` | 每题累计 `att` 作答 / `ok` 对 / `wrong` 错 |
| `cleared` | 「我会了，清掉」的标记 |
| `at` | 每题最近一次作答时间（ISO 字符串） |
| `atList` | 每题最近 10 次作答时间（新的在前） |
| `hist` | **新加的**：每题最近 5 次作答明细 `{ a, ok, at }`（你答的 / 这次对不对 / 时间）；题卡下方「最近一次作答」就取自它 |
| `rounds` | **新加的**：最近 20 轮模拟考结算 `{ mode, startAt, endAt, costMs, ok, answered, total }` |
| `unit` | 上次停留的单元（不是作答记录） |

- 老字段一个没删，`hist` 只是多出来的一层明细：`stat` 看累计次数，`hist` 留「最近这 5 次到底写了什么」。题卡下方会显示「最近一次作答：…（对/错）」，就取自 `hist`；训练台（`工具/dsh-plugin/`）还不统计它，归档时能对上。
- **再答一次是追加，不是覆盖**：`stat.att + 1`、`atList` 往前插一条（只留 10）、`hist` 往前插一条（只留 5）。

导出 / 导入（页脚也有这两个按钮）：

- **导出记录（JSON）**：下载 `英语-练习记录-YYYY-MM-DD.json`，外壳是统一格式 `lt.practice-records/1`（`schema` / `subject` / `tool` / `exportedAt` / `data`），`data` 里就是上表这个对象（含 `hist`）。
- **导入记录（JSON）**：选文件 → 先弹确认（显示「现在几条 → 导入几条」）→ **整份覆盖**本机记录。**不是合并**：想留旧记录，先导出一份再导入。文件读不动会中文提示「导入失败」，不会动现有记录。导入时会自动把旧题号迁移成新题号（见第十一节）。
- **清空全部作答记录**：连 `stat`（累计对错）、`cleared`（我会了标记）、`at` / `atList` / `hist` **一起清**（旧版清不干净的 bug 已修），只保留当前单元。**不可撤销**，清之前先导出。

归档建议放仓库 `学习记录/` 目录；开始页的「备份全部记录」也会把这个键一起备份。

## 十、深链（打开就落到指定位置）

在地址后面加 hash。只在**打开页面时读一次**，运行中不会改地址栏。

| 深链 | 落到 |
| --- | --- |
| `#view=practice` | 做题，**默认过关**（带 hash 进来一律先给过关，免得被上次的模拟考状态困住；不带 hash 才沿用上次模式） |
| `#view=practice&mode=drill` / `#view=practice&mode=exam` | 直接进过关 / 模拟考 |
| `#view=practice&unit=U2` | 做题，U2 第一题 |
| `#view=review` | 复盘（默认「错题」tab） |
| `#view=review&tab=paper` | 复盘 · 原卷批改（等价老写法 `#view=report`） |
| `#view=fills` / `#view=practice&filter=fills` | 做题页只看填空题 |
| `#unit=U1`…`#unit=U4` | 换单元（也认 `#unit=1`、`#unit=unit1`） |

旧值都留了别名，老书签不会失效：

| 旧值 | 现在落到 |
| --- | --- |
| `#view=mistakes` / `#view=wrong` | 复盘 · 错题 |
| `#view=report` | 复盘 · 原卷批改 |
| `#view=fills` | 做题（旧的「填空自测」已并入做题） |
| `#layout=one` | 静默忽略（一题一屏现在是唯一形态） |

`tab=wrong|paper` 可以直接选复盘的哪个 tab（`#view=review&tab=paper` 等价于 `#view=report`）。非法值按 key 静默忽略、回默认，不报错。

例：`file:///…/英语/九上英语过关练习.html#view=practice&mode=exam&unit=U2`

## 十二、仍然存疑的题（建议和老师对一下）

| 题 | 疑点 |
| --- | --- |
| U1 第 1 题 | 开放性单词填空：答案 `true`（`a fact` / `fact` 也算对），标存疑 |
| U1 第 2 题 | 手写 `outstanding`，参考答案 `outdated`（转折语义），标存疑 |
| U1 第 11 题 | 原卷答 B、参考答案 D；题干「不亚于」的语义判断存疑，标 `doubt` |
| U1 第 16 题 | `be famous for ___` 的参考答案与手写 `having a talent` 不同，`her talent` 与 `having a talent` 都算对 |
| U1 第 26、27 题 | 原卷空白，答案按语境补（`not aware / that`、`I'm afraid / that`）；已按上下文定答案，**不再标 `doubt`**，但原卷确实空着 |
| U2 第 3 题 | 手写被反复重涂，无法辨认，标 `doubt` + `manual`，不判分 |
| U2 第 4 题 | 手写与下一行印刷字重叠，标 `doubt` + `manual` |
| U2 语法填空 第 3 空 | 手写字迹潦草（`was needed` / `is needed` 两说），标 `doubt` |
| U2 语法填空 第 4、5 空 | 被修正带遮挡：第 4 空按 `helps us in many ways` 推定 `in`，第 5 空没有答案（`manual`） |
| U4 单词拼写 第 1 题 | `a addict` 的冠词疑为排版疏漏，答案存疑 |
| U4 完成句子 第 5 题 | 第 4 空按 `organizing` 推定 |

标了存疑（`doubt`）的题，解析里会多一句「该题存疑，建议与老师核对」；没有参考答案的题只给「请对照原卷核对」的提示，不硬判。

## 十三、重新生成 / 自检

```powershell
cd 英语/练习工具
node build.mjs                              # 数据校验 + 生成 data/bundle.js 和 ../九上英语过关练习.html
node check-grading.mjs                      # 按原卷手写逐题判分，打印清单（人工复核用）
node check-grading.mjs --only-wrong         # 只看判错/待核对的
node serve.mjs 4311                         # 本地预览服务（源码版要 HTTP）
node shots.mjs "http://127.0.0.1:4311/英语/练习工具/index.html" "preview"   # 重拍六张截图（做题/判分与解析/答题卡/模拟考结算/复盘×2）
node qa.mjs "http://127.0.0.1:4311/英语/练习工具/index.html" ".qa"          # 交互自检，共 77 条断言
```

- `build.mjs` 会先校验数据（id 唯一 / 选择题 4 个选项且答案在选项内 / 填空题有答案或标了存疑），不过就以退出码 1 结束；通过则打印总题量与每个单元的大题分组。
- 它同时把 `data/id-migration.json`（旧题号 → 新题号）随数据下发成 `window.__ID_MIGRATION`，页面靠它自动迁移旧记录。
- `qa.mjs` / `shots.mjs` 要驱动无头 Chrome，必须先起 `serve.mjs` 并用 `http://` 地址；`qa.mjs` 全过退出码 0，有失败会逐条列出并退出 1。
- 预览图在 `preview/`：`00-做题-一题一屏` / `01-判分与解析` / `02-答题卡` / `03-模拟考结算` / `04-复盘-错题` / `05-复盘-原卷批改` / `06-语篇填空`。
- 产物不手改（ADR-0003）：`英语/九上英语过关练习.html` 只能由 `build.mjs` 从 `index.html` + `data/` 生成。
