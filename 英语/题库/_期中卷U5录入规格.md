## 2. 单元骨架

```json
{
  "unit": "U5",
  "title": "九上 期中卷（2026-2027 第一学期）",
  "header": { "class": null, "name": null, "id": "190919" },
  "note": "2026-2027 学年第一学期初三级英语科期中考试，满分 110 分。原卷为照片，本单元按卷面逐题录入。",
  "passages": { ... },
  "items": [ ... ]

```

- **`no` = 卷面题号，1–66 连续**（全卷连续编号，不要按大题重新从 1 编）。所以**不要写 `id`**，
  页面会自动拼成 `U5-1`…`U5-66`。
- `section` = 卷面大题标题（去掉「一、」这类序号），取值只能是下面九个之一（**照抄，不得自创**）：
  `语法选择`(1–10) / `完形填空`(11–20) / `阅读理解 (A)`(21–25) / `阅读理解 (B)`(26–30) /
  `阅读理解 (C)`(31–35) / `阅读填空`(36–40) / `匹配阅读`(41–45) / `回答问题`(46–50) /
  `语法填空`(51–55) / `语篇填词`(56–65) / `书面表达`(66)
  > 卷面把阅读理解分成 (A)(B)(C) 三个小节，为让每篇短文各自成组，`section` 带上小节字母；
  > 其余照卷面原字。

## 6. passages（卷面长文本，`{{题号}}` 标空位）

只给**确实共用一段文字**的大题：`语法选择`、`完形填空`、`阅读理解 (A)`、`阅读理解 (B)`、
`阅读理解 (C)`、`阅读填空`、`回答问题`、`语法填空`、`语篇填词`、`书面表达`。
- `语法选择` 短文里 10 个空写 `{{1}}`…`{{10}}`；`语法填空` 用 `{{51}}`…`{{55}}`；`语篇填词` 用 `{{56}}`…`{{65}}`。
- `阅读填空`（36–40）与 `匹配阅读`（41–45）：`阅读填空` 有正文 → 放进 `passages`；
  `匹配阅读` 是左五右六的**表格匹配**，没有正文 → 放进 `passages` 也放逐题 `stem` 里更合适，
  **做法**：`匹配阅读` 不写 passage，把「五位同学的需求」（左栏）分别放进对应题 `stem`，
  把「六个社团活动」（右栏 A–F）整理成 `options`（A–F），这样每题可独立作答。
  `阅读填空` 的 A–E 五个选项句整理成该大题的 `options`（36–40 共用），
  每题 `stem` 写「第 N 空」+ 该空前后的原文片段（`______` 处留空）。
- `书面表达` 的 passage = 题目要求（四个求助帖 + 要求），可精简单行为 `stem` 里的中文要点。
- 短文一律**逐字照抄图片**（保留 `(牛)`、`25°C`、`IP`、`SwagBot` 这类原样），
  只把卷面上的空位换成 `{{n}}`；不要翻译、不要改写、不要补句子。
