## 1. 来源与构建方式

### 1.1 结论：脚本生成的单文件产物

- 语法闪练：`英语/语法闪练/build.mjs`（403 行）读 `data/g*.json`（build:55-57），校验后组 `window.FLASH_DATA`（build:188-216、333-339），再把 `index.html` 里的占位

### 2.3 模块（题型组）与渲染组织

**语法闪练 = 5 个 block 的顺序刷题**

- 题型只有一种：单项选择（4 选项，点选即判，一题一屏，ADR-0004）。
- 渲染：4 个屏幕 `#scr-home`（`index.html:346` 起：三个入口「开始今晚方案 / 只刷我错过的题 / 只判考点」+ block 卡片 + 页内文档行 + 导出/导入/清空）、`#scr-drill`（377）、`#scr-result`（401）、`#scr-doc`（429）。

### 2.4 一道题包含哪些字段、哪些可省

**语法闪练**（规范 `data/SCHEMA.md:29-45`，校验 `build.mjs:87-131`）：

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| `group` / `title` / `block` | ✓ | 文件级；`group ∈ clause|verb|word|gz|verbform`，`block` 与 group 绑定（build:39） |
| `id` | ✓ | `^[a-z]{2}-\d{3}$`，前缀按 group（cl/vb/wd/gz/vf），**全库唯一** |

| `level` | ✓ | 1/2/3；`level:3` ≤ 15% |
| `stem` | ✓ | **恰好一个 `______`**（3+ 下划线），全库不重复 |
| `cn` | 可省（写 `null`） | 中文提示/译文 |
| `options` | ✓ | 恰好 4 项、去重、不带 `A.` 前缀、不含下划线 |
| `answer` | ✓ | `A`–`D` |
| `rule` | ✓ | ≤60 字 |
| `trap` | ✓ | ≤50 字 |

### 4.4 编码 / 缩进 / 换行

- 所有页面、脚本、数据：**UTF-8 无 BOM**（实测 8 个关键文件 BOM=false）；无外部资源。
- 盘上换行全部 CRLF（`core.autocrlf` 行为；`.gitattributes` 只强制 `.githooks/*` 用 LF）。构建写 LF，parity 比较前统一 CRLF→LF。
- JSON 缩进：语法闪练 `data/g*.json` 用 **2 空格**；九上 `data/u*.json`、`key/explain` 用 **1 空格/层**；build 输出统一 `JSON.stringify(...,null,1)`。

## 5. 坑与注意（做 2026 期中材料时最容易踩）

1. **产物不能手改**：改完源必须 build，再跑 `node 工具/parity.mjs 英语`；parity 自己会临时写盘再还原，别在构建/编辑并行时跑。
2. **语法闪练文档也进产物**：改 `考前口诀卡.md` / `最小对立对卡.md` / `使用说明.md` / `docs/plans/语法闪练与今晚复习方案.md` 都要重跑 build。
3. **数字过期**：`英语/语法闪练/使用说明.md`（:24/:48/:52）与 `docs/plans/语法闪练与今晚复习方案.md`（:49/:134）、`开始.html:179` 仍写「134 题 / B1 30」，当前实际 **136 题（B1 32）**；写新文档别照抄旧数字。
4. **语法闪练 topic 是硬约束**：新考点不登记 `TOPICS` 会报错；有题但 `topic-cues.json` 缺线索会直接构建失败；`near-topics.json` 缺只警告（「只判考点」干扰项退化）。
5. **九上单元是写死的**：`英语/练习工具/build.mjs:22` 只循环 1–4；加 U5 必须改代码。
6. **九上题号迁移**：改 `id`/题号会影响旧记录；按 ADR-0004 用 `data/id-migration.json`（build:78-84）下发映射，不要直接改键。
7. **记录键是跨文件契约**：`开始.html:191-200` 的 `RECORD_KEYS` 读取 `eng9a-practice-v1` / `eng9a-flash-v1` 做备份与「今天做什么」统计；改键名会同时影响入口页、发布版和训练台（`工具/dsh-plugin/records.js` 还没认识 `eng9a-flash-v1`）。
8. **深链契约**：九上 `#view=practice&mode=drill`、`#view=review&tab=wrong`（`开始.html:178`）；语法闪练 `#block=1..5`、`#list=wrong`、`#view=doc&doc=…`（`使用说明.md:110-122`）。改 hash 处理要同步 `docs/plans/开始页与深链契约.md`。
9. **pre-commit 只跑容量闸门**（`.githooks/pre-commit` 只调 `工具/check-size.mjs`），产物一致性靠 CI（`.github/workflows/repo-budget.yml`，`工具/README.md:171`）与手动 parity，别以为提交成功=产物没漂。
10. **「英语两份」在 parity 里是 B 类**（引擎手写在 HTML，只注入数据）；要改 UI/交互就改 `index.html` 源码壳，再 build，产物里没有第二份可改的引擎。
