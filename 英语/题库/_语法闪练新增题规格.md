# 语法闪练 · 期中错题同款考点补充题（2026-2027 期中卷）

背景：学生这套期中卷 **41.5/110**。语法类失分点已逐题定位。本任务把这些失分点变成
`英语/语法闪练` 里的新题，让他下次遇到同款能对。

## 0. 必读

1. `英语\语法闪练\data\SCHEMA.md` —— 格式与受控词表（**出题质量红线务必逐条遵守**）。
2. `英语\语法闪练\data\g1-clause.json` / `g2-verb.json` / `g3-word.json` —— 现有题风格与 id 序号（新题 id 接着往后排，别撞号）。
3. 参考已有题目的 `rule`/`trap` 写法（一句话规则 + 一句话陷阱，不要翻译腔、不要空话）。

## 1. 三个文件的分工

| 文件 | block | 组前缀 | 本批新增 |

## 3. 质量要求（会被 build.mjs 强制检查 + 人工抽查）

- 每次新增都必须：`stem` 含且只含一个 `______`、`options` 恰好 4 个且互不重复、`answer` ∈ A–D、
  `level` 以 1–2 为主（`level:3` 全文件 ≤15%）、`verified: true`（自己反代回原句核对过）。
- `rule` ≤60 字、`trap` ≤50 字：`rule` 说清"为什么"，`trap` 写"学生怎么会错 + 怎么躲"。
  例：`rule`「最高级用于三者以上比较，前加 the；in the world 是典型最高级范围状语。」
  `trap`「看到 the ___ child 就填原级——先看有没有 in the world 这类范围词。」
- 干扰项必须是"学生真的会错"的选项（如 needn't / mustn't 混、hard / hardly 混、satisfy 家族四形），
  不许用明显荒唐词凑数。
- 题干不要和文件里已有题重复（build 会报）。新增题目风格要与现有题一致：带九上 U1–U4 或本次期中语境。
