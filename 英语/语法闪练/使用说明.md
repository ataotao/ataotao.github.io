# 语法闪练 · 使用说明

给「九上英语期中考前一晚」用的一次性突击工具：**点一下就知道对错**，对的题 1 秒自动翻页，错的题停下来讲两句（规则 + 易错点 + 出处），本轮结束时错的题自动重练到做对为止。刷完给一张「考点正确率」表，看哪几个点明早还得扫一眼。

- 配套方案：`docs/plans/语法闪练与今晚复习方案.md`（时间表、考场流程、明确不做的事）
- 考前口诀卡：`英语/语法闪练/考前口诀卡.md`（明早 15 分钟只看这一页）
- 题库出处与命题依据：`docs/plans/广州九上英语期中-调研A-卷型与语法考点.md`、`…调研B-真题与命题特点.md`

## 一、怎么打开

**直接双击 `英语/语法闪练.html`**（单文件、离线、不用服务器；手机用浏览器打开同一个文件也行）。

- 这个 `.html` 是**产物**，由 `node 英语/语法闪练/build.mjs` 从 `index.html` + `data/` 生成，**不要手改**（ADR-0003）。
- 源码版要先起服务：`node 英语/练习工具/serve.mjs 4312`，再开 `http://127.0.0.1:4312/英语/语法闪练/index.html`。
- 数据存在本机浏览器（`localStorage`，键 `eng9a-flash-v1`），换设备/清缓存会丢，记得导出。

## 二、开始屏：两个入口

| 按钮 | 作用 |
| --- | --- |
| **开始今晚方案** | 按 Block 1 → 2 → 3 → 4 → 5 串成一整轮（现在共 **134 题**，弹窗会报预计时长）。今晚就用这个 |
| **只刷我错过的题** | 把所有做错过（`wrong > 0`）的题捞出来重刷；没做错过时是灰的 |

下面的 block 卡片可以**单独点进去**只刷这一组（这张卡也在提示这组考什么）：

| 2 | 动词三件套（非谓语 / 时态 / 主动被动四时态） | 30 | 模拟考最大失分区 |

## 三、做题屏：点一下就是判分

- **没有提交按钮**。点 A/B/C/D 立刻判：
  - **对**：变绿打勾，**1.0 秒后自动翻到下一题**（会的题不浪费一秒）；
  - **错**：所选项变红、正确项标绿，下方展开 **规则 + 易错点 + 出处**，点「记住了 →」或按 `Enter` 继续。**这题会进本轮末尾的重练队列**。
- 顶栏：`退出` · 进度条 `x/134` · 正确率 · 用时 · 当前考点（右上角小标签）。
- 本轮全部做完后自动进入**重练轮**（只做刚才错的题，选项顺序不变，做对才放你走）；重练再错继续重来。
- 键盘：`1 2 3 4` / `A B C D` 选，`Enter` 继续，`Esc` 退出（会先确认）。

## 四、结算屏

- 大号正确率 + `对 X / Y` + 用时。
- **考点正确率表**：按考点聚合，**低于 60% 的排最前面**——这就是明早要再看一眼的那几个点。
- 四个按钮：`重练错题（N）`、`再来一轮`、`复制今晚小结`（markdown 进剪贴板，含正确率、弱考点、错题 id·考点·出处）、`回到开始屏`。

## 五、记录：导出 / 导入 / 清空

存在 `localStorage` 的 `eng9a-flash-v1`：

```js
{ stat: { "vf-001": { att: 2, ok: 1, wrong: 1, at: "ISO 时间" }, ... },
  rounds: [ { mode: "plan|block|redo", startAt, endAt, costMs, total, ok, wrongIds: [] } ],
  last:   { ...上一轮结算，结算屏读它 } }
```

- **导出记录（JSON）**：`英语-语法闪练-YYYY-MM-DD.json`，外壳是仓库统一格式 `{ "schema": "lt.practice-records/1", "subject": "英语", "tool": "语法闪练", "exportedAt", "data": {...} }`（ADR-0001）。导出后放进仓库 `学习记录/` 即可进档案。
- **导入记录**：**整份覆盖**本机记录，先弹确认；文件坏了只提示「导入失败」，不动原记录。
- **清空记录**：连 `stat` / `rounds` / `last` 一起清，不可撤销。
- 注意：训练台（`工具/dsh-plugin/`）目前还不认识 `eng9a-flash-v1`，导出的快照暂时只当存档；要纳入统计得改 `records.js` 的解析。

## 六、深链（打开就落到指定位置）

只在启动时读一次，运行中不回写地址栏。

| 深链 | 落到 |
| --- | --- |
| `#block=1` … `#block=5` | 直接开这一组 |
| `#view=drill` | 从第一题开始（等价「开始今晚方案」的做题屏） |

## 七、改题库 / 重建

```powershell
cd 英语/语法闪练
node build.mjs              # 校验 + 生成 data/bundle.js 与 ../语法闪练.html
node build.mjs --strict     # 缺题库文件也算失败（发布前用）
```

`build.mjs` 强制校验：`id` 唯一且格式对 · 考点在**受控词表**内 · `options` 恰好 4 个不重复 · `answer` ∈ A–D · `stem` 恰好一个 `______` · `rule` ≤60 字 · `trap` ≤50 字 · 文件内与全库题干不重复 · `level:3` ≤15%。

- 数据格式、受控考点词表、质量红线：`data/SCHEMA.md`
- 词汇与话题范围、不规则动词表：`data/VOCAB.md`
- block 标题 / 预计分钟 / 一句话提示：`data/blocks.json`
- 加一组题：在 `data/` 放一个新的 `gN-xxx.json`（`group` 必须是 `clause|verb|word|gz|verbform`），再在 `build.mjs` 的 `TOPICS` 与 `SPEC` 里登记；**产物只能由 build 生成**。

## 八、已知取舍（不是 bug）

1. **单句而不是语篇**：广州语法选择真卷是一篇 200 词短文挖 10 空。闪练把每个空抽成一句，练的是「信号词 → 形式」的反射；**考场流程（先通读定时态基调）写在方案文档第七节**，别指望闪练代替它。
2. **语篇填词（首字母）练不了**：那题要写出完整单词，考拼写；闪练只覆盖它的「词性 + 变形」部分。拼写靠明早看单词表。
3. **完形填空不做**：广州完形四选项是**同词性不同词义**，属词汇辨析，和语法闪练不是一个东西。
4. **不判「得分」**：题库没有分值口径，只算正确率。
5. **「出处」不是真题原文的承诺**：Block 5 的题干取自真卷原文并在 `src` 标了年份/学校，可回原卷核对；其余 block 是自编题，`src` 只标「哪个单元的哪个语法点」。

## 九、出问题了怎么查

| 现象 | 原因 / 处理 |
| --- | --- |
| 打开后显示「题库还没生成」 | `data/bundle.js` 没生成：跑 `node build.mjs` |
| 开始屏有灰色「题库待生成」卡片 | 对应 `data/g*.json` 缺失（`build.mjs` 的警告里会写缺哪个） |
| 记录不见了 | 换了浏览器/设备，或清了缓存；用「导入记录」恢复 |
| 手机上点选项没反应 | 先确认页面没被「退出确认」弹窗挡住；`Esc` 或点「再看看」关掉 |
| 想看某题为什么这么判 | 答错后展开的讲解里有 `rule`（规则）+ `trap`（易错点）+ `出处`；题库原文在 `data/g*.json` |
