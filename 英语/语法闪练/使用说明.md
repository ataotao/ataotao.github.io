# 语法闪练 · 使用说明

给「九上英语期中考前一晚」用的一次性突击工具：**点一下就知道对错**，判完立刻给「考点 + 规则 +（答错时）易错点 + 出处」，看完点「下一题 →」再走；本轮结束时错的题自动重练到做对为止。刷新页面不会丢进度。刷完给一张「考点正确率」表，看哪几个点明早还得扫一眼。

- 配套方案：`docs/plans/语法闪练与今晚复习方案.md`（时间表、考场流程、明确不做的事）
- 考前口诀卡：`英语/语法闪练/考前口诀卡.md`（明早 15 分钟只看这一页）
- 题库出处与命题依据：`docs/plans/广州九上英语期中-调研A-卷型与语法考点.md`、`…调研B-真题与命题特点.md`

## 一、怎么打开

**直接双击 `英语/语法闪练.html`**（单文件、离线、不用服务器；手机用浏览器打开同一个文件也行）。

**网页版**（手机/平板直接开，不用传文件）：<https://ataotao.github.io/1/英语/语法闪练.html>
—— 也可以从站点首页 <https://ataotao.github.io/1/> 的「⚡ 语法闪练」卡片进。发布走站点仓库 `tools/publish.ps1`（清单里必须有这个文件，见 `docs/plans/开始页与深链契约.md` §四）。

- 这个 `.html` 是**产物**，由 `node 英语/语法闪练/build.mjs` 从 `index.html` + `data/` 生成，**不要手改**（ADR-0003）。
- 源码版要先起服务：`node 英语/练习工具/serve.mjs 4312`，再开 `http://127.0.0.1:4312/英语/语法闪练/index.html`。
- 数据存在本机浏览器（`localStorage`，键 `eng9a-flash-v1`），换设备/清缓存会丢，记得导出。**网页版与本地版是两份记录**（不同源），互不同步。

## 三、做题屏：点一下就是判分，看完要点再走

- **题卡顶部有一行「历史」**（做过才显示，没做过不占版面）：`历史：做对 3 次 · 做错 2 次 · 看答案 1 次（共 6 次）`。
  它来自本机累计记录，**刷新、换题、重练都还在**；鼠标悬停能看到「上次作答：…」。判完一次这一行立刻 +1，所以每道题"错过几次"一目了然。
- **没有提交按钮**。点 A/B/C/D 立刻判：
  - **对**：变绿打勾，展开 **考点 + 规则 + 出处**，**等你点「下一题 →」或按 `Enter`** 才翻页（做对了也要看一眼要点）。想让会的题自己翻过去，把顶栏的 `自动:关` 点成 `自动:开`，之后做对 1.0 秒自动翻页（这个开关会被记住）。
  - **错**：所选项变红、正确项标绿，下方展开 **考点 + 规则 + 易错点 + 出处**，点「记住了 →」或按 `Enter` 继续。**这题会进本轮末尾的重练队列**。
- 反馈块固定是这个顺序：`✓/✗` → **考点**（例：比较级）→ **怎么认出**（一句「先看哪里 → 怎么判断」，如「有 than，或空前有 much/even → 比较级」）→ 规则 → 易错点（仅答错）→ 出处。**先看「怎么认出」那一行**：它教的是入口，规则只是入口之后的动作。
- **卡住了可以点选项下方的「看答案」**：直接亮出正确项 + 完整讲解，不用再猜。代价是 **这题不计入正确率**（避免刷答案把分数抬高），但**会进本轮末尾的重练队列**——没自己想起来就算没掌握，最后必须再做一次。结算页会单列「另有 N 题看了答案（没计入正确率，已加入重练）」。**看过答案的题也会被开始屏的「只刷我错过的题」收进去。**
- **想换题不用退出**：题卡下方有一条 `‹ 上一题` ｜ `答题卡 1/20` ｜ `下一题 ›`，键盘 `←` / `→` 也能换。
  - 点「答题卡」会弹出本轮所有题的题号网格，格子上标着**做对（绿）/ 做错（红）/ 看答案（琥珀）/ 未做**，点哪个题号就切到哪题（一轮 134 题也能滚动）。
  - **换题本身不判分、不计数**：进度条与正确率只按真做了的题算。
  - 已作答的题切回去是**只读回看**：当时的讲解还在，但不能重复判分、也不会重复计分。
  - 有跳过的题时本轮不会结束；点讲解里的「下一题 →」会跳到下一道还没做的题，跳过的题最后绕回来。想结束/放弃本轮仍点「退出」。
- 顶栏：`退出` · 进度条 `x/134` · 正确率 · 用时 · 当前考点（右上角小标签）·`自动:关/开`。正确率的分母是**判过的题**，不含看答案的题。
- **刷新/误关页面不会丢进度**：本轮做到第几题、做对几题、哪些题看过答案都存在本机，重新打开会**自动接着上次那一题**继续（toast 会提示「接着上次：已做 x/y」），答题卡上的对/错/看答案状态也一并恢复。点「退出」才算放弃本轮。
- 本轮全部做完后自动进入**重练轮**（只做刚才错的题，选项顺序不变，做对才放你走）；重练再错继续重来。
- 键盘：`1 2 3 4` / `A B C D` 选，`←` / `→` 换题，`Enter` 继续，`Esc` 退出（会先确认）。

### 看不懂句子？答完看译文，没答时悬停看词义

- **答完题（或点「看答案」）之后**，英文句子**正下方**会出现一行浅紫底的中文整句译文（左侧带一个「译」小标）。切到别的题再切回来，译文还在；刷新续做也在。**没作答时译文不显示**——译文里含着答案的意思，先露出来就等于泄题。
- **没作答时**，把鼠标移到题干里的**任何一个英文单词或短语**上，会浮出深色小气泡：上面是中文释义，下面是原词。短语（如 `in order to`、`is made up of`、`get rid of`）是**整块**显示的，鼠标放在短语里任何一个词上都会给出整块的意思，不会拆成逐词直译。
- 手机上没有鼠标：**点一下单词/短语**同样出词义，点空白处收起。
- 词义来自 `data/glossary.json`（全局词表）+ 每题的 `gloss`（语境义覆盖）。**每道题的每个词都有释义**是构建时校验的（见下文）；答案所在的那个空不会给词义，避免把答案漏出来。
- 做题屏底部提示行也写着「悬停英文词看中文」，忘了就瞄一眼。

### 「只判考点」模式怎么走（专项）

- 第一屏**不显示 A/B/C/D**，只给 4 个考点按钮：判对判错都立刻给「考点 + 这道题的规则」；点「看选项，选答案 →」才出现选项。
- **按「组」走**：一组固定 10 题，做完出结算；结算页那个按钮是 **「下一组 10 题」**，顺着题库往后开新一组（110 题轮完再从头），相邻两组不重复；错题/看答案的题最多先插 5 题。**不是随机抽题**——同一个记录状态重开拿到的还是同一组，方便你陪她对照同一组前后两次。
- 考点判错不影响答案分：顶部正确率与 `store.stat` 只算答案；考点另有「考点识别 X/Y」一行（结算页，低于 80% 会点名判错的考点）。
- 换题、答题卡、刷新续做都照常；重练轮只重练**答案**错的题，不再判考点。
- 用法建议：**每天 10 题**（约 5 分钟），先把「考点识别」练到 8/10，再回普通模式刷速度。判考点拿不准时，去看「最小对立对卡」里对应那一组。

## 四、结算屏

- 大号正确率 + `对 X / Y` + 用时（`Y` 是**判过的题数**，不含看答案的题）。
- **考点正确率表**：按考点聚合，**低于 60% 的排最前面**——这就是明早要再看一眼的那几个点。表里的「题数」和顶部「对 X / Y」同口径，**都不含看答案的题**（某个考点全看了答案，该行显示 `0 题 / —` 并排在最前）。
- 看答案的题会单列一行 `另有 N 题看了答案（没计入正确率，已加入重练）`，并在错题区用琥珀色「看答案」标签标出来，可点跳题。
- **考点识别**（只有「只判考点」模式才出现）：`考点识别 对 X/Y（Z%）· 答案 对 A/B（W%）`；Z 低于 80% 时列出判错的考点名（最多 5 个）。这一行就是「先练判考点，再练速度」的信号——答案分低但考点识别高，说明是规则没记牢；两个都低，说明入口还没建立。
- 四个按钮：`重练错题（N）`、`再来一轮`、`复制今晚小结`（markdown 进剪贴板，含正确率、弱考点、错题 id·考点·出处）、`回到开始屏`；另有一个 `考前口诀卡` 入口（明早 15 分钟要看的就是它）。

## 五、页内资料：方案 / 口诀卡 / 对比卡 / 速查表 / 本说明

开始屏底部（结算屏也有）有一行入口：**考前口诀卡 ｜ 最小对立对卡 ｜ 考点识别速查表 ｜ 今晚复习方案 ｜ 使用说明**，点开在**页面内直接读**，不用去找文件、也不用联网。

- **考点识别速查表**：49 个考点各一行「怎么认出」（43 个本次有题 + 6 个考纲里有、这次没出题），按 4 个 block 分组，带「题数」列（`0` = 本题库没出题）。由 `data/topic-cues.json` 生成，改线索后重跑 `build.mjs` 自动更新，不手改。
- **打印版**：同一份表另有单文件 `考点识别速查表.html`（构建产物），双击打开 → `Ctrl+P` → A4 一页。页内阅读时直接 `Ctrl+P` 也只会印当前这份文档（打印样式已处理）。

- 这三份文档在 `build.mjs` 构建时从仓库里的 `.md` 转成 HTML 一起打进 `data/bundle.js`（`window.FLASH_DOCS`），所以单文件离线版也带着它们。
- 为什么不直接链 `.md`：浏览器打开 `.md` 只会下载或显示成源码，页内渲染才叫"方便查看"。
- 改了文档要重新 `node build.mjs` 才会同步进页面。

## 六、记录：导出 / 导入 / 清空

存在 `localStorage` 的 `eng9a-flash-v1`：

```js
{ stat: { "vf-001": { att: 2, ok: 1, wrong: 1, peek: 1, at: "ISO 时间" }, ... },  // 单题累计：作答/对/错/看答案
  rounds: [ { mode: "plan|block|redo|spot", startAt, endAt, costMs, total, ok, wrongIds: [],
              peek: 2, peekIds: ["wd-011", "gz-003"],
              spot: { total: 10, ok: 7, wrongTopics: ["比较级", "宾语从句语序"] } } ],  // spot 只在「只判考点」轮出现
  last:   { ...上一轮结算，结算屏读它；只有 spot 轮才带 spot 字段 },
  current:{ mode, title, ids: [...], idx, done, ok, phase, wrongIds, pendingRedoIds,
            phaseOk, phaseDone, perTopic, peekIds, spot,   // spot = 考点屏的进度快照（旧记录没有）
            results: { "cl-003": { picked: 1, peek: false, correct: true }, ... },  // 每题结果，切题/刷新用
            startAt },  // 进行中本轮；刷新靠它恢复，退出/结算时清空
  settings:{ autoNext: false } }                               // 「自动跳题」开关
```

- `stat` 就是题卡顶部那行「历史」的来源：`att` 作答次数、`ok` 做对、`wrong` 做错、`peek` 看答案、`at` 最近一次时间。**看答案只加 `peek`，不动 `att/ok/wrong`**，所以正确率口径不受影响。
- `current.results` 是「进行中本轮」每道题的结果（`picked` 选的选项、`peek` 是否看答案、`correct` 对错），答题卡的颜色与「切回已作答的题只读回看」都靠它；旧版记录没有这个字段时按旧逻辑恢复。
- 正确率口径：`正确率 = 答对 / 判过题数`，**判过题数 = 进度 − 看答案的题**。看答案的题不算对也不算错，只保证它最后一定进重练。

- **导出记录（JSON）**：`英语-语法闪练-YYYY-MM-DD.json`，外壳是仓库统一格式 `{ "schema": "lt.practice-records/1", "subject": "英语", "tool": "语法闪练", "exportedAt", "data": {...} }`（ADR-0001）。导出后放进仓库 `学习记录/` 即可进档案。
- **导入记录**：**整份覆盖**本机记录，先弹确认；文件坏了只提示「导入失败」，不动原记录。导入的是旧版文件（没有 `current` / `settings`）也正常。
- **清空记录**：连 `stat` / `rounds` / `last` / `current` 一起清，不可撤销。
- 注意：训练台（`工具/dsh-plugin/`）目前还不认识 `eng9a-flash-v1`，导出的快照暂时只当存档；要纳入统计得改 `records.js` 的解析。

## 八、改题库 / 重建

```powershell
cd 英语/语法闪练
node build.mjs              # 校验 + 生成 data/bundle.js 与 ../语法闪练.html
node build.mjs --strict     # 缺题库文件也算失败（发布前用）
```

`build.mjs` 强制校验：`id` 唯一且格式对 · 考点在**受控词表**内 · `options` 恰好 4 个不重复 · `answer` ∈ A–D · `stem` 恰好一个 `______` · `rule` ≤60 字 · `trap` ≤50 字 · 文件内与全库题干不重复 · `level:3` ≤15% · **`cn` 整句译文必填**（缺了警告，`--strict` 下报错）· **`gloss` 键必须能在题干里逐词匹配** · **悬停词表覆盖率**（构建汇总会打印 `悬停词表 … 覆盖 x/y（%）`，缺词会按文件点名）。

- 数据格式、受控考点词表、质量红线：`data/SCHEMA.md`
- 悬停词义：`data/glossary.json`（题干里每个词形都要有词条；短语键用题干实际词形）。改题干/加题后，跑 build 看覆盖率，缺哪个词补哪个（个别语境义放该题的 `gloss`）
- 「只判考点」的干扰项来源：`data/near-topics.json`（每个考点给 3 个最易混的邻近考点；加考点时要补一行，`build.mjs` 会校验）
- 解析里的「怎么认出」线索：`data/topic-cues.json`（每个考点一句「先看哪里 → 怎么判断」；**每个题库考点都必须有**，缺一条 build 直接报错）
- 词汇与话题范围、不规则动词表：`data/VOCAB.md`
- block 标题 / 预计分钟 / 一句话提示：`data/blocks.json`
- 加一组题：在 `data/` 放一个新的 `gN-xxx.json`（`group` 必须是 `clause|verb|word|gz|verbform`），再在 `build.mjs` 的 `TOPICS` 与 `SPEC` 里登记；**产物只能由 build 生成**。

## 九、已知取舍（不是 bug）

1. **单句而不是语篇**：广州语法选择真卷是一篇 200 词短文挖 10 空。闪练把每个空抽成一句，练的是「信号词 → 形式」的反射；**考场流程（先通读定时态基调）写在方案文档第七节**，别指望闪练代替它。
2. **语篇填词（首字母）练不了**：那题要写出完整单词，考拼写；闪练只覆盖它的「词性 + 变形」部分。拼写靠明早看单词表。
3. **完形填空不做**：广州完形四选项是**同词性不同词义**，属词汇辨析，和语法闪练不是一个东西。
4. **不判「得分」**：题库没有分值口径，只算正确率。
5. **「出处」不是真题原文的承诺**：Block 5 的题干取自真卷原文并在 `src` 标了年份/学校，可回原卷核对；其余 block 是自编题，`src` 只标「哪个单元的哪个语法点」。

## 十、出问题了怎么查

| 现象 | 原因 / 处理 |
| --- | --- |
| 刷新后没接着上次 | 说明这一轮已经点过「退出」或已结算（`current` 被清）；重新点「开始今晚方案」即可。想保留进度就别中途退出 |
| 点「考前口诀卡」提示「文档还没打包」 | 文档是构建期注入的：跑一次 `node build.mjs` |
| 打开后显示「题库还没生成」 | `data/bundle.js` 没生成：跑 `node build.mjs` |
| 开始屏有灰色「题库待生成」卡片 | 对应 `data/g*.json` 缺失（`build.mjs` 的警告里会写缺哪个） |
| 记录不见了 | 换了浏览器/设备，或清了缓存；用「导入记录」恢复 |
| 手机上点选项没反应 | 先确认页面没被「退出确认」弹窗挡住；`Esc` 或点「再看看」关掉 |
| 想看某题为什么这么判 | 判完的反馈里依次是 `考点` + `规则` + `易错点`（仅答错）+ `出处`；题库原文在 `data/g*.json` |
