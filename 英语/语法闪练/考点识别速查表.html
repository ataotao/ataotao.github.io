考点识别速查表 · 九上 U1–U4

每个考点一句「先看哪里 → 怎么判断」。做题时先用它归考点，再想规则；「题数」= 本题库里的题量，0 表示考纲里有、这次没出题。线索与 `data/topic-cues.json` 同源，改数据后重跑 build 即可。

一、从句与句子类型 · Block 1

考点题数怎么认出
adj + that 从句4空前是 sure/glad 这类表确信或情感的形容词，空后成分齐全 → that
it 作形式主语3句首 It 只是占位，真正内容在后面；空后是 sb + to do 时选 of/for，是 that 从句时用 that
宾语从句3动词或介词后接一个句子：不缺成分用 that，表「是否」用 if/whether，缺成分用 what
宾语从句语序3四个选项是同一疑问词的不同摆法 → 从句一律陈述语序，别把助动词提前
宾语从句时态3主句是过去时，从句动词要退一步；但讲客观真理不退
状语从句2两个完整句子用一个连词连起来、空在连词位 → 先判断逻辑关系
条件状语从句4句中有 if / unless：先看空在从句还是主句，从句用现在时、主句才用 will
让步状语从句3前后意思相反 → although/though；有 though 就不要再加 but（空可能是不填）
名词性从句2空在句首或 be 动词后：从句缺主语/宾语 → what；不缺成分 → that
定语从句1空紧跟在名词后 → 引导词代替那个名词：指人用 who，指物用 which
感叹句4句首是 What 还是 How → 看空后面有没有名词：有名词用 What，没有用 How
特殊疑问句2看答语：In two weeks → How soon，Once a month → How often；句式是倒装
祈使句2没有主语、动词原形开头 → 祈使句；「祈使句 + and/or + 将来句」的空选 and 或 or
附加疑问句0句末小尾巴 → 跟着前面主句的 be / 助动词 / 情态动词走
直接引语间接引语1said / told 后面接别人说的话 → 时态退一步、语序改成陈述

二、动词三件套 · Block 2

考点题数怎么认出
不定式6空在 ask/tell/want sb 后、too…to、或表目的 → to do；make 变被动要补 to
动名词6空在介词后，或在 enjoy / practise / finish / mind 后 → doing
非谓语辨析4选项是 to do / doing / done → 先看空前的动词和搭配（need doing、make sb do）
一般现在时2every day / usually 这类习惯，或客观真理 → 动词原形或三单
一般过去时1yesterday / last week / ago / in 2010 → 过去式
一般将来时1next year / soon / tomorrow → will 或 be going to
现在完成时5so far / since / yet → have/has + 过去分词；空也可能考 since/for
过去进行时1while / at that time，说某一刻正在做 → was / were doing
被动语态（现在）3先看主语能不能自己做：不能 → is/are + 过去分词；be made of/from 也跟着时态
被动语态（过去）2过去时间 + 有 by / 主语被做 → was / were + 过去分词
被动语态（将来）2next year / in the future + 主语被做 → will be + 过去分词
被动语态（完成）1so far / up to now + 主语被做 → have been + 过去分词
情态动词2空在 can / must / may 后 → 动词原形；Must I 问就用 needn't 答
主谓一致2主语是 The number of / neither…nor → 先找真正的主语再定单复数

三、词法速记 · Block 3

考点题数怎么认出
系动词5look/feel/sound/seem 后面：填形容词；或 seem to be / seem to do
形容词副词2空修饰名词 → 形容词；修饰动词或形容词 → 副词
形容词辨析0四个都是形容词、意思不同 → 看语境搭配选
副词辨析0四个都是副词 → 看动作的方式和程度
比较级5句中有 than，或空前有 much / even → 比较级；两个 as 之间用原级
最高级1有 in / of 范围，且前面常带 the → -est 或 most
冠词4空在名词前 → 元音音素用 an、特指用 the、泛指用 a/an；固定搭配可能不填
代词4空在动词前用主格、动词后用宾格、名词前用形容词性物主
不定代词3两者用 neither/either，三者以上用 none/all；something 类看语境，others 指别人
介词3空在名词 / 动名词前 → 看固定搭配（be used to / be proud of）
介词短语2四个都是介词短语 → 看固定搭配（in charge of / in addition to）和上下文
连词4空在两句之间 → 判因果 / 转折 / 条件；so/such … that 看空后是形容词还是名词
并列连词2not A but B、either … or … 这类 → 看前后结构，谓语就近一致
名词单复数1空在冠词或数量词后 → 判断可数不可数与单复数
量词0a piece of / a number of 这类 → 看后面的名词和中心词
词形转换1四个选项是同一词根的不同词性 → 看空位要名词、形容词还是副词
词义辨析0四个词性相同、意思不同 → 看语境
短语动词0动词 + 介词 / 副词 → 看固定搭配

四、不规则动词闪刷 · Block 4

考点题数怎么认出
不规则动词·过去式12括号给原形、句子在讲过去（有 yesterday / last week 或 showed 这类）→ 过去式
不规则动词·过去分词12空前是 have/has/be，或空后跟 by → 填过去分词
