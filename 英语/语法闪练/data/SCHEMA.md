# 语法闪练 · 数据格式规范（出题人必读）

一个 JSON 文件 = 一个「考点组」。产出到 `英语/语法闪练/data/`，UTF-8，无注释，严格按下面结构。

```json
{
  "group": "clause",
  "title": "从句与句子类型",
  "block": 1,
  "items": [
    {
      "id": "cl-001",
      "topic": "adj + that 从句",
      "level": 1,
      "stem": "It is true ______ Wang Zhenyi is remembered for her great work.",
      "cn": null,
      "options": ["that", "what", "whether", "which"],
      "answer": "A",
      "rule": "It is + adj + that 从句：it 是形式主语，真正的主语是 that 引导的主语从句。",
      "trap": "看到 It is… 别先当强调句；后面是完整句时用 that，不能用 what。",
      "src": "U1 · 复习指引「adj + that clauses」",
      "verified": true
    }
  ]
}
```

## 字段规则

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `group` | ✓ | 短码，与文件名一致：`clause` / `verb` / `word` / `gz` / `verbform` |
| `title` | ✓ | 组名，≤8 字 |
| `block` | ✓ | 属于今晚第几个 block：`1`=从句与句子类型 / `2`=动词三件套 / `3`=词法速记 / `4`=不规则动词 |
| `id` | ✓ | `组前缀-三位序号`，如 `cl-001`、`vb-014`、`wd-007`、`gz-003`。**文件内唯一**，一经分配不要改（记录靠它） |
| `topic` | ✓ | 考点名，≤12 字，**必须从下面的受控词表里挑**（结算页按它聚合正确率） |
| `level` | ✓ | `1` 基础 / `2` 中等 / `3` 难。今晚优先刷 1–2；`level:3` 占比 ≤15% |
| `stem` | ✓ | 题干。**空格统一写成 6 个下划线 `______`**，一题只挖一个空；英文原句，句末带标点 |
| `cn` | | 中文提示/译文。本工具把它当「可显示给学生看的中文提示」：英文题干也可以带中文译文或情境说明，界面在题干下方用浅灰小字显示；没有就写 `null` |
| `options` | ✓ | **顺序数组，恰好 4 项**，第 1 项即 A、第 4 项即 D。**去重**，不含 "A." 前缀 |
| `answer` | ✓ | `"A"`/`"B"`/`"C"`/`"D"`，必须落在 options 里 |
| `rule` | ✓ | 一句话规则，≤60 字，中文讲清"为什么" |
| `trap` | ✓ | 一句话易错点，≤50 字，写清学生怎么错 + 怎么躲开 |
| `src` | ✓ | 来源标签，如 `U1 · 复习指引` / `U2 · 语法填空` / `广州期中·风格`（**不得声称是某年真题原文，除非你能在 `src` 里给出可核对出处**） |
| `verified` | ✓ | 你自己逐字复核过答案与四个选项后填 `true`；有一丝不确定填 `false`（会被列出来人工复核） |

## 受控词表（`topic` 只能取这些）

**block 1 · 从句与句子类型（`clause`）**
`adj + that 从句`、`it 作形式主语`、`宾语从句`、`宾语从句语序`、`宾语从句时态`、`状语从句`、`条件状语从句`、`让步状语从句`、`名词性从句`、`定语从句`、`感叹句`、`特殊疑问句`、`祈使句`、`附加疑问句`、`直接引语间接引语`

**block 2 · 动词三件套（`verb`）**
`不定式`、`动名词`、`非谓语辨析`、`一般现在时`、`一般过去时`、`一般将来时`、`现在完成时`、`过去进行时`、`被动语态（现在）`、`被动语态（过去）`、`被动语态（将来）`、`被动语态（完成）`、`情态动词`、`主谓一致`

**block 3 · 词法速记（`word`）**
`系动词`、`形容词副词`、`形容词辨析`、`副词辨析`、`比较级`、`最高级`、`冠词`、`代词`、`不定代词`、`介词`、`介词短语`、`连词`、`并列连词`、`名词单复数`、`量词`、`词形转换`、`词义辨析`、`短语动词`

**block 4 · 不规则动词（`verbform`）**
`不规则动词·过去式`、`不规则动词·过去分词`

**Block 5 · 广州卷真题同款（`gz`，lead 维护）**
题干取自广州/越秀区往年期中与中考真题原文，`block` = `5`，考点仍用上面三组的受控词（便于和 1–3 组一起聚合正确率）。`src` 必须写明出处（年份 + 学校 + 区域），**不写题号**——原卷题号无法逐份核验，写了就是假精度。

两条本组专属豁免（其余文件不适用）：
1. **题干长度以原卷为准**，可短于 8 词（真题原句不补语境——补了就不是原文，"可回原卷核对"是这组的价值所在）；
2. 题干里可以保留 `Moreover / And / In her opinion` 这类语篇连接词，哪怕单句读起来语境悬空。

> 想用的考点不在表里 → 从表里挑最接近的，**不要自创**；确实需要新词，写在汇报里让 lead 加表。

## 出题质量红线（违背任一条都会被退回）

1. **四个选项都必须是"像样的干扰项"**：不能靠明显荒唐的选项凑数（如 `A. that B. cat C. run D. blue`）。干扰项应当对应学生真实的错误路径（时态混、主被动混、前缀混、形近词混）。
2. **同一题只能有一个正确答案**。填完后逐一反代回原句读一遍，确认其余三项在语法或语义上明确错。
3. **不考超纲内容**：词汇锁定在沪教牛津版（广州版）九上 U1–U4 及更早的课标词汇内。见 `VOCAB.md`。
4. **同一文件内题干不得重复**，也不要把同一句话换个空挖第二遍。
5. **题干要像考试题**，不要像教材例句：带上 U1–U4 的话题语境（王贞仪/阿基米德/天才/家庭生活/压力与网瘾/服务他人），长度 8–25 词。
6. `rule` 是"规则"，不是"翻译"；`trap` 是"陷阱与规避"，不是"再讲一遍规则"。两句都要具体、可操作，禁止"注意积累""认真审题"这类空话。
7. 选项里出现的**同一个点尽量覆盖面广**，不要把 30 题写成同一种题型；每 10 题至少横跨 4 个不同 `topic`。

## 校验（`node 英语/语法闪练/build.mjs` 会强制检查）

`group`/`title`/`block` 合法 · `id` 文件内唯一且格式正确 · `topic` 在受控词表内 · 恰好 4 个不重复选项 ·
`answer` ∈ A–D · `stem` 含 `______` 且只挖一空 · `rule` ≤60 字 · `trap` ≤50 字 · 文件内题干不重复 ·
`level:3` 不超过 15%。
