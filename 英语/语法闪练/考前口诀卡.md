# 动词三件套 · 考前口诀卡

**2026-11-06 考前 15 分钟，只读这一页**（B2 的 30 题 + B1 动词题里只留 20 行，全是「明天会考 + 你真会错」的）

| 信号词 | 规则 | 口诀（照做） |
| --- | --- | --- |
| 括号给词 `(apply)(need)(check)` | 先定这空是谓语还是非谓语：谓语看时态/三单/被动，非谓语看搭配 | 先定成分再变形：谓语看时态和三单，非谓语看搭配 |
| 空前后有 `by / without`、`be used to`、`addicted to` | 介词后只能接动名词 | 介词后一律 doing；to 当介词时也一样 |
| `enjoy / finish / mind / practise / keep` 后 | 只接 doing，不接 to do | 这五个词后只放 doing |
| `make sb do` 改成被动 | to 必须还原：be made to do | 主动不写 to，被动把 to 补回来 |
| 物作主语 + `need` | need doing = need to be done | 东西要修：need doing，不写 to do |
| `remember / forget / stop / regret` 后 | doing 指已做过，to do 指还没做 | 做过用 doing，还没做用 to do；找时间线索 |
| `ask / tell / want sb ___`；`too…to`；`enough to` | 这几处都接 to do，to 后是原形 | 求人做事、too…to、enough to 只放原形 |
| `is/are + ___`（every day）；`was/were + ___`（yesterday） | 被动 = be + 过去分词，be 跟时态变 | 先问「谁被」：be 变时态，过去分词照抄 |
| `will + ___`（next year）；`have + ___`（so far） | 将来 will be done；完成 have been done | will 后加 be，have 后加 been；少一个就成主动 |
| `if` 从句 + 主句有 `will` | 从句用一般现在时表将来 | if 从句用现在时，will 只准放主句 |
| `for` / `since` | since 接时间点，for 接时间段 | since 跟点，for 跟段；2015 只配 since |
| `have been to` / `have gone to` | been 去过已回，gone 去了未回 | twice、ever 只配 been；人不在现场用 gone |
| `borrow / buy / die / leave` + `for/since` | 短暂动词换成延续动词 keep / have / be | 「借了两周」写 has kept for，不写 has borrowed for |
| 单数主语 + `every day / usually` | 一般现在时第三人称单数加 -s/-es | 主语单数，动词加 s（collects 不是 collect） |
| `said / told / announced` + 后面从句 | 从句退一步（will→would）；真理不退 | 主句过去，从句退一步；真理不退 |
| `while` + 两个动作同时 | while 从句用 was/were doing | while 后 was doing，主句接 did |
| `be made of` / `be made from` | 看得出原材料用 of，看不出用 from | 看得出 of，看不出 from；纸、酒用 from |
| `—Must I …?` | 否定答语用 needn't，mustn't 是禁止 | must 问，needn't 答；mustn't 是「不许」 |
| `neither … nor` 连接主语 | 谓语跟 nor 后最近的主语一致 | nor 后面跟谁，动词就跟谁 |
| `The number of` / `A number of` | 中心词是 number 用单数；A number of 用复数 | The number 单数，A number 复数 |
